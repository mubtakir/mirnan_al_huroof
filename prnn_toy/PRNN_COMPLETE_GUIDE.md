# 1. تمهيد: ما هي PRNN؟

**الشبكة العصبية الرنينية الطورية** ليست شبكة عصبية بالمفهوم التقليدي. إنها **حقل فيزيائي مستمر** من المذبذبات المترابطة التي تتطور وفق قوانين الديناميكا الموجية اللاخطية. لا توجد بوابات خطية، ولا مشتقات عكسية، ولا Softmax. كل ما في الأمر **موجات تتزامن، تتداخل، وتتنافس على الطاقة**.

### الفرق الجوهري عن الشبكات التقليدية:
| المفهوم | في PRNN | في الشبكات التقليدية |
|---|---|---|
| العصبون | مذبذب ذو سعة z(t) وطور φ(t) في C | رقم حقيقي x ∈ R |
| الوزن | موصل اقتران انتشاري K_ij | معامل ضرب w_ij |
| التنشيط | تداخل بنّاء/هدام طبيعي | ACTIVATION(∑w·x) |
| التعلم | CHL: محلي، هيبي، لا مشتقات | Backpropagation عبر PST |

المعلومة في PRNN ليست عدداً بل **حالة رنينية**: **طور موجي + سعة طاقة**. الفكرة الواضحة (مثل "نعم") هي موجة طورها 0 وسعتها عالية. الفكرة المعاكسة (مثل "لا") هي موجة طورها π وسعتها عالية. والفكرة الضعيفة أو المشوشة هي سعة منخفضة بغض النظر عن طورها.

# 2. قلب النظام: معادلات المذبذبات

## 2.1 نموذج كوراموتو (Kuramoto) — الطور فقط

أبسط نموذج: كل عصبون يملك طوراً واحداً φ_i(t). يتطور وفق:

```
dφ_i/dt = ω_i + Σ_j K_ij · sin(φ_j - φ_i) + ضوضاء
```

**القيود:**
- السعة ثابتة (جميع المذبذبات لها نفس القوة)
- لا يوجد "موت" للخلايا الضعيفة — كل العصبونات مؤثرة دائماً

يُستخدم هذا النموذج في `prnn_toy.jl` لإثبات الفكرة الأساسية.

## 2.2 نموذج ستوارت-لانداو (Stuart-Landau) — السعة + الطور

النموذج المطوَّر: كل عصبون هو عدد مركب كامل:

```
z_i(t) = r_i(t) · exp(i · φ_i(t))

dz_i/dt = (μ - |z_i|² + i·ω_i) · z_i + Σ_j K_ij · (z_j - z_i) + ضوضاء
```

**ما يعنيه كل مصطلح فيزيائياً:**
- **μ**: معامل النمو — يدفع السعة للارتفاع حتى تتشبع
- **-|z_i|²·z_i**: التشبع اللاخطي — يمنع السعة من الانفجار، يجذبها نحو |z|=√μ
- **+i·ω_i·z_i**: الدوران الذاتي — التردد الطبيعي لكل عصبون (يكسر التناظر)
- **Σ K_ij·(z_j - z_i)**: الاقتران الانتشار — يسحب المذبذب نحو جيرانه

### لماذا السعة مهمة؟

في PRNN، **السعة = الثقة**. إذا كان العصبون في حالة تداخل هدام (طوره متعارض مع محيطه)، تنخفض سعته تلقائياً. وإذا انخفضت السعة إلى الصفر، فإن:
1. لا يؤثر على جيرانه (الاقتران K·(z_j - z_i) يصبح صفراً)
2. لا يُقرأ مخرجه (لا ينتج قراراً)
3. يمكنه العودة لاحقاً عندما تتغير الظروف

هذا هو **Dynamic Gating** الطبيعي — بدون Softmax، بدون بوابات، بدون طبقات إضافية.

# 3. حل XOR: أول برهان

لماذا XOR؟ لأنها أصغر مسألة لا يمكن حلها بخط مستقيم واحد. أي نموذج تعلم جاد يجب أن يثبت قدرته على حل اللاخطية.

## 3.1 المشكلة: فخ التناظر الطوري

في نموذج كوراموتو التقليدي، إذا مثلنا:
- البت **0** = طور 0 راديان
- البت **1** = طور π راديان

فإن الإدخال (0,0) → أطوار [0, 0]. والإدخال (1,1) → أطوار [π, π]. لكن **[π, π] هي [0, 0] مزيحة طورياً بمقدار π!** وبما أن معادلة كوراموتو تعتمد على **فروق الأطوار فقط**، فإن المخرجين سيكونان متطابقين — وهذا خطأ، لأن XOR تقتضي أن يكون مخرجا (0,0) و (1,1) متساويين (كلاهما 0)، والمشكلة أن فرق الطور بينهما هو π بسبب الإزاحة الجماعية.

**بعبارة أخرى:** الشبكة لا تستطيع التمييز بين "كل المدخلات متطابقة عند 0" و"كل المدخلات متطابقة عند 1".

## 3.2 الحل: مذبذب التحيز المرجعي (Node 3 — Bias)

نضيف مذبذباً ثالثاً إلى طبقة المدخلات:

| العقدة | الدور | الطور أثناء التدريب |
|---|---|---|
| Node 1 | المدخل الأول (x₁) | 0 أو π |
| Node 2 | المدخل الثاني (x₂) | 0 أو π |
| **Node 3** | **المرجع الطوري (Bias)** | **0.0 دائماً** |
| Node 4, 5, 6 | الطبقة الخفية | حر |
| Node 7 | المخرج | مقيد (موجب) / حر (سالب) |

مذبذب التحيز هو **الأرض الطورية (Phase Ground)**. يكسر التناظر الدوراني المطلق ويمنح الشبكة مرجعاً ثابتاً لقياس الأطوار ضده. بدونه، كل الإزاحات الجماعية غير مرئية. وبوجوده، يمكن للطبقة الخفية أن تتعلم الفرق بين (0,0) و (1,1) لأن الإزاحة بمقدار π تقاس بالنسبة للمرجع الثابت عند 0.

## 3.3 الهيكل الكامل (7 مذبذبات)

```
المدخلات:    Node 1 (x₁)     Node 2 (x₂)     Node 3 (Bias=0)
                │  │  │         │  │  │         │  │  │
الخفية:        Node 4 ── Node 5 ── Node 6
                │  │  │         │  │  │
المخرج:          Node 7 (Output)
```

**قيود الهيكل:**
- لا اتصال مباشر بين المدخل 1 والمدخل 2
- لا اتصال مباشر بين المدخل 1 والمخرج
- لا اتصال مباشر بين المدخل 2 والمخرج
- جميع الاتصالات الأخرى حرة (بما فيها Bias → Output)

هذا يجبر المعلومة على **المرور عبر الطبقة الخفية** لتوليد تمثيل غير خطي قبل الوصول للمخرج.

## 3.4 دورة التدريب

```
لكل عينة (x₁, x₂) → target y:

1. التهيئة: أطوار عشوائية صغيرة للجميع
2. المرحلة الموجبة (Positive):
   - أثبت: Node 1 = x₁·π، Node 2 = x₂·π، Node 3 = 0، Node 7 = y·π
   - شغّل المحاكاة 500 خطوة → سجل الأطوار المستقرة φ⁺
3. المرحلة السالبة (Negative):
   - أثبت: Node 1 = x₁·π، Node 2 = x₂·π، Node 3 = 0
   - حرر: Node 7 (يبدأ من φ⁺₇)
   - شغّل المحاكاة 500 خطوة → سجل الأطوار المستقرة φ⁻
4. التحديث الهيبي: ΔK_ij = η · [cos(φ⁺ᵢ - φ⁺ⱼ) - cos(φ⁻ᵢ - φ⁻ⱼ)]
5. اضمحلال الأوزان: K *= 0.9995  
```

### لماذا تضمحل الأوزان؟
بدون اضمحلال، الأوزان تتضخم تدريجياً (لأن التحديث الهيبي تراكمي). الاضمحلال يبقيها ضمن نطاق مستقر ويمنع الانفجار.

## 3.5 النتائج على XOR

| المدخلات | المتوقع | الطور الفعلي | التنبؤ | الحالة |
|---|---|---|---|---|
| (0,0) | 0 | 0.013 راديان | 0 | ✓ |
| (1,0) | 1 | 2.530 راديان | 1 | ✓ |
| (0,1) | 1 | -2.273 راديان | 1 | ✓ |
| (1,1) | 0 | 0.146 راديان | 0 | ✓ |

**الفكرة:** إذا كان cos(φ₇) > 0 فالطور قريب من 0 → تنبؤ 0. وإذا كان cos(φ₇) < 0 فالطور قريب من π → تنبؤ 1.

## 3.6 نموذج ستوارت-لانداو المُحسَّن

`prnn_stuart_landau.jl` يفعل الشيء نفسه لكن بمذبذبات مركبة:

```
z_i(t) = r_i(t) · exp(i · φ_i(t))
dz_i/dt = (μ - |z_i|² + i·ω_i)·z_i + Σ K_ij·(z_j - z_i)
```

التحديث الهيبي يصبح **موزوناً بالسعة**:

```
ΔK_ij = η · [Re(z⁺ᵢ · conj(z⁺ⱼ)) - Re(z⁻ᵢ · conj(z⁻ⱼ))]
       = η · [r⁺ᵢ·r⁺ⱼ·cos(φ⁺ᵢ - φ⁺ⱼ) - r⁻ᵢ·r⁻ⱼ·cos(φ⁻ᵢ - φ⁻ⱼ)]
```

هذا يعني: إذا كان أحد المذبذبين سعته صفر (ميت أو غير مهتم)، **فالتحديث يتوقف تلقائياً** بغض النظر عن الطور — لأنه لا فائدة من تعلم وزن خلية ميتة.

كما أضيفت **جدولة الضوضاء (Simulated Annealing)**:
```
noise_level = 0.015 × (1 - (epoch/300)²)
```
ضوضاء عالية في البداية لاستكشاف فضاء الطور، ثم تبرد تدريجياً لتستقر في الجاذب الصحيح.

# 4. التعلم: Contrastive Hebbian Learning (CHL)

## 4.1 المبدأ

التعلم الهيبي التبايني مبني على فكرة بسيطة: **"الخلايا التي تطلق معاً تترابط معاً — لكن فقط إذا اختلفت الحالة الموجبة عن الحالة السالبة"**.

### المرحلة الموجبة (Positive):
نثبت أطوار المدخلات والمخرج على القيم الصحيحة (الحقيقة). الخلايا الخفية حرة لتتزامن مع هذا القيد. تسجل حالة النظام كمرجع للـ "الصواب".

### المرحلة السالبة (Negative):
نثبت المدخلات فقط، ونحرر المخرج ليتحرك بحرية بناءً على قواه الداخلية. الخلايا تسقط في "الجاذب الطبيعي" للشبكة (الافتراضي). تسجل هذه الحالة كمرجع للـ "الخطأ".

### قاعدة هيبي التباين (للطور فقط):
```
ΔK_ij = η · [cos(φ⁺ᵢ - φ⁺ⱼ) - cos(φ⁻ᵢ - φ⁻ⱼ)]
```

إذا كان الزوج متزامناً (cos(Δφ)≈1) في الحالة الموجبة ومتفرقاً (cos(Δφ)≈0 أو سالب) في السالبة → يزيد الوزن. والعكس صحيح.

### قاعدة هيبي للطور + السعة:
```
ΔK_ij = η · [Re(z⁺ᵢ · conj(z⁺ⱼ)) - Re(z⁻ᵢ · conj(z⁻ⱼ))]
```

هذا تضيف بُعداً جديداً: حتى لو كان الزوج متزامناً طورياً، إذا كانت سعة أحدهما منخفضة في الحالة الموجبة → التحديث صغير، لأن "الثقة" منخفضة.

## 4.2 لماذا هذا أفضل من Backpropagation؟

| الميزة | CHL | Backpropagation |
|---|---|---|
| محلية | كل وزن يرى فقط الخلايا المتصلة به مباشرة | يحتاج المشتق عبر كل طبقة |
| تماثل زمني | تعلم أثناء التشغيل (on-the-fly) | يحتاج تمريراً عكسياً منفصلاً |
| طبيعية فيزيائياً | تشبه التثبيت المشبكي الحقيقي | اصطناعية رياضية بحتة |
| بدون حواجز تفاضل | لا تحتاج | تحتاج (غير قابلة للتفاضل) |

## 4.3 التطبيق العملي

في كل 4 نماذج في prnn_toy:
1. يُدخل (x₁, x₂)
2. تُشغَّل المرحلة الموجبة
3. تُشغَّل المرحلة السالبة
4. تُحدَّث الأوزان محلياً
5. الأوزان تضمحل بنسبة 0.0005 كل دورة

# 5. الذاكرة الترابطية وإكمال الأنماط

في `prnn_associative_memory.jl` نتجاوز XOR إلى الذاكرة: تخزين أنماط واسترجاعها من مدخلات تالفة.

## 5.1 تخزين الأنماط (Hebbian Prescription)

نريد تخزين نمطين طوريين في 8 مذبذبات:

**النمط 1 — النصف والنصف:**
```
[1, 1, 1, 1, -1, -1, -1, -1]
```
أربع خلايا عند الطور 0، وأربع عند الطور π.

**النمط 2 — التناوب:**
```
[1, -1, 1, -1, 1, -1, 1, -1]
```

تُحسب مصفوفة الأوزان كمجموع ضرب خارجي:
```
K_ij = (1/N) · Σ_p ξ⁽ᵖ⁾ᵢ · ξ⁽ᵖ⁾ⱼ       (حيث i ≠ j)
```

هذه الصيغة تجعل كل نمط جاذباً (attractor) في فضاء الطور. إذا دخلت الشبكة إلى منطقة قريبة من النمط الأول، سحبتها قوة الجذب نحو النمط بالكامل.

## 5.2 استرجاع الأنماط التالفة

**الاختبار 1 — النمط 1 المشوه:**
```
المدخل:  [-1, 1, 0.1, -0.2, 0, -1, -1, -1]
         ↑       ↑          ↑
         مقلوب  مفقود      مفقود
```
**النتيجة:** انجذبت الأطوار نحو `[0, 0, 0, 0, π, π, π, π]` واستقرت السعات عند √2 ≈ 1.41. تَمَّ استرجاع النمط كاملاً.

**الاختبار 2 — النمط 2 المشوه:**
```
المدخل:  [1, 0, 1, -0.5, 0.2, -1, 0, -1]
         └── 3 عناصر مفقودة (سعة ≈ 0) ──┘
```
**النتيجة:** استعاد النظام التناوب الطوري المثالي.

## 5.3 لماذا تعمل؟

مصفوفة K المصممة هيبياً تخلق **أحواض جذب (Attractor Basins)** في فضاء الطور المركب 8-الأبعاد. أي نقطة داخل حوض الجذب تنزلق تلقائياً نحو قاع الحوض — النمط المخزن. عملية "الاسترجاع" ليست بحثاً ولا مقارنة، بل **انزلاق فيزيائي محض** على سطح جهد:

```
V(z) = -½ Σᵢⱼ K_ij · zᵢ · conj(zⱼ) + ¼ Σᵢ (|zᵢ|² - μ)²
```

وبقوانين ستوارت-لانداو فإن `dz/dt ∝ -∂V/∂z` — أي أن النظام يتجه نحو **أقل طاقة جهدية**، وهي النمط المخزن.

# 6. الذاكرة المتسلسلة والدورات الحدية

في `prnn_sequential_memory.jl` ننتقل من الاسترجاع الثابت إلى **التوليد المتسلسل المستمر**. الفكرة: بدلاً من جاذب نقطة واحدة، نخلق دورة حدية (Limit Cycle): A → B → C → A → ...

## 6.1 كسر تناظر الزمن

الذاكرة الترابطية العادية تستخدم K متناظرة (K_ij = K_ji)، مما يعني طاقة V تحفظ انعكاس الزمن. لجعل الأنماط تنتقل بتسلسل، نحتاج K غير متماثلة:

**الوصفة الهيبية المتسلسلة:**
```
K_ij = (β/N) · Σ_t ξ⁽ᵗ⁺¹⁾ᵢ · ξ⁽ᵗ⁾ⱼ
```

حيث ξ⁽ᵗ⁺¹⁾ هو النمط التالي و ξ⁽ᵗ⁾ هو النمط الحالي. هذا يعني أن K[i,j] كبير إذا كان الخلية i نشطة في النمط التالي والخلية j نشطة في النمط الحالي → يدفع النظام للأمام.

**للأنماط A, B, C الثلاثة:**
```
K_ij ∝ Bᵢ·Aⱼ + Cᵢ·Bⱼ + Aᵢ·Cⱼ
```

فكل نمط "يدفع" نحو النمط الذي يليه.

## 6.2 آلية التبديل بين الأنماط

دعون منفردة، لولا آليتان تمنعان النظام من البقاء في نمط واحد:

### أ. التثبيط العالمي (Global Inhibition):
```
dz_i/dt = (μ - a_i - g_inh · global_activity - |z_i|²) · z_i + Σ K_ij · z_j
```
حيث `global_activity = Σₖ |zₖ|² / N`. عندما ينشط نمط بقوة، يثبط كل الأنماط الأخرى. هذا يمنع تداخل نمطين معاً.

### ب. التعب العصبي (Neural Fatigue):
```
da_i/dt = (-a_i + γ · |z_i|²) / τ_a
```
المتغير a_i يعمل كـ "تعب": يزيد بمقدار نشاط الخلية ويخفض نموها. بعد فترة، يتعب النمط النشط، تنخفض قوته، فيفسح المجال للنمط التالي.

### معاً:
```
dz_i/dt = (μ - a_i - g_inh · ∑|zₖ|²/N - |z_i|²) · z_i + Σ K_ij · z_j
```
```
- g_inh · ∑|zₖ|²    → يمنع نمطين معاً
- μ - a_i             → التعب يخفض μ الفعلي للخلية مع الوقت
- Σ K_ij · z_j        → الدفع غير المتماثل نحو النمط التالي
```

## 6.3 النتيجة

عند تشغيل المحاكاة 1200 خطوة من قرب النمط A:

```
الخطوة 40   | A: [▒▒▒▒▒▒▒▒▒▒] | B: [░░░░░░░░░░] | C: [░░░░░░░░░░] | A
الخطوة 280  | A: [░░░░░░░░░░] | B: [▒▒▒▒▒▒▒▒▒▒] | C: [░░░░░░░░░░] | B
```

# 7. الربط الهولوغرافي الطوري (VSA)

قبل أن نصل إلى النصوص الحقيقية، هناك مشكلة: **كيف نمثل الكلمات في فضاء طوري؟**

## 7.1 متجهات الأساس الطورية

كل كلمة في المعجم تحصل على **متجه طوري عشوائي** في الفضاء المركب N-البُعدي:

```
v_base("العلم") = [exp(i·θ₁), exp(i·θ₂), ..., exp(i·θ_N)]    حيث θ عشوائية
```

جميع المتجهات سعتها 1.0 (للحفاظ على الطاقة)، وأطوارها مختلفة. في فضاء N-بُعدي، يكون عدد الكلمات المتعامدة تقريباً ∞ لأن التقاطعات العشوائية لا تكاد تحدث.

## 7.2 الربط الهولوغرافي (Binding)

لتمثيل **"كلمة في سياقها"**، نضرب متجه الكلمة الحالية مع متجه الكلمة السابقة:

```
v_adapted(w_t) = v_base(w_t) ⊙ v_base(w_{t-1})
     أي:      = element-wise(v_base(w_t) · v_base(w_{t-1}))
```

هذا ليس ضرباً عادياً. إنه **إزاحة طورية نقية** في كل بُعد:
```
exp(i·θ_t) · exp(i·θ_{t-1}) = exp(i·(θ_t + θ_{t-1}))
```

والجمالية: إذا كان v_base(w_t) و v_base(w_{t-1}) متجهان عشوائيان مستقلان، فإن v_adapted(w_t) متجه **جديد كلياً** متعامد مع جميع متجهات الأساس ومع جميع المتجهات المربوطة الأخرى.

## 7.3 لماذا هذا يحل مشكلة التفرع؟

لنأخذ كلمة **"و"** التي تأتي في جملتين:
- **الجملة أ:** "العلم → نور → **و** → الجهل → ظلام"
- **الجملة ب:** "الحياة → جميلة → **و** → العقل → زينة → الإنسان"

### المشكلة (بدون ربط):
المتجه v_base("و") هو نفسه في الجملتين. الانتقال من "و" إلى ما بعدها سيكون عشوائياً.

### الحل (مع الربط):
```
v_adapted("و" في الجملة أ) = v_base("و") ⊙ v_base("نور")   # متجه فريد 1
v_adapted("و" في الجملة ب) = v_base("و") ⊙ v_base("جميلة")  # متجه فريد 2
```
هذان المتجهان **متعامدان تماماً** في الفضاء N-البُعدي (200 بُعد). مصفوفة K تتعلم: v_adapted1 → v_adapted("الجهل") و v_adapted2 → v_adapted("العقل"). لا تداخل ولا التباس.

## 7.4 فك الربط (Unbinding)

عند التوليد، نحتاج لاستخراج الكلمة من الحالة المركبة z:

```
z_unbound = z ⊙ conj(v_context)
```

حيث v_context هو v_base(last_word). بعد فك الربط، نحسب التقاطع (overlap):

```
overlap(word) = Re(⟨z_unbound, v_base(word)⟩) / N
```

نختار الكلمة ذات التقاطع الأعلى.

## 7.5 القياس الفيزيائي

هذا النظام مشابه لـ **Vector Symbolic Architectures (VSA)** أو **Holographic Reduced Representations (HRR)**، مطبَّق في الفضاء المركب بدلاً من الحقيقي مع إزاحات طورية بدلاً من الالتفاف (convolution). الرياضيات متطابقة تقريباً، لكن التنفيذ الموجي يمنح خصائص اضمحلال طبيعية وسعات ديناميكية ليست موجودة في VSA التقليدي.

# 8. مولد النصوص الفيزيائي

في `prnn_text_generator.jl` نجمع كل القطع:
1. متجهات أساس طورية لـ 10 كلمات (N=200 بُعد)
2. الربط الهولوغرافي
3. مصفوفة K غير متماثلة لتسلسل: A→B→C...
4. التثبيط العالمي والتعب المحلي
5. فك التشفير بـ unbind

## 8.1 بنية التدريب

```
الجملة 1: ["العلم", "نور", "و", "الجهل", "ظلام"]

الانتقالات (v_curr → v_next):
  v_base("العلم") → bind(v_base("نور"), v_base("العلم"))
  bind(v_base("نور"), v_base("العلم")) → bind(v_base("و"), v_base("نور"))
  bind(v_base("و"), v_base("نور")) → bind(v_base("الجهل"), v_base("و"))
  bind(v_base("الجهل"), v_base("و")) → bind(v_base("ظلام"), v_base("الجهل"))

الجملة 2: ["الحياة", "جميلة", "و", "العقل", "زينة", "الإنسان"]
... (مثلها مع السياق المختلف)
```

K تُبنى كمجموع ضرب خارجي:
```
K[i,j] += β · v_next[i] · conj(v_curr[j]) / N       (حيث i≠j)
```

## 8.2 دورة التوليد

```
1. ابدأ من prompt (مثلاً "العلم")
2. z = v_base("العلم")
3. كرر 6 مرات:
   أ. شغّل محاكاة ستوارت-لانداو 50 خطوة:
      - مع تثبيط عالمي g_inh = 0.4 وتعب τ_a = 1.5
      - z يتجه نحو v_next المربوط
   ب. فك التشفير: z_unbound = z ⊙ conj(v_context)
   ج. اختر الكلمة ذات التقاطع الأعلى
   د. إذا الكلمة مكررة أو overlap < 0.15 → توقف
   ه. z الجديد = bind(v_base(الكلمة), v_base(السياق))
```

## 8.3 النتائج

**Prompt = "العلم":**
```
العلم → نور → و → الجهل → ظلام ✓
```

**Prompt = "الحياة":**
```
الحياة → جميلة → و → العقل → زينة → الإنسان ✓
```

**كيف حلَّت الشبكة تفرع "و"؟** عندما وصلت إلى "و"، كانت z في حالة طورية مختلفة (لأن v_adapted("و") اختلف باختلاف السياق)، فوجهتها K نحو المسار الصحيح.

# 9. المتعلم من الكوربوس الحقيقي

في `prnn_corpus_learner.jl` — أخطر ملف في المجموعة — ننتقل من 10 كلمات يدوية إلى **كوربوس عربي حقيقي بأبعاد 10,000**.

## 9.1 المعمارية

مشابهة لمولد النصوص لكن بفروق جوهرية:

| الميزة | Text Generator | Corpus Learner |
|---|---|---|
| عدد الكلمات | 10 كلمات يدوية | >100 كلمة من الكوربوس |
| البعد N | 200 | **10,000** |
| متجهات الأساس | عشوائية خالصة | من computed_extended_phase_vector مرنان |
| مصفوفة K | كاملة O(N²) | **منخفضة الرتبة O(T·N)** |
| الكوربوس | جملتان | 100 جملة من `q (52) corpus.txt` |

## 9.2 تسريع الرتبة المنخفضة (Low-Rank Approximation)

بتخزين K كاملة، نحتاج N² = 10,000² = 100 مليون قيمة — هذا ثقيل. الحل: لأن K = (β/N)·Σ_t v_next_t · conj(v_curr_t)، يمكننا حساب الاقتران بدون بناء K كاملة:

```
لكل (v_curr, v_next) في الانتقالات:
    overlap = dot(v_curr, z)       # Σ conj(v_curr[j]) · z[j]
    coupling += (β/N · overlap) · v_next
```

هذا يختزل O(N²) إلى **O(T·N)** حيث T هي عدد الانتقالات (مئات لا غير). هذا هو مفتاح قابلية التوسع لـ PRNN: **التعليم منخفض الرتبة يعني أن التدريب والتوليد لا يتطلبان بناء مصفوفة كاملة أبداً**.

## 9.3 التكامل مع مرنان

```
v_real = MirnanNew.Physics.WordPhysics.compute_extended_phase_vector(word)
phases = v_real .* (√N · π)
base_vectors[word] = exp.(im .* phases)
```

المتجهات ليست عشوائية بل تأتي من متجهات الطور الحقيقية لمرنان. هذا يعني أن المسافة الطورية بين الكلمات تحمل معنى: الكلمات المتقاربة في المعنى لها أطوار متقاربة.

## 9.4 النتائج

نظام يعمل بكفاءة ويولد جملًا بناءً على أي كلمة بدء من الكوربوس. السرعة: توليد كلمة كل 40 خطوة محاكاة (بالمقارنة مع الخطوات العادية للـ RNN).

# 10. المحاكاة الكمية الموجية

`prnn_quantum_wave.jl` هو استراحة جميلة: ثلاث تجارب توضح القوانين الفيزيائية التي تجعل PRNN تعمل.

## 10.1 تجربة الشق المزدوج (Double-Slit)

31 مذبذباً في صف خطي. مصدران عند الثلثين يحقنان موجات بفارق طور π/2. المحاكاة تظهر **أهداب التداخل** — عقد تدميرية (تداخل هدام) وقمم بناءة (تداخل بناء). هذه هي بالضبط الظاهرة التي تحدث في PRNN عندما تلتقي الموجات من مدخلين مختلفين.

## 10.2 الإفناء الموجي (Wave Annihilation / NOT Gate)

مذبذبان مقترنان بقوة K=2. نبدأ بز₁ = ز₂ = 1 (طور متوافق ← بناء). فجأة نعكس ز₂ ← -ز₂ (نحقن النظير المعاكس — أي NOT gate). خلال 30 خطوة، تلاشى إجمالي الطاقة إلى الصفر تقريباً: `|z₁ + z₂| ≈ 10⁻⁷`. هذا هو **التداخل الهدام الكامل** — عندما تلتقي موجة بمثيلتها المعاكسة تماماً، تفنى الطاقة.

هذه هي آلية **النفي الطبيعية** في PRNN: عملية فيزيائية تلقائية، لا تحتاج لوزن خاص ولا لطبقة منفصلة.

## 10.3 التشابك والانهيار الطوري (Entanglement)

مذبذبان A و B مقترنان بقوة K=10. ضوضاء لانجفان تحاول زعزعة أطوارهما، لكن الاقتران القوي يحافظ على رابط الطور: φ_B ≈ φ_A + π (طور مضاد دائم — حالة سينغليت موجية).

عندما نثبت A عند طور قياس (مثلاً 1.25π)، ينهار B فوراً إلى الطور المتوقع φ_B = φ_A - π بفارق < 0.05 راديان. **قياس واحد يحدد حالة الآخر** — دون اتصال مباشر بينهما، فقط عبر الحقل المشترك.

هذا ليس تشابكاً كمياً حقيقياً، لكنه **تماثل حسابي** يظهر كيف يمكن لشبكة PRNN أن تنشر المعلومة عبر الحقل بدلاً من الأسلاك المباشرة.

# 11. البنشمارك: PRNN ضد N-Gram

`benchmark_prnn_vs_ngram.jl` يقارن PRNN (بُعد 10,000، تعلم هيبي هولوغرافي) مع N-Gram (Bigram + Laplace smoothing) على 1000 جملة من كوربوس مرنان.

### المقاييس:

| المقياس | N-Gram | PRNN |
|---|---|---|
| وقت التدريب | 4.645 مللي ثانية | 104.988 ثانية |
| الذاكرة | 142.6 KB | 216.3 MB |
| سرعة الاستدلال | 2.50 كلمة/مللي ثانية | 0.0009 كلمة/مللي ثانية |
| التكرار | 2.9% | 2.9% |
| صحة الانتقالات | **78.6%** | **95.2%** ← أكثر تماسكاً |
| التعميم | لا (يحتاج رؤية كل زوج أثناء التدريب) | نعم (فضاء طوري متصل) |

### التحليل:

N-Gram أسرع بعدة مراتب وأصغر حجماً — وهذا متوقع لأنه مجرد جدول إحصاء. لكنه لا يستطيع التوليد أبداً لزوج لم يره في التدريب (transition validity = 100% فقط لما رآه، وصفر لما لم يره). PRNN، بفضل فضاء الطور المستمر 10,000-البُعدي، يستطيع **التعميم**: حتى لو لم يرَ الانتقال (A→B) مسبقاً، فإن المسافة الطورية بين A و B قد تكون مشابهة لانتقال آخر رآه.

عندما تزيد البيانات (تخيل مليون جملة)، سيقترب PRNN من أداء N-Gram في السرعة (بفضل التسريع منخفض الرتبة) بينما يتفوق عليه في التماسك والتعميم.

# 12. الملخص: ماذا تعلمنا؟

## المسار من البسيط إلى المعقد:

```
مستوى 0 — معادلة كوراموتو: أطوار فقط، XOR بسيط
مستوى 1 — ستوارت-لانداو: سعة + طور، XOR أقوى + جدولة ضوضاء
مستوى 2 — الذاكرة الترابطية: أحواض جذب طورية، تخزين 2 نمط
مستوى 3 — الذاكرة المتسلسلة: كسر تناظر الزمن، دورات حدية A→B→C
مستوى 4 — الربط الهولوغرافي: VSA طوري، حل التفرع السياقي
مستوى 5 — مولد النصوص: 10 كلمات، ربط + فك + K غير متماثلة
مستوى 6 — متعلم الكوربوس: 100+ كلمة، 10,000 بُعد، تسريع رتبة منخفضة
مستوى 7 — بنشمارك: PRNN ضد N-Gram، إثبات التماسك الأعلى
```

## الركائز الأربع لـ PRNN:

1. **المذبذب المركب (Stuart-Landau):** كل عصبون هو `z = r·exp(i·φ)` مع ديناميكية سعة وطور مشتركة
2. **التعلم التبايني الهيبي (CHL):** تحديث محلي، لا مشتقات، يعمل أثناء المحاكاة
3. **الربط الهولوغرافي (VSA):** تمثيل السياق عبر ضرب المتجهات الطورية
4. **التثبيط + التعب:** آليات فيزيائية للتبديل بين الأنماط

## لماذا PRNN وليس Transformer؟

- PRNN **تتعلم محلياً** — تحتاج طاقة أقل ورقاقات (chips) أبسط
- PRNN **تتعمم في فضاء متصل** — ليست مجرد lookup table
- PRNN **مقاومة للضوضاء طبيعياً** — السعات المنخفضة تكتم تلقائياً
- PRNN يمكن تنفيذها **كدارات تماثلية** (راجع `prnn_xor_7osc.cir` — 7 مذبذبات فان دير بول في SPICE)
- مصفوفة K منخفضة الرتبة تجعل التوسع ممكناً
