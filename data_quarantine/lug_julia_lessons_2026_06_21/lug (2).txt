8. Constructors
عند كتابة:

julia نسخ

فهذا Constructor تلقائي.

يمكن إنشاء Constructor خاص.

مثال:

julia نسخ
struct Person

    name::String
    age::Int64

    function Person(name, age)

        age < 0 &&
            error("Age cannot be negative")

        new(name, age)

    end

end
الآن:

julia نسخ
Person("Ali",-5)
يعطي خطأ.

الدرس التاسع: Metaprogramming و Macros في Julia
هذا من أكثر المواضيع تميزاً في Julia.

الفكرة الأساسية:

في Julia يمكن للكود أن يتعامل مع الكود نفسه كبيانات.

أي أن البرنامج يستطيع:

إنشاء كود جديد.
تعديل كود موجود.
توليد دوال تلقائياً.
تحليل التعبيرات قبل تنفيذها.
1. الكود كبيانات
لنكتب:

julia نسخ
x = 10 + 20
نحن نراها عملية جمع.

لكن Julia تراها شجرة تعبير (Expression Tree).

إنشاء تعبير
julia نسخ
ex = :(10 + 20)
طباعة التعبير:

julia نسخ
println(ex)
الناتج:

text نسخ
10 + 20
معرفة النوع:

julia نسخ
typeof(ex)
الناتج:

text نسخ
Expr
2. التعبيرات Expr
يمكن فحص محتوياتها:

julia نسخ
ex = :(10 + 20)
الرأس:

julia نسخ
ex.head
الناتج:

text نسخ
:call
المعاملات:

julia نسخ
ex.args
الناتج تقريباً:

text نسخ
Any[:+,10,20]
أي:

text نسخ
+
10
20
3. تنفيذ تعبير
لدينا:

julia نسخ
ex = :(10 + 20)
تنفيذه:

julia نسخ
eval(ex)
الناتج:

text نسخ
30
4. الاقتباس Quote
julia نسخ
:(x + y)
يعني:

لا تنفذ.

بل خزّن التعبير.

يمكن كتابة:

julia نسخ
quote

    a = 10
    b = 20

    a + b

end
النوع:

julia نسخ
Expr
أيضاً.

7. ماذا يفعل Macro؟
الدالة:

julia نسخ

تعمل أثناء التنفيذ Runtime.

أما:

julia نسخ
@something
فيعمل أثناء التوسع Expansion.

أي قبل التنفيذ.

8. رؤية التوسع
julia نسخ
macro square(x)

    :( $x * $x )

end
الاستخدام:

julia نسخ
@square 5
الناتج:

text نسخ
25
لكن ماذا ولّد؟

julia نسخ
@macroexpand @square 5
الناتج:

julia نسخ
:(5 * 5)
هذه من أهم أدوات التعلم.

9. Macro مع التعبيرات
لدينا:

julia نسخ

يتوسع إلى:

julia نسخ
(3 + 2) * (3 + 2)
ثم ينفذ.

10. Macro للتتبع

        )

    end

end
الاستخدام:

julia نسخ

الناتج:

text نسخ

11. مثال احترافي
قياس الوقت.

julia نسخ
macro timer(ex)

    quote

        start = time()

        result = $ex

        elapsed =
            time() - start

        println(elapsed)

        result

    end

end
الاستخدام:

julia نسخ
@timer begin

    sleep(1)

end
يطبع الزمن المستغرق.

12. Hygiene
مشكلة مهمة.

لنكتب:

julia نسخ

    quote

        x = 100

    end

end
قد يتعارض مع:

julia نسخ

في البرنامج.

لهذا توفر Julia:

julia نسخ
esc(...)
مثال:

    esc(ex)

end
سنحتاج هذه الفكرة عند كتابة Macros احترافية.

14. متى نستخدم Macro؟
ليس لكل شيء.

إذا أمكن كتابة:

julia نسخ
function
أولاً.

استخدم Macro عندما تحتاج:

توليد كود.
إنشاء DSL.
تقليل التكرار الكبير.
فحص الكود قبل التنفيذ.
15. DSL
DSL = Domain Specific Language

مثال مشهور:

في مكتبة JuMP:

هذا ليس جزءاً من Julia نفسها.

بل Macro يحول هذه الصيغة إلى كود Julia عادي.

18. الفرق بين Function و Macro
الخاصية	Function	Macro
تعمل أثناء التنفيذ	نعم	لا
تستقبل القيم	نعم	لا
تستقبل التعبيرات	لا	نعم
تولد كوداً	لا	نعم
تستخدم بكثرة	نعم	أقل
مثال مهم
دالة:

julia نسخ
square(x)=x*x
تستقبل:

julia نسخ
5
أما:

julia نسخ
@square 5
فيستقبل:

julia نسخ
:(5)
كتعبير.

أهم قاعدة احترافية
استخدم:

julia نسخ
Function
في 95% من الحالات.

واستخدم:

julia نسخ
Macro
فقط عندما تحتاج فعلاً إلى معالجة الكود نفسه.

الدرس العاشر: الأداء (Performance) في Julia
هذا الدرس هو ما يجعل الكثير من العلماء والمهندسين يختارون Julia.

فالكود الصحيح في Julia يمكن أن يصل إلى سرعة قريبة جداً من C و C++ دون الحاجة لكتابة امتدادات خارجية.

لماذا تكون Julia سريعة؟
بشكل مبسط:

ترجمة JIT (Just-In-Time).
استنتاج الأنواع Type Inference.
Multiple Dispatch.
توليد كود آلة متخصص لكل نوع.
تحسينات LLVM.
1. أول تشغيل أبطأ من البقية
لنكتب:

julia نسخ

julia نسخ

5. Type Stability
هذه أهم قاعدة في الأداء.

مثال سيئ
julia نسخ
function bad(x)

    if x > 0
        return 1
    else
        return 1.0
    end

end
قد تعيد:

text نسخ
Int64
أو:

text نسخ
Float64
المترجم لا يستطيع معرفة النوع النهائي بسهولة.

مثال جيد
julia نسخ
function good(x)

    if x > 0
        return 1.0
    else
        return 1.0
    end

end
النوع دائماً:

text نسخ
Float64
فحص استقرار الأنواع
julia نسخ
@code_warntype good(5)
إذا رأيت:

text نسخ
Any
كثيراً،

فغالباً لديك مشكلة أداء.

8. التخصيص المسبق Preallocation
سيئ:

julia نسخ
function bad(n)

    v = []

    for i in 1:n
        push!(v, i)
    end

    v

end
كل Push قد يسبب إعادة تخصيص.

أفضل:

julia نسخ
function good(n)

    v = Vector{Int}(undef, n)

    for i in 1:n
        v[i] = i
    end

    v

end
أسرع بكثير.
