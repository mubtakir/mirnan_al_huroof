# تنسيق النصوص التدريبية — Training Text Format Rules
# ═══════════════════════════════════════════════════════════

# القاعدة 1: الجمل التامة
# الجملة التامة المعنى تنتهي بنقطة.
# Example: الملك حكم البلاد بحكمة.

# القاعدة 2: الجمل غير التامة
# الجملة غير التامة تنتهي بفاصلة،
# Example: الملك قوي وشجاع،

# القاعدة 3: الجمل المكملة
# الجمل المكملة لبعضها (سببية، تعليق) تنتهي بفاصلة منقوطة؛
# Example: جاء القائد؛ فنهض الجيش.

# القاعدة 4: جمل القول
# جمل القول تنتهي بنقطتين
# Example: قال الملك: افتحوا الأبواب

# القاعدة 5: علامات الترقيم ملاصقة
# كل علامة ترقيم (.,، ؛ : ! ?) ملاصقة للكلمة الأخيرة بدون مسافة
# WRONG: الملك جاء .
# RIGHT: الملك جاء.

# القاعدة 6: فاصل الفقرات
# سطر فارغ بين فقرة وفقرة
# ملاحظة: التدريب الافتراضي في train.jl هو مستوى الفقرة (:paragraph)،
# لذلك هذا السطر الفارغ هو حد تعليمي يمنع اقتران نهاية فقرة ببداية فقرة أخرى.

# القاعدة 7: تعريف الفقرة
# الفقرة = جملة واحدة أو أكثر، كل جملة تنتهي بعلامة ترقيم (. , ؛ :)

# القاعدة 8: فصل الحوار
# يُفصل بين طرفي الحوار بأحد these الأشكال:
#   a) Tab character بين سطر القول وسطر الجواب
#   b) كلمات سؤال: / جواب: / س: / ج:
# Example:
#   سأل الأمير: لماذا تبكي؟
#   	أجابت الأميرة: لأن أخي مريض.
# OR:
#   سؤال: لماذا تبكي؟
#   جواب: لأن أخي مريض.

# ═══════════════════════════════════════════════════════════
# مثال كامل
# ═══════════════════════════════════════════════════════════
# الملك قوي وشجاع؛ يحب شعبه.
# ذهب إلى القصر، وجلس على عرشه.
# سأل الوزير: أنت جاهز للحرب؟
# 	أجاب الملك: نعم، جاهز تماماً.
# الشمس تغرب، والقمر يطلع.
