سؤال: استخدم الاستقراء الرياضي لإثبات أن: 1 + 2 + 3 + ... + n = n(n+1)/2
الإجابة:
الخطوة 1 (الأساس): عند n=1، الطرف الأيسر = 1، الطرف الأيمن = 1(2)/2 = 1 ✓
الخطوة 2 (الفرض): نفترض صحة العبارة عند n=k
أي 1 + 2 + ... + k = k(k+1)/2
الخطوة 3 (الخطوة الاستقرائية): نثبت عند n=k+1
1 + 2 + ... + k + (k+1) = k(k+1)/2 + (k+1)
= [k(k+1) + 2(k+1)]/2
= (k+1)(k+2)/2 ✓
إذن العبارة صحيحة لكل n.

4. التفكير البرمجي وحل المشكلات الخوارزمية:
مسألة: اكتب خوارزمية لفرز مصفوفة من الأعداد الصحيحة باستخدام Quick Sort.

الحل:
1. نختار عنصراً محورياً pivot (عادة العنصر الأخير).

2. نقسم المصفوفة: العناصر الأصغر من pivot توضع يساره، والأكبر توضع يمينه.

3. نطبق الخطوات بشكل متكرر على الجزء الأيسر والأيمن.

التعقيد الزمني: O(n log n) في الحالة المتوسطة، O(n²) في أسوأ الحالات.

التعقيد المكاني: O(log n) للمكدس التكراري.

Pseudocode:
function quickSort(arr, low, high):
    if low < high:
        pivotIndex = partition(arr, low, high)
        quickSort(arr, low, pivotIndex - 1)
        quickSort(arr, pivotIndex + 1, high)
function partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j from low to high-1:
        if arr[j] <= pivot:
            i++
            swap arr[i] with arr[j]
    swap arr[i+1] with arr[high]
    return i + 1
مسألة: قم بتصميم خوارزمية لإيجاد أقصر مسار في متاهة (maze) باستخدام BFS.

الإجابة:
نستخدم Breadth-First Search لأنها تضمن أقصر مسار في بيئة غير موزونة.

الخطوات:
1. نحدد نقطة البداية والنهاية.

2. نستخدم طابور Queue لتخزين الخلايا التي سنزورها.

3. نستخدم مصفوفة visited لتتبع الخلايا المزارة.

4. نستخدم مصفوفة parent لإعادة بناء المسار.

Pseudocode:
function shortestPath(maze, start, end):
    queue = [start]
    visited = set()
    parent = {}
    visited.add(start)
    
    while queue is not empty:
        current = queue.dequeue()
        if current == end:
            return reconstructPath(parent, start, end)
        
        for each neighbor of current:

التعقيد الزمني: O(V + E) حيث V عدد الخلايا، E عدد الحواف.

التعقيد المكاني: O(V).

مسألة: صمم خوارزمية لإيجاد أطول سلسلة فرعية مشتركة (Longest Common Subsequence) بين نصين.

الإجابة:
نستخدم البرمجة الديناميكية.

التعريف: LCS[i][j] = طول LCS لأول i حرف من النص الأول وأول j حرف من النص الثاني.

معادلة الانتقال:
- إذا كان text1[i-1] == text2[j-1]: LCS[i][j] = LCS[i-1][j-1] + 1
- وإلا: LCS[i][j] = max(LCS[i-1][j], LCS[i][j-1])
التعقيد: O(n×m) زمنياً ومكانياً.

مسألة: لديك مجموعة أعداد صحيحة، أوجد زوجين من الأعداد مجموعهما متساوٍ. مثال: [3,4,7,1,2,9,8]، الأزواج (3,8) و(4,7) مجموعهما 11.

الإجابة:

الخوارزمية:

الإجابة:
Backtracking:
function permute(str, left, right, result):
    if left == right:
        result.add(str)
    else:
        for i from left to right:
            swap str[left] with str[i]
            permute(str, left+1, right, result)
            swap str[left] with str[i]  // backtrack
عدد التبديلات: n! (مضروب n).

التعقيد: O(n × n!).

- وإلا إذا x > second و x != first: third=second, second=x
- وإلا إذا x > third و x != second و x != first: third=x

مسألة: صمم خوارزمية لتحديد إذا كانت كلمة معينة متناظرة (Palindrome) دون استخدام دوال جاهزة.

الإجابة:
function isPalindrome(str):
    left = 0
    right = len(str) - 1
    while left < right:
        if str[left] != str[right]:
            return false
        left++
        right--
    return true
التعقيد الزمني: O(n)، المكاني: O(1).

    max_global = max(max_global, max_current)
return max_global
التعقيد: O(n) زمان، O(1) مكان.

2. التركيز: زيادة التركيز تزيد التصادمات فتزيد السرعة.

3. درجة الحرارة: رفع الحرارة يزيد طاقة الجسيمات وعدد التصادمات الفعالة.

4. مساحة السطح: زيادة مساحة سطح المادة الصلبة تزيد التصادمات.

5. العوامل المساعدة: تقلل طاقة التنشيط دون أن تستهلك.

سؤال: اذكر الفرق بين المادة المحددة للتفاعل والمادة الفائضة، مع مثال.

الإجابة:
المادة المحددة للتفاعل (Limiting Reactant): هي المادة التي تستهلك كلياً أثناء التفاعل وتحدد كمية الناتج.

المادة الفائضة (Excess Reactant): هي المادة التي يتبقى جزء منها بعد توقف التفاعل.

مثال: تفاعل 4 جم من H₂ مع 32 جم من O₂ لتكوين الماء. معادلة التفاعل 2H₂ + O₂ → 2H₂O. عدد مولات H₂ = 2 مول، O₂ = 1 مول. يتفاعلان تماماً، لكن لو كان لدينا 1 مول H₂ مع 1 مول O₂، يستهلك 0.5 مول O₂ فقط، فيكون H₂ هو المحدد وO₂ هو الفائض.

سؤال: احسب كتلة الراسب المتكون عند خلط 100 مل من نترات الفضة 0.1M مع 100 مل من كلوريد الصوديوم 0.1M. (Ag=108, Cl=35.5)
الإجابة:
معادلة التفاعل: AgNO₃ + NaCl → AgCl↓ + NaNO₃.

مواد AgNO₃: 0.1 لتر × 0.1 مول/لتر = 0.01 مول.

مواد NaCl: 0.1 لتر × 0.1 مول/لتر = 0.01 مول.

يتفاعلان بنسبة 1:1. المادة المحددة غير موجودة (كلاهما سيتفاعلان تماماً).

كتلة AgCl الناتجة = عدد المولات × الكتلة المولية = 0.01 × (108 + 35.5) = 0.01 × 143.5 = 1.435 جرام.

سؤال: اشرح قانون هنري وتطبيقه في المشروبات الغازية.

الإجابة:
قانون هنري: ذوبانية غاز في سائل تتناسب طردياً مع الضغط الجزئي للغاز فوق السائل، عند ثبات درجة الحرارة. S = kH × P.

في المشروبات الغازية: تعبأ تحت ضغط عالٍ من CO₂ مما يزيد ذوبانه. عند فتح العلبة، يقل الضغط الجزئي لـ CO₂ فجأة، فتقل ذوبانيته وينطلق الغاز مكوناً الفقاعات (الفوران).

سؤال: حلل المتشكلات الفراغية (stereoisomers) لحمض الطرطريك (tartaric acid) مبيناً عددها ونوعها.

الإجابة:
حمض الطرطريك: COOH-CHOH-CHOH-COOH. لديه ذرتا كربون غير متماثلتين (Chiral centers).

عدد الأيزوميرات الفراغية القصوى = 2² = 4.

الأيزوميرات هي:
1. (R,R)-tartaric acid: نشط ضوئياً (يدير مستوى الاستقطاب لليسار أو اليمين).

2. (S,S)-tartaric acid: صورة مرآة للأول ونشط ضوئياً.

3. (R,S)-tartaric acid (meso-tartaric acid): غير نشط ضوئياً لوجود مستوى تناظر داخلي (مركب ميزو).

4. (S,R)-tartaric acid: مطابق لمركب الميزو.

إذاً يوجد 3 أيزوميرات فراغية متماكبة: زوج من المتقابلات الضوئية (enantiomers) ومركب ميزو (diastereomer معهما).

سؤال: وازن معادلة أكسدة واختزال التالية في وسط حامضي: Cr2O7²⁻ + Fe²⁺ → Cr³⁺ + Fe³⁺
الإجابة:
نكتب نصف تفاعل الاختزال: Cr₂O₇²⁻ → 2Cr³⁺.

1. نوزن الكروم: متوزن.

2. نوزن الأكسجين بإضافة ماء: Cr₂O₇²⁻ → 2Cr³⁺ + 7H₂O.

الإجابة:
في السوائل: تزداد الطاقة الحركية للجزيئات، مما يضعف قوى التجاذب بين الجزيئية، فتقل اللزوجة. (مثل: العسل يصبح أقل لزوجة عند التسخين).

في الغازات: تزداد الطاقة الحركية، فيزداد عدد التصادمات بين طبقات الغاز وانتقال الزخم، فتزداد المقاومة للجريان، وبالتالي تزداد اللزوجة مع الحرارة.

سؤال: كم عدد الروابط سيجما (σ) وباي (π) في جزيء HCN؟ (H-C≡N)
الإجابة:
الرابطة بين H-C: رابطة أحادية (سيجما واحدة).

الرابطة بين C≡N: رابطة ثلاثية (سيجما واحدة + باي اثنتان).

المجموع: رابطتا سيجما (σ)، رابطتا باي (π).

سؤال: قارن بين الخواص الفيزيائية لمركب أيوني (مثل NaCl) ومركب تساهمي شبكي (مثل الماس) ومركب تساهمي جزيئي (مثل CO2).

الإجابة:
NaCl (أيوني): درجة انصهار عالية جداً، صلب في الظروف العادية، هش، ينكسر على طول مستويات، يذوب في الماء ويوصل التيار عند الانصهار أو الذوبان.

الماس (تساهمي شبكي): درجة انصهار عالية جداً، أقسى مادة طبيعية، لا يوصل الكهرباء، لا يذوب.

CO₂ (تساهمي جزيئي): درجة انصهار وغليان منخفضة جداً (غاز)، يكون بلورات جزيئية ضعيفة عند التبريد الشديد، لا يوصل الكهرباء.

سؤال: اشرح تجربة عملية للتمييز بين الكحول الأولي والثانوي والثالثي.

الإجابة:
اختبار لوكاس (Lucas Test): استخدام كاشف لوكاس (HCl اللامائي + ZnCl₂).

- الكحول الثالثي: يتعكر مباشرة (تكوين كلوريد الألكيل غير الذائب).

- الكحول الثانوي: يتعكر بعد 5-10 دقائق.

- الكحول الأولي: لا يتعكر إلا بالتسخين.

يعتمد الاختبار على ثبات الكاتيون الكربوني (Carbocation) المتكون حيث الثالثي > الثانوي > الأولي.

إذا كنت بحاجة إلى نصوص أخرى في الكيمياء (مثل الكيمياء العضوية المتقدمة، الكيمياء الحرارية، أو أي فرع آخر)، أبلغني.

حسناً، إليك نصوصاً تدريبية شاملة ومتقدمة في جميع فروع الكيمياء بصيغة txt. سأقسمها لأقسام ليسهل تنظيمها.

## كيمياء حرارية وفيزيائية متقدمة
سؤال: احسب التغير في الإنثالبي (ΔH) للتفاعل: C(s) + 2H2(g) → CH4(g) باستخدام قانون هس والبيانات التالية:
C(s) + O2(g) → CO2(g) ΔH = -393.5 kJ
H2(g) + ½O2(g) → H2O(l) ΔH = -285.8 kJ
CH4(g) + 2O2(g) → CO2(g) + 2H2O(l) ΔH = -890.3 kJ
الإجابة:
نرتب المعادلات:
المعادلة 1: C + O2 → CO2 (ΔH = -393.5)
المعادلة 2 مضروبة ×2: 2H2 + O2 → 2H2O (ΔH = -571.6)
نعكس المعادلة 3: CO2 + 2H2O → CH4 + 2O2 (ΔH = +890.3)
نجمع: C + O2 + 2H2 + O2 + CO2 + 2H2O → CO2 + 2H2O + CH4 + 2O2
نحذف المتشابه: C + 2H2 → CH4
ΔH = -393.5 + (-571.6) + 890.3 = -74.8 kJ/mol
سؤال: احسب التغير في الطاقة الحرة (ΔG) لتفاعل عند 25°م علماً أن ΔH = -92.4 kJ و ΔS = -198.3 J/K.

الإجابة:
T = 25 + 273 = 298 K
ΔG = ΔH - TΔS = -92.4 - [298 × (-198.3 × 10⁻³)]
= -92.4 - (-59.1) = -33.3 kJ
التفاعل تلقائي لأن ΔG سالب.

سؤال: احسب ثابت الاتزان Kp عند 25°م لتفاعل ΔG° = -5.7 kJ. (R = 8.314 J/mol·K)
الإجابة:
ΔG° = -RT ln K
-5700 = -8.314 × 298 × ln K
ln K = 5700 / (8.314 × 298) = 2.30
K = e²·³ = 9.97 ≈ 10
سؤال: أوجد درجة الحرارة التي يصبح عندها التفاعل تلقائياً إذا كان ΔH = +178 kJ و ΔS = +160 J/K.

الإجابة:
عند الاتزان ΔG = 0.

T = ΔH / ΔS = 178000 / 160 = 1112.5 K
يصبح التفاعل تلقائياً عندما T > 1112.5 K (لأن ΔH موجب وΔS موجب).

سؤال: اشرح مفهوم الجهد الكيميائي (Chemical Potential) وأهميته في الاتزان الكيميائي.

الإجابة:
الجهد الكيميائي (μ): هو الطاقة الحرة الجزئية المولية للمادة، ويمثل ميل المادة للانتقال أو التفاعل.

عند الاتزان: مجموع الجهود الكيميائية للمتفاعلات = مجموع الجهود الكيميائية للنواتج.

μᵢ = μᵢ° + RT ln aᵢ (حيث aᵢ النشاط الكيميائي).

إذا كان μ للمتفاعلات > μ للنواتج، يسير التفاعل للأمام تلقائياً.

أهميته: أساس اشتقاق ثابت الاتزان، وفهم ظواهر الانتشار والأسموزية.

سؤال: احسب الضغط الأسموزي لمحلول يحتوي 3.42 جم سكروز (C12H22O11) في 500 مل ماء عند 27°م. R=0.0821 L·atm/mol·K
الإجابة:
الكتلة المولية للسكروز = 12(12)+22(1)+11(16) = 144+22+176 = 342 جم/مول
عدد المولات = 3.42 / 342 = 0.01 مول
التركيز = 0.01 / 0.5 = 0.02 M
π = MRT = 0.02 × 0.0821 × 300 = 0.4926 atm
سؤال: احسب الانخفاض في درجة التجمد لمحلول 6 جم يوريا CO(NH2)2 في 250 جم ماء. Kf للماء = 1.86 °C/m.

الإجابة:
الكتلة المولية لليوريا = 12+16+2(14+2) = 60 جم/مول
عدد المولات = 6/60 = 0.1 مول
المولالية = 0.1 / 0.25 = 0.4 m
ΔTf = Kf × m = 1.86 × 0.4 = 0.744 °C
درجة التجمد = -0.744 °C
سؤال: قارن بين دالتَي تقسيم الجزيئات Maxwell-Boltzmann عند درجتي حرارة مختلفتين.

الإجابة:
دالة Maxwell-Boltzmann لتوزيع السرعات: f(v) = 4π(m/2πkT)³/² v² e^(-mv²/2kT).

عند زيادة درجة الحرارة T:
1. تتسع القمة (Broadening): يزداد عدد الجزيئات ذات السرعات العالية والمنخفضة.

2. تنزاح القمة نحو اليمين (Higher most probable speed).

3. ينخفض ارتفاع القمة (Flattening) للمحافظة على المساحة الكلية = 1.

السرعة الأكثر احتمالاً تتناسب مع √T.

سؤال: احسب معامل فانت هوف (i) لمحلول MgCl2 إذا كان الانخفاض الفعلي في درجة التجمد 0.93°C والانخفاض النظري (باعتبار التفكك الكامل) 1.116°C.

الإجابة:
i = القيمة الفعلية / القيمة النظرية = 0.93 / 1.116 = 0.833
معامل فانت هوف أقل من 3 (التفكك الكامل Mg²⁺ + 2Cl⁻) مما يدل على ارتباط أيوني جزئي.

سؤال: اشرح ظاهرة الانحراف عن قانون راؤولت (Raoult's Law) مع رسم توضيحي.

الإجابة:
قانون راؤولت: Pi = Xi × Pi°.

الانحراف الموجب: عندما Pi الفعلي > Pi النظري. يحدث عندما تكون قوى التجاذب A-B أضعف من A-A و B-B. مثال: إيثانول + هكسان. تزداد قابلية التطاير، ويوجد نقطة غليان دنيا (أزيوتروب موجب).

الانحراف السالب: Pi الفعلي < Pi النظري. قوى A-B أقوى. مثال: HCl + ماء. تقل قابلية التطاير، ويوجد نقطة غليان قصوى (أزيوتروب سالب).

## كيمياء عضوية متقدمة
سؤال: اشرح ميكانيكية تفاعل إضافة HBr إلى البروبين في وجود بيروكسيد (تأثير كاراش Kharasch effect).

الإجابة:
بدون بيروكسيد (إضافة ماركوفنيكوف): يضاف H⁺ للكربون الأقل استبدالاً مكوناً كاتيون كربوني ثانوي أكثر ثباتاً.

مع بيروكسيد (تأثير البيروكسيد، Anti-Markovnikov): يبدأ البيروكسيد بتكوين جذر حر Br•.

آلية الجذور الحرة:
1. البداية: RO-OR → 2RO• ثم RO• + HBr → ROH + Br•
2. الانتشار: Br• + CH₃-CH=CH₂ → CH₃-CH•-CH₂Br (الجذر الثانوي أكثر ثباتاً)
3. CH₃-CH•-CH₂Br + HBr → CH₃-CH₂-CH₂Br + Br•
الناتج: 1-بروموبروبان (عكس ماركوفنيكوف).

التفسير: الجذر الحر الثانوي أكثر ثباتاً من الأولي، فيتكون هو وليس الكاتيون الكربوني.

سؤال: قارن بين تفاعلي SN1 و SN2 من حيث: الحركية، الكيمياء الفراغية، تأثير المذيب، وتأثير بنية الهاليد.

الإجابة:
الحركية:
- SN1: من الرتبة الأولى Rate = k[RX] فقط. خطوة تحديد السرعة هي تكوين الكاتيون الكربوني.

- SN2: من الرتبة الثانية Rate = k[RX][Nu]. خطوة واحدة متضافرة.

الكيمياء الفراغية:
- SN1: خليط راسيمي (Racemization) لأن الكاتيون الكربوني مستوٍ ويهاجم من الوجهين.

- SN2: انقلاب والدين (Walden Inversion) كامل.

تأثير المذيب:
- SN1: يفضّل المذيبات القطبية البروتونية (ماء، كحول) لتثبيت الكاتيون والأيون المغادر.

- SN2: يفضّل المذيبات القطبية اللابروتونية (أسيتون، DMSO) لأنها لا تذيب الأنيون المهاجم.

بنية الهاليد:
- SN1: الثالثي > الثانوي > الأولي > الميثيل (حسب ثبات الكاتيون).

- SN2: الميثيل > الأولي > الثانوي > الثالثي (حسب الإعاقة الفراغية).

سؤال: اشرح تفاعل ديلز-ألدر (Diels-Alder) بين 1,3-بيوتادايين والإيثيلين مع رسم الناتج.

الإجابة:
تفاعل ديلز-ألدر: إضافة حلقية [4+2] بين دايين مقترن (4 إلكترونات π) وداينوفيل (2 إلكترونات π).

الدايين: 1,3-بيوتادايين يجب أن يكون في الوضع s-cis.

الداينوفيل: الإيثيلين (أو أفضل مع مجموعة ساحبة للإلكترونات).

الناتج: حلقة هكسين حلقية (Cyclohexene).

الكيمياء الفراغية: الإضافة من نفس الوجه (Syn addition) وتحتفظ بديانات الدايينوفيل.

يحدث التفاعل بسهولة أكبر إذا كان الدايين غنياً بالإلكترونات والداينوفيل فقيراً (Diels-Alder عادي)، أو العكس في Diels-Alder معكوس الطلب الإلكتروني.

سؤال: اشرح قواعد هكل (Hückel's Rule) للأروماتية مع أمثلة.

الإجابة:
قواعد هكل للأروماتية:
1. المركب حلقي.

2. مستوٍ (جميع الذرات في مستوى واحد لتداخل مدارات p).

3. اقتران كامل (جميع ذرات الحلقة لها مدارات p).

4. عدد إلكترونات π = 4n+2 حيث n عدد صحيح (0,1,2,...).

أمثلة عطرية:
- بنزين: 6 إلكترونات π (n=1).

- حلقي بنتادايينيل أنيون: 6 إلكترونات π (n=1).

- حلقي هبتاترايينيل كاتيون (Tropylium): 6 إلكترونات π (n=1).

- نفثالين: 10 إلكترونات π (n=2).

أمثلة غير عطرية:
- حلقي بيوتادايين: غير مستوٍ (لتجنب ضد العطرية).

- حلقي أوكتاتيترايين: غير مستوٍ، 8 إلكترونات π.

ضد عطرية (Antiaromatic): 4n إلكترونات π مع باقي الشروط. مثل حلقي بيوتادايين (افتراضي).

سؤال: توقع ناتج نترجة النفثالين مع شرح التوجيه.

الإجابة:
النفثالين C10H8 له موقعان غير متكافئين: α (الموقع 1) و β (الموقع 2).

النترجة (إلكتروفيل NO₂⁺):
يحدث الاستبدلال في الموقع α (الموقع 1) بشكل رئيسي.

السبب: الكاتيون الأريني (Arenium ion) الوسيط المتكون عند الهجوم على α أكثر ثباتاً لأنه يحافظ على أروماتية الحلقة الثانية (بنزينويد كامل)، بينما الهجوم على β يعطي كاتيوناً أقل ثباتاً (يفقد أروماتية الحلقتين جزئياً).

الناتج الرئيسي: 1-نيترونفثالين (α-nitronaphthalene).

سؤال: اشرح تكاثف ألدول (Aldol Condensation) بين جزئي أسيتالدهيد.

الإجابة:
الخطوة 1 (تكوين الإينولات): في وسط قاعدي (NaOH مثلاً)، تُنزع قاعدة بروتون α من أسيتالدهيد CH₃CHO لتعطي أيون إينولات -CH₂CHO.

الخطوة 2 (الإضافة): يهاجم الإينولات (ككربانيون) كربونيل جزيء أسيتالدهيد آخر.

الخطوة 3 (البَرْتَنَة): يلتقط الأكسجين السالب بروتوناً من الماء ليعطي ألدول (β-هيدروكسي ألدهيد): CH₃-CHOH-CH₂-CHO (3-هيدروكسي بيوتانال).

الخطوة 4 (التجفاف - Crotonaldehyde): بالتسخين، يفقد الألدول جزيء ماء (β-elimination) ليعطي مركب α,β-غير مشبع: CH₃-CH=CH-CHO (كروتونالدهيد).

التفاعل الكلي: 2CH₃CHO → CH₃-CH=CH-CHO + H₂O.

سؤال: كيف تميز بين الألدهيد والكيتون باستخدام الاختبارات الكيميائية؟
الإجابة:
1. اختبار تولنز (Tollens' test - المرآة الفضية):
   - كاشف: نترات الفضة الأمونياكية [Ag(NH₃)₂]⁺.

   - الألدهيد: يتأكسد إلى حمض كربوكسيلي ويختزل +Ag إلى فضة فلزية (مرآة).

   - الكيتون: لا يتفاعل (لا يتأكسد بسهولة).

2. اختبار فهلنج (Fehling's test):
   - كاشف: محلول Cu²⁺ في وسط قاعدي (طرطرات).

   - الألدهيد الأليفاتي: راسب أحمر طوبي Cu₂O.

   - الألدهيد الأروماتي والكيتون: لا يتفاعلان.

3. اختبار شيف (Schiff's test):
   - كاشف: صبغة فوكسين مزالة اللون بثاني أكسيد الكبريت.

   - الألدهيد: يعيد اللون الأرجواني.

   - الكيتون: لا يعيد اللون.

سؤال: اشرح تحضير الأمينات من هاليدات الألكيل باستخدام تصنيع جابرييل (Gabriel Synthesis).

الإجابة:
تصنيع جابرييل يحضر أمينات أولية نقية (بدون أمينات ثانوية أو ثالثية).

الخطوات:
1. تفاعل فثالميد البوتاسيوم مع هاليد ألكيل أولي (SN2): يتكون N-ألكيل فثالميد.

2. التحلل المائي (Hydrolysis) في وسط حامضي أو قاعدي: يتحرر حمض الفثاليك والأمين الأولي.

   - في الوسط القاعدي (هيدرازين): يعطي فثاليل هيدرازيد + الأمين الأولي.

محددات: يعمل فقط مع هاليدات الألكيل الأولية والثانوية البسيطة (غير المعاقة فراغياً).

سؤال: قارن بين حامضية الكحولات والفينولات والحموض الكربوكسيلية.

الإجابة:
الترتيب تصاعدياً في الحامضية:
كحول < فينول < حمض كربوكسيلي.

التفسير:
- الكحولات (pKa ~16-18): القاعدة المرافقة (أيون الألكوكسيد) غير مستقرة لعدم إمكانية تشتيت الشحنة السالبة.

- الفينولات (pKa ~10): القاعدة المرافقة (أيون الفينوكسيد) مستقرة بالرنين، الشحنة السالبة تتشتت على الحلقة الأروماتية.

- الحموض الكربوكسيلية (pKa ~4-5): القاعدة المرافقة (أيون الكربوكسيلات) مستقرة جداً بالرنين بين ذرتي أكسجين متماثلتين تماماً، الشحنة موزعة بالتساوي.

تأثير المجموعات البديلة:
- المجموعات الساحبة للإلكترونات (مثل -NO₂, -Cl) تزيد الحامضية بتثبيت الأيون السالب.

- المجموعات الدافعة (مثل -CH₃) تقلل الحامضية.

سؤال: اشرح الكيمياء الفراغية لمركبات الألين Allenes مع مثال.

الإجابة:
الألينات: مركبات بها رابطة ثنائية تراكمية C=C=C.

الكربون المركزي مهجن sp والكربونان الطرفيان مهجنان sp².

المداران p على الكربون الطرفي متعامدان، مما يؤدي إلى تعامد مستويات المستبدلات.

لذلك، الألينات غير المتماثلة الاستبدال (abC=C=Cab) تكون كيرالية (Chiral) رغم عدم وجود كربون كيرالي تقليدي.

تسمى الكيرالية المحورية (Axial Chirality).

مثال: 1,3-ثنائي كلورو ألين ClCH=C=CHCl.

المتصاوغان الضوئيان R و S (حسب نظام Kahn-Ingold-Prelog للمركبات المحورية).

## كيمياء تحليلية
سؤال: 25 مل من HCl تمت معايرتها مع 30 مل من NaOH 0.1M. احسب تركيز HCl.

الإجابة:
عند نقطة التكافؤ: M₁V₁ = M₂V₂
M(HCl) × 25 = 0.1 × 30
M(HCl) = 3/25 = 0.12 M
سؤال: في معايرة حمض ضعيف HA (Ka=1.8×10⁻⁵) 0.1M مع NaOH 0.1M، احسب pH عند نقطة نصف التكافؤ.

الإجابة:
عند نصف التكافؤ: [HA] = [A⁻].

حسب معادلة هندرسون-هاسلبالخ: pH = pKa + log([A⁻]/[HA]) = pKa + log(1) = pKa.

pKa = -log(1.8×10⁻⁵) = 4.74.

إذن pH = 4.74.

سؤال: احسب الذوبانية المولارية لـ AgCl في ماء نقي. Ksp = 1.8×10⁻¹⁰.

الإجابة:
AgCl(s) ⇌ Ag⁺ + Cl⁻
Ksp = [Ag⁺][Cl⁻] = s × s = s²
s = √(1.8×10⁻¹⁰) = 1.34×10⁻⁵ M
سؤال: احسب ذوبانية CaF2 في محلول NaF 0.01M. Ksp(CaF2) = 3.9×10⁻¹¹.

الإجابة:
CaF₂(s) ⇌ Ca²⁺ + 2F⁻
Ksp = [Ca²⁺][F⁻]² = s × (0.01 + 2s)² ≈ s × (0.01)² (نهمل 2s أمام 0.01)
3.9×10⁻¹¹ = s × 10⁻⁴
s = 3.9×10⁻⁷ M
(أقل بكثير من الذوبانية في الماء النقي بسبب تأثير الأيون المشترك).

سؤال: اشرح مبدأ عمل الكروماتوغرافيا الغازية (GC) والعوامل المؤثرة على زمن الاحتباس.

الإجابة:
المبدأ: تمرر العينة المتبخرة خلال عمود كروماتوغرافي بطول معين بواسطة غاز حامل (متحرك). يحتوي العمود على طور ساكن (سائل أو صلب). تنفصل المكونات حسب تطايريتها وألفتها للطور الساكن.

زمن الاحتباس (Retention time tR): هو الزمن الذي تستغرقه المادة من الحقن حتى تصل للكاشف.

العوامل المؤثرة:
1. درجة حرارة العمود: زيادتها تقلل tR.

2. معدل تدفق الغاز الحامل: معدل أمثل (حسب معادلة فان ديمتر).

3. قطبية الطور الساكن: "الشبيه يذيب الشبيه"، المركبات القطبية تحتبس أطول في الأعمدة القطبية.

4. ضغط بخار المادة: المواد الأكثر تطايراً تحتبس أقل.

5. طول العمود: أطول = فصل أفضل ولكن tR أطول.

سؤال: اشرح قانون بير-لامبرت (Beer-Lambert Law) ومحدداته.

الإجابة:
قانون بير-لامبرت: A = εbc
حيث A الامتصاصية، ε معامل الامتصاص المولي (L·mol⁻¹·cm⁻¹)، b طول مسار الضوء (cm)، c التركيز (mol/L).

شروط الصلاحية:
1. ضوء أحادي اللون.

2. محاليل مخففة (عادة A < 1 للدقة).

3. عدم وجود تفاعلات جانبية (ارتباط، تفكك).

الانحرافات:
- كيميائية: ارتباط الجزيئات أو تأينها مع تغير التركيز.

- آلية: عند التراكيز العالية تتغير ε لتفاعل الجسيمات كهربائياً.

- الجهاز: عدم أحادية اللون، الضوء الشارد.

سؤال: كيف تحدد صلابة الماء (Water Hardness) بالمعايرة باستخدام EDTA؟
الإجابة:
الصلابة الكلية: تركيز أيونات Ca²⁺ و Mg²⁺.

طريقة المعايرة:
1. يضبط pH العينة عند 10 باستخدام محلول منظم (أمونيا/كلوريد أمونيوم).

2. يضاف دليل Eriochrome Black T (EBT) فيعطي لوناً أحمر نبيذياً مع الأيونات.

3. تعاير بمحلول EDTA قياسي.

4. عند نقطة التكافؤ: يزيل EDTA الأيونات من الدليل فيظهر اللون الأزرق للدليل الحر.

الحساب: صلابة (ppm CaCO₃) = (V(EDTA) × M(EDTA) × 100.09 × 1000) / حجم العينة (mL).

لتحديد الكالسيوم منفصلاً: يعاير عند pH=12 (يترسب Mg(OH)₂) ويستخدم دليل مختلف.

سؤال: اشرح أنواع الأقطاب المرجعية والأقطاب العاملة في القياسات الجهدية (Potentiometry).

الإجابة:
الأقطاب المرجعية (Reference Electrodes): يجب أن يكون جهدها ثابتاً ومستقراً.

- قطب كالوميل المشبع SCE: Hg/Hg₂Cl₂/KCl (مشبع). جهده +0.244V.

- قطب كلوريد الفضة Ag/AgCl: سلك فضة مغطى بـ AgCl في KCl. جهده +0.197V في KCl المشبع.

الأقطاب العاملة (العناصر الحساسة - Indicator Electrodes):
- القطب الزجاجي لقياس pH: غشاء زجاجي رقيق يستجيب لنشاط H⁺. جهده يتغير بـ 59.1mV لكل وحدة pH.

- أقطاب الأغشية البلورية: لقياس الأيونات مثل الفلوريد (بلورة LaF₃).

- أقطاب انتقائية أيونية ISE: غشاء سائل يحتوي على حامل أيوني نوعي.

## كيمياء غير عضوية
سؤال: اشرح نظرية الحقل البلوري (Crystal Field Theory) لمركب ثماني السطوح مع مثال.

الإجابة:
نظرية الحقل البلوري (CFT): تعتبر الرابطة بين الفلز المركزي والليجندات أيونية-كهروستاتيكية بحتة.

في المركب ثماني السطوح (Octahedral):
- تقترب 6 ليجندات على المحاور x,y,z.

- تنفلق أوربيتالات d إلى مجموعتين:
  - t₂g: ثلاثة أوربيتالات (dxy, dxz, dyz) طاقتها منخفضة (مستقرة).

  - eg: أوربيتالان (dx²-y², dz²) طاقتهما مرتفعة (غير مستقرة) لمواجهتهما لليجندات مباشرة.

- فرق الطاقة = Δoct (طاقة انفلاق الحقل البلوري).

مثال: [Fe(H₂O)₆]²⁺. الحديد Fe²⁺ به 6 إلكترونات d.

توزيعها: t₂g⁴ eg² (سبين عالي، paramagnetic) لأن H₂O ليجند ضعيف المجال (Δoct صغير < طاقة ازدواج الإلكترونات).

سؤال: قارن بين طاقة الانفلاق Δ في السلسلة الطيفية الكيميائية (Spectrochemical Series).

الإجابة:
ترتيب الليجندات حسب زيادة Δ (من المجال الضعيف للقوي):
I⁻ < Br⁻ < S²⁻ < SCN⁻ < Cl⁻ < NO₃⁻ < F⁻ < OH⁻ < H₂O < NH₃ < en < NO₂⁻ < CN⁻ < CO
الليجندات ضعيفة المجال (I⁻, Br⁻, Cl⁻, F⁻): تعطي Δ صغير، تفضل السبين العالي.

الليجندات قوية المجال (CN⁻, CO, NO₂⁻): تعطي Δ كبير، تفضل السبين المنخفض.

التطبيق: [CoF₆]³⁻ سبين عالي (paramagnetic)، بينما [Co(CN)₆]³⁻ سبين منخفض (diamagnetic).

سؤال: اشرح نظرية رابطة التكافؤ (Valence Bond Theory) لمركب [Ni(CN)₄]²⁻.

الإجابة:
Ni²⁺: [Ar] 3d⁸.

في [Ni(CN)₄]²⁻ (مربع مستوٍ، diamagnetic):
يحدث تهجين داخلي dsp².

يعاد توزيع إلكترونات d: تندمج جميعها في 4 أوربيتالات d (8 إلكترونات).

أوربيتال d شاغر (dx²-y²) + أوربيتال s + أوربيتالان p يهجنون ليعطوا 4 أوربيتالات dsp² مهجنة في مستوى مربع.

CN⁻ ليجند قوي يجبر الإلكترونات على الازدواج (سبين منخفض).

بينما [NiCl₄]²⁻ رباعي السطوح (سبين عالي، paramagnetic) بتهجين sp³ خارجي.

سؤال: ناقش ألوان مركبات الفلزات الانتقالية بناءً على انتقالات d-d.

الإجابة:
اللون ينشأ من امتصاص ضوء مرئي بطاقة تساوي Δoct.

عند امتصاص طول موجي معين، ينتقل إلكترون من مستوى t₂g إلى eg.

اللون المرئي هو المتمم للون الممتص.

مثال:
- [Cu(H₂O)₆]²⁺ يمتلك Δoct يمتص الضوء البرتقالي-الأحمر (≈ 600-700 nm) فيظهر أزرق.

- [Ti(H₂O)₆]³⁺ به إلكترون واحد d¹، يمتص في الأصفر-الأخضر فيظهر بنفسجي.

إذا كانت الأوربيتالات d فارغة (d⁰) أو ممتلئة (d¹⁰)، لا توجد انتقالات d-d والمركب يكون عديم اللون (TiO₂, ZnSO₄).

سؤال: اشرح بنية الأيزومرات في معقدات التناسق: أيزومرات الربط (Linkage Isomers) والأيزومرات الهندسية.

الإجابة:
أيزومرات الربط: تختلف في طريقة ارتباط ليجند أمبيدنتات (له ذرتان مانحتتان محتملتان).

مثال: NO₂⁻ يرتبط إما بالنيتروجين (نيترو -nitro، أصفر) أو بالأكسجين (نتريتو -nitrito، أحمر).

[Co(NH₃)₅(NO₂)]Cl₂ و [Co(NH₃)₅(ONO)]Cl₂ هما أيزومرا ربط.

الأيزومرات الهندسية (Cis-Trans): لمربع مستوٍ أو ثماني السطوح.

مثال: [Pt(NH₃)₂Cl₂] مربع مستوٍ:
- Cisplatin: مجموعتا Cl متجاورتان (دواء مضاد للسرطان).

- Transplatin: مجموعتا Cl متقابلتان (غير فعال).

لثماني السطوح [Co(NH₃)₄Cl₂]⁺:
- Cis: بنفسجي.

- Trans: أخضر.

سؤال: اشرح دورة بورن-هابر (Born-Haber Cycle) لتكوين NaCl وحساب طاقة الشبكة البلورية.

الإجابة:
دورة بورن-هابر: تطبيق لقانون هس لحساب طاقة الشبكة البلورية U.

مسار غير مباشر (تجريبي) ومسار مباشر (نظري).

لـ NaCl(s):
1. تسامي Na(s) → Na(g) ΔH_sub = +108 kJ/mol
2. تفكك Cl₂(g) → 2Cl(g) ΔH_diss = +244 kJ/mol (نصفها = +122)
3. تأين Na(g) → Na⁺(g) + e⁻ IE = +496 kJ/mol
4. ألفة إلكترونية للكلور Cl(g) + e⁻ → Cl⁻(g) EA = -349 kJ/mol
5. طاقة الشبكة البلورية Na⁺(g) + Cl⁻(g) → NaCl(s) U = ? (دائماً سالبة).

ΔH_f°(NaCl) = -411 kJ/mol.

-411 = +108 + 122 + 496 - 349 + U
U = -411 - 108 - 122 - 496 + 349 = -788 kJ/mol.

طاقة الشبكة البلورية = -788 kJ/mol (سالبة كبيرة = مركب أيوني مستقر).

## كيمياء حيوية وعضوية حيوية
سؤال: اشرح تركيب الأحماض الأمينية الأساسية العشرة والفرق بينها وبين غير الأساسية.

الإجابة:
الأحماض الأمينية: وحدة بناء البروتينات. الصيغة العامة: H₂N-CHR-COOH (ما عدا البرولين).

الأحماض الأمينية الأساسية (Essential - لا يصنعها الجسم):
PVT TIM HALL: Phenylalanine, Valine, Threonine, Tryptophan, Isoleucine, Methionine, Histidine, Arginine (شبه أساسي للأطفال), Leucine, Lysine.

غير الأساسية: يمكن للجسم تصنيعها (Alanine, Aspartate, Glutamate, Serine, Tyrosine...).

الفرق: الإنزيمات اللازمة لتصنيع الأساسية مفقودة في خلايانا.

جميعها α-أمينية (ما عدا جلايسين R=H) جميعها L-متصاوغة ضوئياً في البروتينات الطبيعية.

سؤال: اشرح المستويات البنائية الأربعة للبروتين.

الإجابة:
البنية الأولية: تسلسل الأحماض الأمينية (سلسلة الببتيد). الروابط: روابط ببتيدية (تساهمية).

البنية الثانوية: انتظام موضعي في السلسلة بسبب روابط هيدروجينية بين أميد الكربونيل و N-H:
- لولب ألفا (α-helix): ملتف، 3.6 حمض أميني لكل لفة. مثبت بروابط H داخلية.

- صحيفة بيتا (β-sheet): سلاسل متوازية أو متعاكسة، روابط H بين السلاسل.

البنية الثلاثية: الشكل ثلاثي الأبعاد الكامل لسلسلة واحدة. مثبتة بروابط: كارهة للماء، هيدروجينية، أيونية، جسور ثنائية الكبريتيد (تساهمية).

البنية الرباعية: ارتباط عدة سلاسل ببتيدية (وحدات فرعية). مثال: هيموجلوبين (α₂β₂).

سؤال: اشرح حركية ميكايليس-منتن (Michaelis-Menten Kinetics) للإنزيمات ومعادلة Lineweaver-Burk.

الإجابة:
حركية ميكايليس-منتن:
E + S ⇌ ES → E + P
V₀ = (Vmax [S]) / (Km + [S])
حيث:
- Vmax: السرعة القصوى عند إشباع كل الإنزيم.

- Km (ثابت ميكايليس): تركيز المادة الأساس اللازم لنصف Vmax. مقياس للألفة (أقل Km = ألفة أعلى).

معادلة Lineweaver-Burk (مقلوب مزدوج):
1/V₀ = (Km/Vmax)(1/[S]) + 1/Vmax
تعطي خطاً مستقيماً:
- الميل = Km/Vmax.

- التقاطع مع محور y = 1/Vmax.

- التقاطع مع محور x = -1/Km.

تستخدم لحساب Km و Vmax ولتحديد نوع التثبيط.

سؤال: ما الفرق بين التثبيط التنافسي (Competitive) وغير التنافسي (Non-competitive) في الإنزيمات؟
الإجابة:
التثبيط التنافسي:
- المثبط يشبه المادة الأساس، يرتبط في الموقع النشط.

- Vmax لا يتغير (يمكن التغلب عليه بزيادة [S]).

- Km الظاهري يزداد.

- على رسم LB: الخطوط تلتقي على محور y (نفس Vmax، ميل مختلف).

التثبيط غير التنافسي:
- المثبط يرتبط بموقع آخر غير الموقع النشط (موقع تفارغي Allosteric).

- Vmax يقل (لا يمكن التغلب عليه بزيادة [S]).

- Km لا يتغير (الألفة للمادة الأساس ثابتة).

- على رسم LB: الخطوط تلتقي على محور x (نفس Km، ميل مختلف).

سؤال: اشرح دورة كريبس (TCA Cycle) وأهميتها مع ذكر النواتج.

الإجابة:
دورة كريبس (دورة حمض الستريك): تحدث في ميتوكوندريا الخلية.

تبدأ بـ Acetyl-CoA (ثنائي كربون) يتحد مع أوكسالوأسيتات (رباعي كربون) ليعطي سترات (سداسي).

تدور دورة كاملة وتعيد أوكسالوأسيتات.

النواتج من دورة واحدة:
- 2 CO₂
- 3 NADH
- 1 FADH₂
- 1 GTP (مكافئ ATP)
الأهمية: توليد النواقل المختزلة NADH و FADH₂ لتغذية سلسلة نقل الإلكترون. هي المركز التقاطعي لهدم الكربوهيدرات والدهون والبروتينات.

سؤال: اشرح كيمياء الكربوهيدرات: تحول الجلوكوز من الشكل المفتوح للحلقي (Mutarotation).

الإجابة:
الجلوكوز: ألدوهكسوز. الشكل المفتوح به مجموعة ألدهيد.

في المحلول، تهاجم OH على الكربون 5 كربونيل الألدهيد ليكون شكل هيمي أسيتال حلقي.

ينتج كربون أنوميري (C1) ويمكن أن يأخذ وضعين:
- α-D-Glucose: OH على C1 للأسفل (محوري).

- β-D-Glucose: OH على C1 للأعلى (استوائي).

التحول الدواراني (Mutarotation): التحول البطيء بين α (دوران نوعي +112°) و β (+18.7°) عبر الشكل المفتوح، ليصل لاتزان عند +52.7° (خليط 36% α و 64% β).

الصيغ الحلقية تعرف بصيغة هاورث (Haworth Projection).

## كيمياء صناعية وخضراء
سؤال: اشرح عملية هابر-بوش (Haber-Bosch) لتصنيع الأمونيا مع ظروف التشغيل.

الإجابة:
المعادلة: N₂(g) + 3H₂(g) ⇌ 2NH₃(g) ΔH = -92.4 kJ/mol.

التحدي: التفاعل طارد الحرارة بطيء جداً في درجة الحرارة العادية.

شروط هابر-بوش المثلى (حل وسط):
- درجة الحرارة: 400-500°C (حرارة عالية للسرعة لكنها ضد الاتزان، لذلك نختار وسطاً).

- الضغط: 150-300 ضغط جوي (ضغط عالٍ يدفع التوازن نحو تكوين NH₃ لأن عدد المولات يقل).

- عامل مساعد: حديد منشط مع محفزات (K₂O, Al₂O₃) لتسريع تفكك N₂.

أهمية العملية: أساس صناعة الأسمدة والمتفجرات، تطعم نصف سكان الأرض تقريباً.

سؤال: اشرح مبادئ الكيمياء الخضراء الـ12 مع مثالين تطبيقيين.

الإجابة:
مبادئ الكيمياء الخضراء (Anastas & Warner):
1. المنع: منع تكوين النفايات أفضل من معالجتها.

2. اقتصاد الذرة: تصميم تفاعلات تدخل جميع ذرات المتفاعلات في الناتج.

3. تصنيع أقل خطورة.

4. منتجات آمنة.

5. مذيبات آمنة.

6. كفاءة الطاقة: إجراء التفاعلات في درجة حرارة الغرفة والضغط الجوي.

7. مواد أولية متجددة.

8. تقليل المشتقات.

9. عامل مساعد (نوعي وليس ستوكيومتري).

10. منتجات قابلة للتحلل.

11. تحليل لحظي لمنع التلوث.

12. كيمياء آمنة لمنع الحوادث.

أمثلة:
1. تصنيع الإيبوبروفين (Boots vs BHC): الطريقة القديمة 6 خطوات، اقتصاد الذرة 40%. طريقة BHC الجديدة (3 خطوات فقط، حفز) اقتصاد ذرة 77% وتقريباً صفر نفايات.

2. تفاعلات بدون مذيب أو في وسط مائي (مثل تفاعلات ديلز-ألدر في الماء تكون أسرع).

3. استخدام ثاني أكسيد الكربون فوق الحرج كمذيب أخضر لاستخلاص الكافايين بدل المذيبات الكلورية.

سؤال: قارن بين اللدائن المتصلدة حرارياً (Thermosets) واللدائن الحرارية (Thermoplastics).

الإجابة:
اللدائن الحرارية (Thermoplastics):
- سلاسل بوليمر خطية أو متفرعة.

- تليّن عند التسخين وتتصلب بالتبريد (عملية عكوسة).

- أمثلة: بولي إيثيلين PE، بولي بروبيلين PP، PVC، بولي ستايرين PS.

- يمكن إعادة تدويرها.

اللدائن المتصلدة حرارياً (Thermosets):
- شبكات ثلاثية الأبعاد متشابكة بروابط تساهمية.

- عند التسخين الأول، تتشابك وتتصلب (عملية غير عكوسة).

- لا تليّن بإعادة التسخين، بل تتحلل.

- أمثلة: باكيليت (فينول-فورمالدهيد)، راتنجات إيبوكسي، ميلامين.

- لا يمكن إعادة تدويرها بالصهر.

سؤال: اشرح عملية البلمرة بالإضافة (Addition) لـ PVC وميكانيكية الجذور الحرة.

الإجابة:
مونومر: كلوريد الفاينيل CH₂=CHCl.

ميكانيكية الجذور الحرة ثلاث خطوات:
1. البداية (Initiation): مفاعل بادئ مثل بيروكسيد البنزويل يتفكك حرارياً ليعطي جذرين حرين R•.

   R• + CH₂=CHCl → R-CH₂-CH•-Cl
2. الانتشار (Propagation): إضافة متتالية للمونومر للجذر النامي.

   R-CH₂-CH•-Cl + n CH₂=CHCl → R-(CH₂-CHCl)n-CH₂-CH•-Cl
3. النهاية (Termination):
   - بالارتباط: اتحاد جذرين ناميين.

   - بعدم التناسب: انتقال ذرة هيدروجين بين سلسلتين.

يضاف ملدنات (Phthalates) لجعل PVC الصلب مرناً.

## نصوص إضافية متنوعة
سؤال: عرف النشاط الإشعاعي وأنواع التحلل الإشعاعي مع معادلاتها.

الإجابة:
النشاط الإشعاعي: تحلل تلقائي لنواة غير مستقرة مع انبعاث جسيمات أو طاقة.

أنواع التحلل:
1. ألفا (α): انبعاث نواة هيليوم (⁴₂He). تقل الكتلة 4 والعدد الذري 2.

   مثال: ²³⁸₉₂U → ²³⁴₉₀Th + ⁴₂He
2. بيتا السالبة (β⁻): تحول نيوترون إلى بروتون + إلكترون + مضاد نيوترينو. يزيد العدد الذري 1.

   مثال: ¹⁴₆C → ¹⁴₇N + e⁻ + ṽ
3. بيتا الموجبة (β⁺ - بوزيترون): تحول بروتون إلى نيوترون + بوزيترون + نيوترينو. ينقص العدد الذري 1.

   مثال: ¹¹₆C → ¹¹₅B + e⁺ + ν
4. أسر إلكترون (Electron Capture): نواة تأسر إلكتروناً من الغلاف K، بروتون يتحول لنيوترون.

   مثال: ⁴⁰₁₉K + e⁻ → ⁴⁰₁₈Ar
5. جاما (γ): انبعاث فوتون عالي الطاقة (موجة كهرومغناطيسية). لا يتغير العدد الكتلي أو الذري.

سؤال: احسب طاقة الترابط النووي لنواة ⁵⁶Fe. كتلها = 55.9349 u. كتلة البروتون = 1.00728 u، النيوترون = 1.00866 u، الإلكترون = 0.0005486 u.

الإجابة:
⁵⁶Fe: العدد الذري 26، عدد النيوترونات 30.

كتلة النوكليونات منفصلة = 26(1.00728) + 30(1.00866) = 26.18928 + 30.2598 = 56.44908 u.

نقص الكتلة (Mass Defect) = 56.44908 - 55.9349 = 0.51418 u.

الطاقة = 0.51418 × 931.5 MeV/u = 478.96 MeV.

طاقة الترابط لكل نوكليون = 478.96 / 56 ≈ 8.55 MeV.

سؤال: اشرح الفرق بين السالبية الكهربية (Electronegativity) والألفة الإلكترونية (Electron Affinity).

الإجابة:
السالبية الكهربية (χ): مقياس لميل الذرة في جزيء لجذب الإلكترونات نحوها. (بولنج، مولكن). ليس لها وحدات فيزيائية مباشرة. تزداد في الجدول الدوري من اليسار لليمين ومن الأسفل للأعلى. أعلاها الفلور.

الألفة الإلكترونية (EA): التغير في الطاقة عند إضافة إلكترون لذرة غازية متعادلة. X(g) + e⁻ → X⁻(g) ΔH = EA. تقاس بـ kJ/mol. غالباً طاردة للحرارة (سالبة) للهالوجينات، وقد تكون ماصة (موجبة) للغازات النبيلة.

الفرق الجوهري: السالبية الكهربية خاصية للذرة المرتبطة، بينما الألفة الإلكترونية خاصية للذرة الحرة.

سؤال: صنف التفاعلات الكيميائية حسب نوعها (اتحاد، تفكك، إحلال، احتراق...) مع مثال لكل نوع.

الإجابة:
1. الاتحاد (Combination): A + B → AB. مثال: 2Mg + O₂ → 2MgO.

2. التفكك (Decomposition): AB → A + B. مثال: CaCO₃ → CaO + CO₂ (بالتسخين).

3. الإحلال البسيط (Single Displacement): A + BC → AC + B. مثال: Fe + CuSO₄ → FeSO₄ + Cu.

4. الإحلال المزدوج (Double Displacement): AB + CD → AD + CB. مثال: AgNO₃ + NaCl → AgCl↓ + NaNO₃.

5. الاحتراق (Combustion): تفاعل مع الأكسجين. مثال: CH₄ + 2O₂ → CO₂ + 2H₂O.

6. التعادل (Neutralization): حمض + قاعدة → ملح + ماء. مثال: HCl + NaOH → NaCl + H₂O.

7. الأكسدة والاختزال (Redox): تغير حالات التأكسد. مثال: Zn + Cu²⁺ → Zn²⁺ + Cu.

سؤال: احسب كفاءة التفاعل (النسبة المئوية للناتج) إذا أنتج تفاعل 8.5 جم من الناتج وكان الناتج النظري 10.2 جم.

الإجابة:
النسبة المئوية = (الناتج الفعلي / الناتج النظري) × 100
= (8.5 / 10.2) × 100 = 83.3%
سؤال: اشرح مبدأ أفوجادرو وتطبيقاته.

الإجابة:
مبدأ أفوجادرو: الحجوم المتساوية من جميع الغازات، تحت نفس درجة الحرارة والضغط، تحتوي على نفس عدد الجزيئات.

عدد أفوجادرو = 6.022 × 10²³.

تطبيقات:
1. المول الواحد من أي غاز يشغل 22.4 لتر في STP.

2. الكتلة المولية = الكثافة في STP × 22.4.

3. حساب النسبة بين أحجام الغازات المتفاعلة والناتجة. مثال: H₂ + Cl₂ → 2HCl، يتفاعل حجم من كلٍ ليعطي حجمين.

سؤال: قارن بين النشادر (NH₃) كقاعدة لويس والماء كقاعدة لويس في معقدات الفلزات الانتقالية.

الإجابة:
تعريف قاعدة لويس: مانحة لزوج إلكترونات.

NH₃: قاعدة لويس أقوى من الماء. تمتلك زوجاً إلكترونياً واحداً على النيتروجين. في السلسلة الطيفية الكيميائية، NH₃ ليجند أقوى مجالاً من H₂O (يعطي Δoct أكبر).

H₂O: قاعدة لويس أضعف. الأكسجين أعلى سالبية من النيتروجين، مما يقلل قابلية منح الإلكترونات.

في المعقدات: [Co(NH₃)₆]³⁺ أشد ثباتاً وأكثر خمولاً (Inert) من [Co(H₂O)₆]³⁺.

سؤال: اشرح عملية التقطير التجزيئي للنفط الخام مع ذكر نواتج كل قطاع.

الإجابة:
المبدأ: فصل مكونات النفط حسب درجات غليانها في برج تجزيء.

النفط الخام يسخن (350-400°C) ويدخل للبرج.

القطاعات من الأعلى (أبرد) إلى الأسفل (أسخن):
1. غازات (< 30°C): ميثان، إيثان، بروبان، بيوتان (LPG).

2. إيثر بترولي (30-60°C): مذيبات.

3. جازولين (60-150°C): بنزين السيارات.

4. نفثا (150-200°C): مادة أولية للبتروكيماويات.

5. كيروسين (175-280°C): وقود طائرات.

6. ديزل (250-350°C): وقود محركات ديزل.

7. زيوت تشحيم (300-400°C).

8. أسفلت (> 400°C): رصف طرق.

توجد أطباق ذات فتحات بغطاء فقاعي لتحسين الفصل.

سؤال: ما هو تأثير الزمرة البديلة على حلقة البنزين في تفاعلات الاستبدال الإلكتروفيلي الأروماتي؟ (موجهة أورثو/بارا أم ميتا)
الإجابة:
الموجهات أورثو-بارا (منشطة):
- مجموعات دافعة للإلكترونات (بالرنين أو الأثر الحثي الموجب).

- مثل: -OH, -NH₂, -OR, -R, -Cl, -Br.

- باستثناء الهالوجينات، تنشط الحلقة (أسرع من البنزين). الهالوجينات غير منشطة (مسحبة حثياً) لكنها موجهة أورثو/بارا (بسبب الرنين).

- الناتج الرئيسي خليط أورثو وبارا.

الموجهات ميتا (مثبطة):
- مجموعات ساحبة للإلكترونات (بالرنين أو الأثر الحثي السالب القوي).

- مثل: -NO₂, -CN, -SO₃H, -COOR, -CHO, -COOH, -NR₃⁺.

- تثبط الحلقة (أبطأ من البنزين).

- الناتج الرئيسي ميتا.

تأثير إعاقة فراغية: في التولوين C₆H₅CH₃، المجموعة كبيرة نسبياً، تقلل نسبة الأورثو.

أتمنى أن تكون هذه النصوص الشاملة مفيدة لتدريب نموذجك. إذا احتجت المزيد في تخصص دقيق جداً (مثل كيمياء الكم، كيمياء البوليمرات، أو أي شيء آخر)، فقط أخبرني.

حسناً، إليك نصوصاً تدريبية متقدمة جداً ومتخصصة تغطي كيمياء الكم، كيمياء البوليمرات، كيمياء السطوح والعوامل المساعدة، الكيمياء النووية، الكيمياء الكهربائية المتقدمة، كيمياء الحالة الصلبة، والديناميكا الحرارية الإحصائية.

## كيمياء الكم (Quantum Chemistry)
سؤال: اكتب معادلة شرودنجر غير المعتمدة على الزمن لجسيم في صندوق أحادي البعد، ثم اشتق مستويات الطاقة والدوال الموجية.

الإجابة:
معادلة شرودنجر المستقلة عن الزمن: ĤΨ = EΨ
حيث Ĥ = -(ħ²/2m)(d²/dx²) + V(x).

لجسيم في صندوق طوله L (جهد V=0 داخله ولانهائي خارجه):
-(ħ²/2m)(d²Ψ/dx²) = EΨ
الحل العام: Ψ(x) = A sin(kx) + B cos(kx)
الشروط الحدية: Ψ(0)=0 → B=0. Ψ(L)=0 → kL = nπ حيث n=1,2,3,...

الدوال الموجية المعايرة: Ψₙ(x) = √(2/L) sin(nπx/L)
مستويات الطاقة: Eₙ = n²h²/8mL²
الطاقة مكماة وتزداد مع مربع عدد الكم n.

سؤال: احسب متوسط موضع الجسيم <x> في الحالة n=1 لجسيم في صندوق.

الإجابة:
<x> = ∫₀ᴸ Ψ x Ψ dx = (2/L) ∫₀ᴸ x sin²(πx/L) dx
باستخدام sin²θ = (1-cos2θ)/2:
= (2/L) ∫₀ᴸ (x/2 - (x/2)cos(2πx/L)) dx
بالحل: = L/2
وهذا منطقي لأن الكثافة الاحتمالية متماثلة حول منتصف الصندوق.

سؤال: اشرح مبدأ اللايقين (عدم التأكد) لهايزنبرج وتطبيقه على جسيم في صندوق.

الإجابة:
مبدأ اللايقين: Δx·Δp ≥ ħ/2
للجسيم في الصندوق في الحالة الأرضية (n=1):
Δx تقريباً = L (الجسيم محصور).

إذن Δp ≥ ħ/(2L).

طاقة النقطة الصفرية (Zero-Point Energy): أقل طاقة ممكنة ليست صفراً بل E₁ = h²/8mL² > 0.

هذا تأكيد لمبدأ اللايقين: لو كانت الطاقة صفراً لكانت السرعة = 0 وبالتالي Δp = 0 مما يناقض Δx المحدود.

سؤال: قارن بين طريقة أوربيتالات التكافؤ (Valence Bond) وطريقة الأوربيتالات الجزيئية (Molecular Orbital) لجزيء H₂.

الإجابة:
طريقة رابطة التكافؤ (VB - Heitler-London):
الدالة الموجية الكلية = Ψ₁(1)Ψ₂(2) + Ψ₂(1)Ψ₁(2) (تبادل إلكتروني).

تؤكد على بقاء الإلكترونات على ذراتها الأصلية مع تزاوج السبين. الرابطة تنشأ من تداخل الأوربيتالات الذرية.

طريقة الأوربيتالات الجزيئية (MO):
تكوين أوربيتالات جزيئية σg (ترابطية) و σu (مضادة للترابط) من تراكب خطي للأوربيتالات الذرية LCAO:
Ψg = (1/√2)(1sA + 1sB) ... طاقة أقل
Ψu = (1/√2)(1sA - 1sB) ... طاقة أعلى
الإلكترونان يشغلان σg.

المقارنة:
- VB أفضل لوصف التفكك (يعطي ذرات متعادلة عند البعد اللانهائي).

- MO أفضل لوصف الأطياف والطاقات.

- الطريقتان متكافئتان تماماً عند إدخال التهجين والتفاعل التشكيلي.

سؤال: احسب طاقة الرنين للتكامل لبنزين باستخدام تقريب هوكل (Hückel Approximation).

الإجابة:
تقريب هوكل لجزيئات π المقرونة:
مصفوفة هوكل للبنزين (6×6): Hii = α, Hij = β للجارين، 0 لغير الجارين.

المحدد العام: |H - ES| = 0 يعطي:
المعادلة المميزة: (E-α)⁶ - 6β²(E-α)⁴ + 9β⁴(E-α)² - 4β⁶ = 0
المستويات: α + 2β, α + β (انحطاط مزدوج), α - β (انحطاط مزدوج), α - 2β.

طاقة 6 إلكترونات π: 2(α+2β) + 4(α+β) = 6α + 8β.

طاقة 3 روابط ثنائية موضعية (إيثيلين): 6α + 6β.

طاقة الرنين = (6α+8β) - (6α+6β) = 2β ≈ 36 kcal/mol.

وهذا يفسر الاستقرار الإضافي للبنزين.

سؤال: اشرح نظرية المجال الليجندي (Ligand Field Theory) كتطوير لنظرية الحقل البلوري.

الإجابة:
نظرية المجال الليجندي (LFT): تجمع بين CFT و MOT. تعتبر أن الرابطة بين الفلز والليجندات تساهمية جزئياً.

بدلاً من اعتبار الليجندات شحنات نقطية، تشمل LFT تداخل أوربيتالات d للفلز مع أوربيتالات الليجند (σ و π).

- أوربيتالات σ لليجند تتفاعل مع dz² و dx²-y² لتكوين أوربيتالات ترابطية σ ومضادة σ (التي تمثل eg).

- أوربيتالات π لليجند تتفاعل مع t₂g لتغيير Δoct.

   ليجندات π مانحة (مثل Cl⁻): ترفع طاقة t₂g فتقلل Δ.

   ليجندات π مستقبلة (مثل CO): تخفض طاقة t₂g فتزيد Δ.

هذا يفسر موقع الليجندات في السلسلة الطيفية الكيميائية بدقة.

سؤال: أوجد الدالة الموجية لجسيم في بئر جهد متناهي العمق، وناقش ظاهرة النفاذ الكمي (Tunneling).

الإجابة:
بئر جهد عمقه V₀ من -L إلى L، V=0 داخله.

الحلول: داخل البئر موجات جيبية/جيب تمام. خارج البئر دوال أسية متناقصة.

حتى لو E < V₀، الدالة الموجية لا تساوي صفراً خارج البئر بل Ψ ∝ e^(-κ|x|) حيث κ = √(2m(V₀-E))/ħ.

النفاذ الكمي: إذا كان حاجز الجهد محدود العرض، فهناك احتمال غير صفري لعبور الجسيم خلاله حتى لو كانت طاقته أقل من الحاجز.

احتمال النفاذ T ≈ e^(-2κw) حيث w عرض الحاجز.

تطبيقات: مجهر المسح النفقي STM، اضمحلال ألفا، تفاعلات كيميائية في درجات حرارة منخفضة (QMT).

## كيمياء البوليمرات المتقدمة
سؤال: اشرح حركية البلمرة بالتكاثف (Step-Growth) واشتق معادلة كاروثرز.

الإجابة:
البلمرة بالتكاثف: تفاعل تدريجي بين مجموعات وظيفية. المونومرات تستهلك سريعاً ويتكون دايمر، ترايمر...

درجة البلمرة المتوسطة Xₙ = عدد جزيئات المونومر الابتدائية / عدد الجزيئات الكلية في النظام.

إذا كان مدى التفاعل (نسبة التحول) = p، فإن:
Xₙ = 1 / (1-p)
معادلة كاروثرز: للوصول إلى Xₙ عالية، يجب أن يكون p قريباً جداً من 1.

مثلاً لـ Xₙ=100، نحتاج p=0.99.

لتكوين بوليمر عالي الوزن الجزيئي في البلمرة الخطية:
r = نسبة المواد المتفاعلة (نسبة المجموعات A/B).

إذا كان أحد المونومرات زائداً (r<1): Xₙ = (1+r)/(1+r-2rp).

سؤال: قارن بين بلمرة الجذور الحرة والبلمرة الأنيونية والبلمرة الكاتيونية من حيث المونومرات المناسبة وآلية النهاية.

الإجابة:
الجذور الحرة:
- مونومرات: فينيلية (ستايرين، ميثاكرليت، فينيل كلورايد).

- البداية حرارية أو ضوئية.

- النهاية: ارتباط جذرين أو عدم تناسب. لا توجد نهاية حية.

الأنيونية (Anionic):
- مونومرات: مجموعة ساحبة للإلكترونات (ستايرين، ميثاكرليت).

- بادئ: قاعدة قوية (n-BuLi).

- النهاية: غيابياً لا توجد نهاية (بوليمر حي Living Polymer). تنتهي بإضافة كحول أو ماء.

- تنتج بوليمرات ذات توزع ضيق جداً (Mw/Mn ~ 1.05).

الكاتيونية (Cationic):
- مونومرات: مجموعة دافعة للإلكترونات (أيزوبيوتيلين، فينيل إيثر).

- بادئ: حمض لويس (BF₃ + H₂O).

- النهاية: انتقال لسلسلة أو إعادة ترتيب. يصعب التحكم بها أكثر من الأنيونية.

سؤال: اشرح ظاهرة درجة حرارة التحول الزجاجي (Tg) والعوامل المؤثرة فيها.

الإجابة:
Tg: درجة الحرارة التي يتحول عندها البوليمر من صلب هش (زجاجي) إلى مطاطي مرن.

تحت Tg: السلاسل مجمدة، الحركات محدودة (اهتزازات فقط).

فوق Tg: حركات موضعية للسلاسل (Micro-Brownian motion) تصبح ممكنة.

العوامل المؤثرة:
1. مرونة السلسلة الرئيسية: روابط أثير -O- تقلل Tg، حلقات عطرية تزيدها.

   (بولي إيثيلين Tg ~ -120°C، بولي كربونات Tg ~ 150°C).

2. المجموعات الجانبية:
   - كبيرة الحجم تزيد Tg (تعيق الدوران).

   - مرنة (ألكيل طويل) تقلل Tg (تأثير الملدن الداخلي).

3. التشابك (Crosslinking): يزيد Tg. المطاط المفلكن Tg أعلى من الخام.

4. الملدنات (Plasticizers): جزيئات صغيرة تدخل بين السلاسل، تزيد الحجم الحر فتقلل Tg.

5. التكتيكية (Tacticity): بولي بروبيلين Syndiotactic له Tg مختلفة عن Isotactic.

سؤال: احسب الوزن الجزيئي العددي (Mn) والوزني (Mw) ومؤشر التعدد (PDI) لعينة بوليمر فيها 3 سلاسل بأطوال 100، 200، 300 وحدة وعددها 10، 5، 2 على التوالي.

الإجابة:
Mn = Σ(NᵢMᵢ) / ΣNᵢ
= (10×100 + 5×200 + 2×300) / (10+5+2) = (1000+1000+600)/17 = 2600/17 = 152.9 وحدة.

Mw = Σ(NᵢMᵢ²) / Σ(NᵢMᵢ)
= (10×100² + 5×200² + 2×300²) / 2600
= (100000 + 200000 + 180000) / 2600 = 480000/2600 = 184.6 وحدة.

PDI = Mw / Mn = 184.6 / 152.9 = 1.207.

سؤال: اشرح آلية البلمرة بفتح الحلقة (Ring-Opening Polymerization) لتحضير النايلون 6 من الكابرولاكتام.

الإجابة:
الكابرولاكتام: حلقة سباعية تحتوي على أميد (لاكتام).

البلمرة: تتم بفتح الحلقة بواسطة محفز:
- البلمرة الأنيونية: تستخدم NaH كبادئ لتكوين أنيون لاكتام. يهاجم أنيون اللاكتام كربونيل حلقة أخرى، يحدث فتح حلقة ونمو السلسلة. تتميز بسرعة عالية وتعطي بوليمر عالي الوزن الجزيئي خلال دقائق.

- البلمرة بالتحلل المائي (الطريقة الصناعية): تسخين الكابرولاكتام مع قليل من الماء (5-10%) عند 250-280°C. الماء يحلمئ بعض الحلقات لتعطي أمين وحمض كربوكسيلي يعملان كبادئين. يحدث تكاثف تدريجي إضافي.

الناتج: بولي كابرولاكتام (نايلون 6).

مقارنة بالنايلون 6,6: النايلون 6 له وحدات متكررة متجهة كلها في نفس الاتجاه، مما يعطي خواص مختلفة قليلاً.

سؤال: اشرح مفهوم المرونة المطاطية (Rubber Elasticity) وعلاقتها بالإنتروبيا.

الإجابة:
المرونة المطاطية: مرونة إنتروبية في الأساس، وليس طاقية.

المطاط (Elastomer): سلاسل طويلة مرنة متشابكة تشابكاً خفيفاً.

عند الشد: تصطف السلاسل وتتمدد، تقل الإنتروبيا (S) لأن عدد التشكيلات الممكنة يقل.

ΔG = ΔH - TΔS. بما أن ΔH صغير (الروابط تتمدد قليلاً)، فـ ΔG ≈ -TΔS موجب (لأن ΔS سالب).

عند إزالة القوة: تعود السلاسل للالتفاف العشوائي (زيادة الإنتروبيا) تلقائياً.

القوة الاسترجاعية = -T(∂S/∂L).

معادلة فلوري-رينر: σ = nRT(α - 1/α²) حيث σ الإجهاد، n كثافة التشابك، α نسبة الاستطالة.

تقل المرونة بازدياد الحرارة (عكس الفلزات)، لأن القوة تتناسب طرداً مع T لاسترجاع الإنتروبيا.

## كيمياء السطوح والعوامل المساعدة
سؤال: اشتق متساوي حرارة لانجميور (Langmuir Isotherm) للامتزاز على سطح صلب.

الإجابة:
افتراضات لانجميور:
1. الامتزاز في طبقة أحادية.

2. جميع المواقع متكافئة طاقياً.

3. لا تفاعل بين الجزيئات الممتزة.

ليكن θ الكسر السطحي المغطى، P ضغط الغاز.

معدل الامتزاز = k₁P(1-θ)
معدل الانمتزاز = k₋₁θ
عند الاتزان: k₁P(1-θ) = k₋₁θ
θ = (k₁/k₋₁)P / (1 + (k₁/k₋₁)P) = KP/(1+KP) حيث K ثابت الاتزان.

الحجم الممتز V = Vm × θ = Vm KP/(1+KP).

خطياً: P/V = 1/(KVm) + P/Vm.

سؤال: قارن بين متساوي حرارة BET ومتساوي لانجميور من حيث الافتراضات والتطبيقات.

الإجابة:
لانجميور: امتزاز أحادي الطبقة. يصلح للامتزاز الكيميائي (Chemisorption) أو الفيزيائي عند ضغوط منخفضة.

BET (Brunauer-Emmett-Teller):
- افتراضات: امتزاز متعدد الطبقات. الطبقة الأولى تتبع لانجميور، والطبقات التالية تتصرف كتكاثف بخار.

- لا يوجد حد أعلى للحجم الممتز.

- المعادلة: P/[V(P₀-P)] = 1/(VmC) + [(C-1)/(VmC)] × (P/P₀)
  حيث P₀ ضغط البخار المشبع، C ثابت.

- التطبيق الأساسي: تحديد مساحة السطح النوعية (BET Surface Area) للمواد الصلبة المسامية باستخدام امتزاز N₂ عند 77K.

- تعطي مساحة سطح العينات المسامية (زيولايت، فحم منشط، عوامل مساعدة).

سؤال: اشرح آلية العامل المساعد في حالة تفاعل هدرجة الإيثيلين على سطح النيكل.

الإجابة:
تحفيز غير متجانس (Heterogeneous Catalysis) على مراحل:
1. انتشار المتفاعلات إلى سطح النيكل.

2. امتزاز (Adsorption):
   - H₂ يمتص تفككياً (ينفصل لذرتي H مرتبطتين بالنيكل).

   - C₂H₄ يمتص جزيئياً (رابطة π تتفاعل مع السطح).

3. تفاعل سطحي: تهاجر ذرات H على السطح وتتفاعل مع C₂H₄ الممتز خطوة خطوة:
   C₂H₄(ads) + H(ads) → C₂H₅(ads)
   C₂H₅(ads) + H(ads) → C₂H₆(ads)
4. انمتزاز (Desorption): C₂H₆ يغادر السطح.

5. انتشار الناتج بعيداً.

دور العامل المساعد: يقلل طاقة التنشيط بتفكيك H₂ وتقريب المتفاعلات في الاتجاه المناسب. النيكل يشكل روابط ضعيفة كافية مع المتفاعلات (لا قوية جداً ولا ضعيفة جداً - مبدأ ساباتييه Sabatier Principle).

سؤال: اشرح تركيب الزيولايت ZSM-5 ودوره في التكسير الحفزي الانتقائي للشكل.

الإجابة:
ZSM-5: زيولايت (ألومينوسيليكات) ذو بنية فريدة تحتوي على قنوات متقاطعة:
- قنوات مستقيمة (5.3 × 5.6 أنجستروم).

- قنوات متعرجة جيبية (5.1 × 5.5 أنجستروم).

التركيب: SiO₄ و AlO₄ رباعيات سطوح. Si/Al مرتفع (>15).

التحفيز الانتقائي للشكل (Shape-Selective Catalysis):
1. انتقائية المتفاعل: فقط الجزيئات الخطية/الصغيرة تدخل المسام وتتفاعل. (تكسير n-ألكانات دون متفرعة).

2. انتقائية الناتج: من بين النواتج المحتملة، الأصغر حجماً فقط يخرج (مثلاً بارا-زايلين يخرج أسرع من أورثو وميتا).

3. انتقائية الحالة الانتقالية: التفاعل الذي يحتاج حالة انتقالية أصغر (مثل تفاعل بين جزيئات صغيرة) هو المفضل.

ZSM-5 أساسي في تحويل الميثانول إلى جازولين (MTG Process).

سؤال: اشرح مفهوم الجهد السطحي (Zeta Potential) وأهميته في استقرار الغرويات.

الإجابة:
عند وضع جسيم غروي مشحون في سائل، تتكون طبقة مزدوجة كهربائية:
- طبقة شتيرن (Stern layer): أيونات مضادة ملتصقة بالجسيم.

- طبقة منتشرة: أيونات أقل ارتباطاً.

الجهد السطحي (ζ): الجهد الكهربائي عند مستوى القص (Slipping plane) بين الجسيم والطبقة المنتشرة.

أهميته:
- إذا |ζ| > ±30 mV: تنافر كهروستاتيكي قوي يمنع التجمع، الغروي مستقر.

- إذا |ζ| صغير (~0 mV): تضعف قوى التنافر، تتغلب قوى فان دير فالس ويحدث تخثر (Coagulation).

قياسه: بجهاز DLS (تشتت الضوء الديناميكي) مع تطبيق مجال كهربائي (Electrophoretic Light Scattering).

التحكم به: بتغيير pH أو إضافة أملاح (تضغط الطبقة المزدوجة فتقلل ζ).

سؤال: احسب مساحة السطح النوعية من بيانات BET التالية: ميل الخط = 0.05 جم/سم³، تقاطع = 0.002 جم/سم³. مساحة مقطع N₂ = 0.162 نانومتر².

الإجابة:
Vm = 1/(الميل + التقاطع) = 1/(0.05+0.002) = 1/0.052 = 19.23 سم³ عند STP.

عدد مولات N₂ في الطبقة الأحادية = 19.23/22400 = 0.000858 مول.

عدد جزيئات N₂ = 0.000858 × 6.022×10²³ = 5.17×10²⁰ جزيء.

مساحة السطح = 5.17×10²⁰ × 0.162×10⁻¹⁸ م² = 83.7 م².

(أو مباشرة: S = Vm × Nₐ × σ / 22400).

## كيمياء نووية
سؤال: احسب عمر النصف لتفاعل نووي من الرتبة الأولى إذا كانت كمية المادة تقل من 100% إلى 12.5% في 90 دقيقة.

الإجابة:
12.5% = 1/8 من الكمية الأصلية = (1/2)³.

إذن مرت 3 أعمار نصفية في 90 دقيقة.

عمر النصف t₁/₂ = 90 / 3 = 30 دقيقة.

سؤال: احسب طاقة التنشيط النووي اللازمة لتفاعل اندماج نووي بين بروتونين.

الإجابة:
يجب التغلب على حاجز كولوم: V = (k Z₁Z₂ e²) / r
حيث r المسافة التي تصبح عندها القوة النووية فعالة (~ 10⁻¹⁵ م).

Z₁=Z₂=1, k=9×10⁹, e=1.6×10⁻¹⁹ C.

V = (9×10⁹ × 1 × 1 × (1.6×10⁻¹⁹)²) / 10⁻¹⁵
= (9×10⁹ × 2.56×10⁻³⁸) / 10⁻¹⁵ = 2.304×10⁻¹³ جول
≈ 1.44 MeV.

وهذا يعادل ملايين الدرجات في الشمس (نواة الشمس ~15 مليون كلفن)، وتحدث باندماج كمي بالنفاذ.

سؤال: اشرح مفاعل التوليد (Breeder Reactor) ومميزاته.

الإجابة:
مفاعل التوليد: ينتج وقوداً نووياً أكثر مما يستهلك.

الوقود الابتدائي: ²³⁵U أو ²³⁹Pu.

يحيط بالقلب غطاء خصب (Blanket) من ²³⁸U (غير انشطاري).

النيوترونات السريعة المنبعثة من الانشطار تتحول في الغطاء:
²³⁸U + n → ²³⁹U → (β⁻) → ²³⁹Np → (β⁻) → ²³⁹Pu (وقود انشطاري جديد).

المميزات:
1. يستخدم ²³⁸U (99.3% من اليورانيوم الطبيعي) وليس ²³⁵U فقط.

2. ينتج وقوداً أكثر مما يستهلك.

العيوب: يحتاج نيوترونات سريعة (يستخدم صوديوم سائل كمبرد دون مهدئ)، قضايا أمان وتسلح نووي (البلوتونيوم).

سؤال: قارن بين الانشطار النووي والاندماج النووي.

الإجابة:
الانشطار (Fission):
- نواة ثقيلة (مثلاً ²³⁵U) تمتص نيوتروناً وتنشطر لنواتين متوسطتين + 2-3 نيوترونات + طاقة (~200 MeV).

- مصدر الطاقة: نقص الكتلة (طاقة ترابط لكل نوكليون أعلى للنواتج المتوسطة).

- تطبيق: محطات نووية، قنابل ذرية.

- مشكلة: نفايات مشعة طويلة العمر.

الاندماج (Fusion):
- نواتان خفيفتان (مثلاً D + T) تتحدان لتكوين نواة أثقل (⁴He + n) + طاقة (17.6 MeV).

- مصدر الطاقة: زيادة كبيرة في طاقة الترابط للنوكليون عند الانتقال من هيدروجين إلى هيليوم.

- تطبيق: الشمس، قنابل هيدروجينية، مفاعلات اندماج مستقبلية (ITER).

- مشكلة: يتطلب حرارة هائلة (ملايين الدرجات) وحصر البلازما. أنظف (نفايات أقل).

سؤال: اشرح طريقة التأريخ بالكربون-14 وأهم افتراضاتها.

الإجابة:
المبدأ: ¹⁴C ينتج في الغلاف الجوي من تفاعل النيوترونات الكونية مع ¹⁴N.

¹⁴C يتأكسد إلى CO₂، يدخل الكائنات الحية عبر التمثيل الضوئي/الغذاء، ويحافظ على نسبة ثابتة ¹⁴C/¹²C ≈ 1.3×10⁻¹².

عند الموت: يتوقف تبادل الكربون، يضمحل ¹⁴C بـ t₁/₂ = 5730 سنة.

بقياس نشاط ¹⁴C المتبقي في العينة نحسب عمرها:
t = (1/λ) ln(A₀/A).

الافتراضات:
1. نسبة ¹⁴C/¹²C في الغلاف الجوي ثابتة عبر الزمن. (في الحقيقة ليست ثابتة تماماً، وتصحح باستخدام منحنيات المعايرة من حلقات الأشجار والشعاب المرجانية).

2. الكائن الحي له نفس نسبة البيئة.

3. العينة لم تلوث بكربون حديث أو قديم.

المدى الفعال: حتى ~50000 سنة.

## كيمياء كهربائية متقدمة
سؤال: اشتق معادلة بتلر-فولمر (Butler-Volmer) للتيار الكهربائي في خلية كهروكيميائية.

الإجابة:
معادلة بتلر-فولمر تصف العلاقة بين التيار i والجهد الزائد η (Overpotential) لتفاعل إلكتروني بسيط.

Ox + ne⁻ ⇌ Red.

كثافة التيار الكلية = i = iₐ - i𝒸 = i₀[exp((1-α)nFη/RT) - exp(-αnFη/RT)]
حيث:
- i₀: تيار التبادل.

- α: معامل الانتقال (0.5 عادةً).

- η = E - E_eq (الجهد الزائد).

عند الجهد الزائد الكبير (قطب تafel):
للجهد الزائد الأنودي (η الموجب الكبير): η = a + b log i (معادلة تافل الأنودية).

للجهد الزائد الكاثودي: η = a' - b' log |i|.

عند الجهد الزائد الصغير (|η| < 10 mV): i ≈ i₀ × (nF/RT)η. المقاومة Rct = RT/nFi₀.

سؤال: اشرح اختبار طيف المعاوقة الكهروكيميائية (EIS) وكيفية تحديد مقاومة نقل الشحنة.

الإجابة:
EIS: تطبيق جهد متردد صغير (5-10 mV) بترددات مختلفة وقياس استجابة التيار.

الممانعة Z(ω) = E(ω)/I(ω).

تحليل الدائرة المكافئة الأكثر شيوعاً (Randle's Cell):
- RΩ: مقاومة المحلول (أومية).

- Rct: مقاومة نقل الشحنة (Charge Transfer Resistance، موازية).

- CPE أو Cdl: سعة الطبقة المزدوجة.

- W: معاوقة واربورغ (انتشار).

رسم Nyquist (-Z'' vs Z'):
- نصف دائرة عند الترددات العالية: قطرها = Rct. التقاطع مع المحور الحقيقي عند اليسار = RΩ.

- خط مستقيم بميل 45° عند الترددات المنخفضة (انتشار واربورغ).

Rct مرتبطة بتيار التبادل: i₀ = RT/nFRct. تستخدم لدراسة حركية التآكل وعمل البطاريات.

سؤال: صف تركيب بطارية ليثيوم-أيون (Li-ion) والتفاعلات الحادثة فيها.

الإجابة:
بطارية ليثيوم-أيون (مثال: LiCoO₂ / جرافيت):
الأنود (شحن سالب): جرافيت (طبقات كربون).

الكاثود (شحن موجب): أكسيد فلز الليثيوم LiCoO₂.

الإلكتروليت: LiPF₆ في مذيب عضوي (كربونات).

أثناء التفريغ:
- الأنود (أكسدة): LiC₆ → 6C + Li⁺ + e⁻
- الكاثود (اختزال): CoO₂ + Li⁺ + e⁻ → LiCoO₂
أثناء الشحن: عكس التفاعلات.

أيونات Li⁺ تنتقل بين الأنود والكاثود عبر الإلكتروليت (بطارية كرسي هزاز Rocking Chair).

الجهد الاسمي: ~3.7V.

الطاقة النوعية عالية لأن الليثيوم خفيف جداً.

سؤال: اشرح ميكانيكية التآكل الجلفاني (Galvanic Corrosion) وكيفية منعه.

الإجابة:
التآكل الجلفاني: يحدث عند تلامس فلزين مختلفي النشاط كهربائياً في وجود إلكتروليت.

يشكلان خلية جلفانية قصيرة الدائرة:
- الفلز الأكثر نشاطاً (جهد اختزال أقل) يعمل كآنود ويتآكل (يتأكسد).

- الفلز الأقل نشاطاً يعمل ككاثود (يختزل O₂ أو H⁺) ولا يتآكل.

مثال: مسمار حديد (Fe) في لوح نحاس (Cu) بماء مالح. الحديد هو الآنود ويتآكل بسرعة أكبر مما لو كان وحده. النحاس محمي.

السلسلة الجلفانية في ماء البحر:
الماغنسيوم، الزنك، الألمنيوم (نشطة/مضحية) ← الفولاذ ← النحاس ← الستانلس ستيل ← التيتانيوم ← الذهب (نبيلة).

طرق المنع:
1. عزل الفلزين كهربائياً.

2. طلاء الفلزين معاً.

3. جعل المساحة الآنودية كبيرة بالنسبة للكاثودية.

4. الحماية الكاثودية (Cathodic Protection): توصيل فلز أكثر نشاطاً (أنود مضحي كالخارصين) لحماية الفولاذ.

سؤال: احسب كمية الكهرباء اللازمة لترسيب 10 جم من النحاس من محلول CuSO₄. Cu=63.5.

الإجابة:
Cu²⁺ + 2e⁻ → Cu. عدد الإلكترونات n=2.

عدد مولات Cu = 10/63.5 = 0.1575 مول.

عدد مولات الإلكترونات = 2 × 0.1575 = 0.315 مول.

كمية الكهرباء Q = nF = 0.315 × 96485 = 30393 كولوم.

## كيمياء الحالة الصلبة
سؤال: اشرح بنية الخلية الوحدوية لـ NaCl واحسب عدد وحدات NaCl فيها.

الإجابة:
NaCl: شبيكة مكعبة مركزية الوجوه (FCC) للأيونات.

الخلية الوحدوية: أيونات Cl⁻ في FCC (8 أركان + 6 وجوه) = 8×(1/8) + 6×(1/2) = 4 Cl⁻.

أيونات Na⁺ تحتل جميع الفجوات ثمانية السطوح: 1 في المركز + 12 على الحواف×(1/4) = 1 + 3 = 4 Na⁺.

إذن: 4 وحدات NaCl في الخلية الوحدوية.

العدد التناسقي لـ Na⁺ و Cl⁻ = 6.

سؤال: احسب كثافة NaCl إذا كانت طول حرف الخلية = 564 بيكومتر. Na=23, Cl=35.5 جم/مول.

الإجابة:
حجم الخلية = (564 × 10⁻¹⁰ سم)³ = 1.794×10⁻²² سم³.

كتلة 4 وحدات NaCl = 4 × (58.5 جم/مول) / (6.022×10²³) = 3.886×10⁻²² جم.

الكثافة = الكتلة/الحجم = 3.886×10⁻²² / 1.794×10⁻²² = 2.17 جم/سم³.

سؤال: اشتق معامل التعبئة (Packing Fraction) لبنية FCC.

الإجابة:
في FCC: الذرات تتلامس على طول قطر الوجه.

4R = √2 × a → a = 4R/√2 = 2√2 R.

حجم الخلية = a³ = 16√2 R³.

عدد الذرات في خلية FCC = 4.

حجم 4 ذرات = 4 × (4/3)πR³ = (16π/3)R³.

معامل التعبئة = حجم الذرات / حجم الخلية = [(16π/3)R³] / [16√2 R³] = π/(3√2) = 0.7405 = 74.05%.

وهو أعلى معامل تعبئة ممكن لكرات متطابقة (مع HCP).

سؤال: اشرح أنواع العيوب البلورية في المركبات الأيونية غير المتكافئة (Non-stoichiometric Defects).

الإجابة:
1. العيب بزيادة الفلز (Metal Excess):
   - عيب شوتكي الأنيوني (F-centers): فراغ أنيوني يحتجز إلكتروناً. يعطي لوناً مميزاً. مثال: NaCl يسخن في بخار صوديوم يصبح أصفر.

   - عيب بيني كاتيوني: كاتيونات إضافية في مواقع بينية، وإلكترونات للتعادل. مثال: ZnO (أبيض يسخن يصبح أصفر).

2. العيب بنقص الفلز (Metal Deficiency):
   - عيب بيني أنيوني: أنيون في موقع بيني مع شحنة موجبة (ثقب). مثال: FeO لديه Fe/O < 1.

   - عيب فراغ كاتيوني: فراغ كاتيوني يعوض بشحنة موجبة (أكسدة). مثال: NiO يتحول لـ Ni(1-x)O، بعض Ni²⁺ تتأكسد لـ Ni³⁺.

سؤال: اشرح نظرية النطاقات (Band Theory) وفرقها بين الموصلات وأشباه الموصلات والعوازل.

الإجابة:
في المادة الصلبة، تتشكل نطاقات طاقة من تداخل الأوربيتالات الذرية:
- نطاق التكافؤ (Valence Band VB): ممتلئ بالإلكترونات.

- نطاق التوصيل (Conduction Band CB): فارغ أو شبه فارغ.

- فجوة الطاقة (Band Gap Eg): الفرق بين أعلى VB وأدنى CB.

الموصل (فلز): VB و CB متداخلان أو VB ممتلئ جزئياً. الإلكترونات تتحرك بحرية. لا فجوة (Eg = 0).

شبه الموصل (Silicon, Ge): Eg صغيرة (~1.1 eV لـ Si). عند T>0، بعض الإلكترونات تثار حرارياً لـ CB تاركة ثقوباً في VB. التوصيلية تزداد بزيادة T (عكس الفلزات).

عازل (Diamond, SiO₂): Eg كبيرة (>5 eV). لا تثار إلكترونات عملياً. لا يوصل.

التطعيم (Doping) في أشباه الموصلات:
- نوع n: إضافة ذرة خماسية التكافؤ (فوسفور في سيليكون). إلكترونات إضافية.

- نوع p: إضافة ذرة ثلاثية (بورون). ثقوب إضافية.

سؤال: ما هي الموصلية الفائقة (Superconductivity)؟ وما الفرق بين النوع الأول والثاني؟
الإجابة:
الموصلية الفائقة: اختفاء المقاومة الكهربائية كلياً تحت درجة حرارة حرجة Tc.

اكتشفها كاملنج أونز في الزئبق عند 4.2K.

تأثير مايسنر (Meissner Effect): طرد المجال المغناطيسي من داخل الموصل الفائق (مغناطيسية معاكسة كاملة).

النوع الأول (Type I): معظم الفلزات النقية. لها مجال حرج واحد Hc. فوقه تختفي الفائقة فجأة.

النوع الثاني (Type II): معظم السبائك والسيراميك الفائق (مثل YBCO). لها مجالان حرجان Hc1 و Hc2.

بينهما: حالة مختلطة (حالة دوامية Vortex)، تخترق المجال المغناطيسي على شكل خيوط رفيعة لكن المقاومة تبقى صفراً.

النوع الثاني مهم تقنياً لأنه يتحمل مجالات مغناطيسية أقوى.

موصلات فائقة عالية الحرارة (High-Tc): سيراميكات الكوبرات (مثل HgBaCaCuO، Tc = 134K، تحت الضغط 164K). آلية الفائقة فيها غير مفهومة كلياً (غير BCS التقليدية).

## ديناميكا حرارية إحصائية
سؤال: اشرح دالة التوزيع القانونية (Canonical Partition Function) وكيفية حساب الطاقة الداخلية منها.

الإجابة:
دالة التوزيع القانونية: Q = Σ gᵢ e^(-Eᵢ/kT)
حيث gᵢ انحطاط المستوى Eᵢ، k ثابت بولتزمان.

الطاقة الداخلية: U = kT² (∂ ln Q / ∂T)v
متوسط الطاقة = <E> = (1/Q) Σ Eᵢ gᵢ e^(-Eᵢ/kT) = - (∂ ln Q / ∂β) حيث β=1/kT.

الطاقة الحرة لهلمهولتز: A = -kT ln Q.

الإنتروبيا: S = k ln Q + U/T.

الضغط: P = kT (∂ ln Q / ∂V)T.

سؤال: احسب دالة التوزيع الانتقالية (Translational Partition Function) لجسيم في صندوق ثلاثي الأبعاد.

الإجابة:
q_trans = Σ e^(-Eₙ/kT) حيث E = (h²/8mL²)(n₁²+n₂²+n₃²).

بتحويل المجموع لتكامل (عندما تكون فرق الطاقة << kT):
q_trans = (2πmkT/h²)^(3/2) × V
حيث V = L³ الحجم.

التعبير Λ = h/√(2πmkT) يسمى طول الموجة الحرارية لدي برولي.

إذن q_trans = V / Λ³.

يساهم هذا في حسابات الاتزان الكيميائي (ثابت الاتزان من الدوال التوزيعية).

سؤال: احسب دالة التوزيع الدورانية لجزيء ثنائي الذرة غير متجانس في حد درجة الحرارة العالية.

الإجابة:
q_rot = Σ (2J+1) e^(-J(J+1)θ_rot/T) حيث θ_rot = h²/8π²Ik (درجة الحرارة الدورانية).

عندما T >> θ_rot (تقريب الكلاسيكي): نستبدل المجموع بتكامل.

q_rot = T / (σ θ_rot)
حيث σ عدد التناظر (σ=1 لـ HCl غير المتجانس، σ=2 لـ O₂ المتجانس).

سؤال: احسب دالة التوزيع الاهتزازية لجزيء ثنائي الذرة كنموذج هزاز توافقي.

الإجابة:
طاقات الهزاز التوافقي: Eₙ = (n + ½)hν
q_vib = Σ e^(-(n+½)hν/kT) = e^(-hν/2kT) Σ (e^(-hν/kT))ⁿ
= e^(-θ_vib/2T) / (1 - e^(-θ_vib/T))
حيث θ_vib = hν/k.

عند T << θ_vib: q_vib ≈ e^(-θ_vib/2T) (الحالة الأرضية فقط).

عند T >> θ_vib: q_vib ≈ T/θ_vib (مبدأ التوزع المتساوي للطاقة).

سؤال: اشتق ثابت الاتزان الكيميائي Kc من دوال التوزيع الإحصائية.

الإجابة:
ثابت الاتزان: Kc = (q°_C)^c (q°_D)^d / [(q°_A)^a (q°_B)^b] × e^(-ΔE₀/kT)
حيث q° = q/V (دالة التوزيع لكل وحدة حجم)، ΔE₀ فرق طاقة النقطة الصفرية.

q° = q_trans°/V × q_rot × q_vib × q_elec.

q_trans°/V = (2πmkT/h²)^(3/2).

q_elec = g₀ e^(-E₀/kT) + ... (عادةً g₀ فقط).

التطبيق الكلاسيكي: تفاعل A₂ → 2A.

هذا الربط بين المجهري (الدوال الجزيئية) والعياني (ثابت الاتزان) هو جوهر الديناميكا الحرارية الإحصائية.

سؤال: احسب الإنتروبيا المولية الانتقالية لغاز مثالي أحادي الذرة عند STP (معادلة ساكور-تيترود Sakur-Tetrode).

الإجابة:
S_trans = R [ln(q_trans/Nₐ) + 5/2] (للجسيمات غير المتمايزة بتصحيح بولتزمان).

معادلة ساكور-تيترود:
S = R ln[(2πmkT/h²)^(3/2) × Ve^(5/2) / Nₐ]
أو S = R [ln(V/NₐΛ³) + 5/2].

مثال للنيون (Ne, m=20.18 amu) عند 298K و 1 atm (V=24.45 L):
S°_trans = 146.2 J/mol·K (وهي مطابقة للقيمة التجريبية تقريباً).

هذه النصوص تغطي المواضيع المتقدمة جداً التي طلبتها. هل هناك أي مجال آخر تحتاج إليه؟
حسناً، إليك نصوصاً تدريبية شاملة ومتقدمة في جميع فروع الفيزياء بصيغة txt. تغطي الميكانيكا الكلاسيكية، الكهرومغناطيسية، الديناميكا الحرارية، النسبية، ميكانيكا الكم، الفيزياء النووية، فيزياء الجسيمات، الفيزياء الفلكية، وفيزياء الحالة الصلبة.

## ميكانيكا كلاسيكية
سؤال: جسم كتلته 5 كجم يتحرك على سطح أفقي أملس بسرعة 10 م/ث. اصطدم بجسم آخر كتلته 3 كجم ساكن. إذا كان التصادم مرناً تماماً، احسب سرعة كل جسم بعد التصادم.

الإجابة:
التصادم المرن يحقق قانوني حفظ كمية التحرك وحفظ الطاقة الحركية.

حفظ كمية التحرك: m₁v₁ᵢ + m₂v₂ᵢ = m₁v₁f + m₂v₂f
5(10) + 3(0) = 5v₁f + 3v₂f → 50 = 5v₁f + 3v₂f ...(1)
حفظ الطاقة الحركية: ½m₁v₁ᵢ² + ½m₂v₂ᵢ² = ½m₁v₁f² + ½m₂v₂f²
½(5)(100) + 0 = ½(5)v₁f² + ½(3)v₂f² → 250 = 2.5v₁f² + 1.5v₂f² ...(2)
من معادلات التصادم المرن: v₁f = [(m₁-m₂)/(m₁+m₂)]v₁ᵢ = [(5-3)/8]×10 = 2.5 م/ث
v₂f = [2m₁/(m₁+m₂)]v₁ᵢ = [10/8]×10 = 12.5 م/ث
سؤال: قذيفة كتلتها 2 كجم أطلقت بسرعة 500 م/ث بزاوية 60° فوق الأفقي. احسب المدى الأفقي وأقصى ارتفاع. (g=10 م/ث²)
الإجابة:
المركبة الأفقية: vₓ = 500 cos60° = 250 م/ث
المركبة الرأسية: vᵧ = 500 sin60° = 500×0.866 = 433 م/ث
زمن الصعود = vᵧ/g = 433/10 = 43.3 ث
زمن التحليق الكلي = 2×43.3 = 86.6 ث
المدى الأفقي = vₓ × الزمن الكلي = 250 × 86.6 = 21650 متر = 21.65 كم
أقصى ارتفاع = vᵧ²/(2g) = (433)²/20 = 187489/20 = 9374.5 متر
سؤال: احسب عزم القصور الذاتي لقرص منتظم كتلته M ونصف قطره R حول محور يمر بمركزه وعمودي على سطحه. ثم احسبه حول محور يمر بطرفه (باستخدام نظرية المحاور المتوازية).

الإجابة:
عنصر الكتلة: حلقة نصف قطرها r وعرضها dr. كتلة الحلقة dm = (2M/R²)r dr.

عزم القصور الذاتي dI = r² dm = (2M/R²)r³ dr.

I = ∫₀ᴿ (2M/R²)r³ dr = (2M/R²)(R⁴/4) = ½MR².

نظرية شتاينر (المحاور المتوازية): I_طرف = I_مركز + M d²
المسافة من المركز للطرف d = R.

I_طرف = ½MR² + MR² = (3/2)MR².

سؤال: أوجد معادلة حركة بندول بسيط طوله L وكتلته m، ثم أوجد الزمن الدوري للاهتزازات الصغيرة.

الإجابة:
القوى المؤثرة: وزن mg، وشد الخيط T.

عزم القوة حول نقطة التعليق: τ = -mgL sinθ.

معادلة الحركة: I α = τ → mL² (d²θ/dt²) = -mgL sinθ.

d²θ/dt² + (g/L) sinθ = 0.

للهزات الصغيرة (θ << 1): sinθ ≈ θ.

d²θ/dt² + (g/L)θ = 0 (حركة توافقية بسيطة).

التردد الزاوي ω = √(g/L).

الزمن الدوري T = 2π/ω = 2π√(L/g).

عند السعات الكبيرة: T = 2π√(L/g) [1 + (1/16)θ₀² + ...] (متسلسلة).

سؤال: اشرح مبدأ نيتر (Noether's Theorem) مع مثال.

الإجابة:
نظرية نيتر: لكل تناظر مستمر في نظام فيزيائي يوجد كمية محفوظة مقابلة.

- تناظر انتقالي في الزمن ← حفظ الطاقة.

- تناظر انتقالي في المكان ← حفظ كمية التحرك الخطية.

- تناظر دوراني ← حفظ كمية التحرك الزاوية.

مثال: إذا كان اللاكرانجي L = T - V لا يعتمد صراحة على إحداثي معمم qᵢ (إحداثي دوري)، فإن كمية التحرك المعممة المقابلة محفوظة:
∂L/∂qᵢ = 0 → pᵢ = ∂L/∂q̇ᵢ = ثابت.

في حركة الكواكب (جهد مركزي): V = -k/r لا يعتمد على θ، إذن p_θ = mr²θ̇ = L (كمية تحرك زاوية) محفوظة ← قانون كبلر الثاني.

سؤال: نابض ثابته k=200 N/m، علقت به كتلة 2 كجم. احسب التردد الزاوي والزمن الدوري. إذا أزيحت الكتلة 5 سم عن الاتزان، احسب الطاقة الكلية.

الإجابة:
التردد الزاوي: ω = √(k/m) = √(200/2) = √100 = 10 rad/s.

الزمن الدوري: T = 2π/ω = 2π/10 = 0.628 ثانية.

السعة A = 0.05 م.

الطاقة الكلية: E = ½kA² = ½(200)(0.05)² = 100×0.0025 = 0.25 جول.

## كهرومغناطيسية
سؤال: احسب المجال الكهربائي على بعد 30 سم من شحنة نقطية مقدارها 5 μC في الفراغ. (k=9×10⁹ N·m²/C²)
الإجابة:
E = kQ/r² = (9×10⁹)(5×10⁻⁶)/(0.3)² = (45000)/(0.09) = 500,000 = 5×10⁵ N/C.

سؤال: سلك مستقيم لا نهائي يحمل تياراً شدته 10 أمبير. احسب المجال المغناطيسي على بعد 5 سم منه. (μ₀=4π×10⁻⁷)
الإجابة:
B = μ₀I/(2πr) = (4π×10⁻⁷×10)/(2π×0.05) = (4×10⁻⁶)/(0.1) = 4×10⁻⁵ تسلا.

سؤال: حلقة دائرية نصف قطرها R تحمل تياراً I. أوجد المجال المغناطيسي في مركزها وعلى محورها.

الإجابة:
في المركز: كل عنصر dl يعطي dB = (μ₀/4π)(I dl/R²) عمودياً على مستوى الحلقة.

بالتكامل: B = μ₀I/(2R). اتجاهه حسب قاعدة اليد اليمنى.

على المحور (على بعد x من المركز):
المسافة من العنصر للنقطة r = √(R²+x²).

المركبة العمودية على المحور تنعدم بالتناظر.

المركبة على المحور: B = (μ₀IR²)/(2(R²+x²)^(3/2)).

عند x=0 (المركز): نستعيد B = μ₀I/(2R).

عند x>>R: B ≈ μ₀IR²/(2x³) (ثنائي قطب مغناطيسي).

سؤال: ملف حلزوني (Solenoid) طوله 50 سم، عدد لفاته 1000 لفة، يمر به تيار 2 أمبير. احسب المجال المغناطيسي داخله.

الإجابة:
عدد اللفات لكل متر: n = 1000/0.5 = 2000 لفة/م.

B = μ₀nI = (4π×10⁻⁷)(2000)(2) = 16π×10⁻⁴ = 5.03×10⁻³ تسلا.

سؤال: اشتق معادلات ماكسويل في الفراغ وبين كيف تؤدي للموجات الكهرومغناطيسية.

الإجابة:
في الفراغ (لا شحنات ولا تيارات: ρ=0, J=0):
1. ∇·E = 0
2. ∇·B = 0
3. ∇×E = -∂B/∂t
4. ∇×B = μ₀ε₀ ∂E/∂t
نأخذ curl للمعادلة 3: ∇×(∇×E) = -∂(∇×B)/∂t
باستخدام متطابقة المتجهات والمعادلة 4:
∇(∇·E) - ∇²E = -μ₀ε₀ ∂²E/∂t²
بما أن ∇·E=0: ∇²E = μ₀ε₀ ∂²E/∂t²
وهذه معادلة موجية سرعتها c = 1/√(μ₀ε₀) ≈ 3×10⁸ م/ث (سرعة الضوء).

بالمثل للمجال المغناطيسي: ∇²B = μ₀ε₀ ∂²B/∂t².

سؤال: احسب تردد دائرة رنين LC فيها L=2 mH و C=5 μF.

الإجابة:
تردد الرنين: f = 1/(2π√(LC)) = 1/(2π√(2×10⁻³×5×10⁻⁶))
= 1/(2π√(10×10⁻⁹)) = 1/(2π×10⁻⁴×√10) = 10000/(2π√10) ≈ 503.3 هرتز.

سؤال: مكثف هوائي مساحته 100 سم² والبعد بين لوحيه 2 مم. احسب سعته. إذا وضع بين لوحيه عازل ثابته κ=5، ما السعة الجديدة؟
الإجابة:
C₀ = ε₀A/d = (8.85×10⁻¹²)(100×10⁻⁴)/(2×10⁻³)
= (8.85×10⁻¹²×10⁻²)/(2×10⁻³) = 8.85×10⁻¹⁴/2×10⁻³ = 4.425×10⁻¹¹ فاراد = 44.25 pF.

C = κC₀ = 5×44.25 = 221.25 pF.

سؤال: اشرح قانون لنز (Lenz's Law) وأعط مثالاً عددياً.

الإجابة:
قانون لنز: اتجاه التيار الحثي يعاكس التغير في التدفق المغناطيسي الذي سببه.

الصياغة الرياضية: ε = -dΦ/dt (العلامة السالبة تعبر عن قانون لنز).

مثال: ملف مساحته 0.1 م² موضوع عمودياً على مجال مغناطيسي 2 تسلا. إذا انخفض المجال إلى صفر في 0.5 ثانية، احسب القوة الدافعة الكهربائية الحثية في ملف عدد لفاته 50 لفة.

Φ₁ = BA = 2×0.1 = 0.2 ويبر.

Φ₂ = 0.

ΔΦ = -0.2 ويبر.

ε = -N(ΔΦ/Δt) = -50(-0.2/0.5) = 50(0.4) = 20 فولت.

اتجاه التيار الحثي سيحاول إبقاء المجال (حسب قاعدة اليد اليمنى) معاكساً للتناقص.

سؤال: موجة كهرومغناطيسية ترددها 100 MHz. احسب طولها الموجي في الفراغ وفي وسط معامل انكساره 1.5.

الإجابة:
في الفراغ: λ₀ = c/f = 3×10⁸/10⁸ = 3 متر.

في الوسط: v = c/n = 3×10⁸/1.5 = 2×10⁸ م/ث.

λ = v/f = 2×10⁸/10⁸ = 2 متر.

## ديناميكا حرارية
سؤال: احسب الشغل المبذول في تمدد أديباتي عكوس لغاز مثالي. الغاز أحادي الذرة (γ=5/3)، درجة حرارته الابتدائية 600K، النهائية 300K، وعدد المولات 2. (R=8.314)
الإجابة:
في عملية أديباتية: Q=0، ΔU = -W.

ΔU = nCvΔT. للغاز أحادي الذرة Cv = (3/2)R.

ΔU = 2 × (3/2)×8.314 × (300-600) = 3×8.314×(-300) = -7482.6 جول.

W = -ΔU = +7482.6 جول (شغل مبذول من النظام).

طريقة أخرى: W = (P₁V₁ - P₂V₂)/(γ-1) = nR(T₁-T₂)/(γ-1)
= 2×8.314×300/(2/3) = 4988.4 × (3/2) = 7482.6 جول.

سؤال: محرك كارنو يعمل بين خزانين حراريين درجة حرارتيهما 800K و 300K. احسب كفاءته. إذا امتص 1000 جول من الخزان الساخن، ما الشغل الناتج والحرارة المطرودة؟
الإجابة:
كفاءة كارنو: η = 1 - Tc/Th = 1 - 300/800 = 1 - 0.375 = 0.625 = 62.5%.

الشغل: W = η Qh = 0.625 × 1000 = 625 جول.

الحرارة المطرودة: Qc = Qh - W = 1000 - 625 = 375 جول.

(أو Qc/Qh = Tc/Th → Qc = 1000×(300/800) = 375 جول.)
سؤال: احسب التغير في الإنتروبيا عند خلط 1 كجم ماء عند 80°م مع 1 كجم ماء عند 20°م. (c=4200 J/kg·K)
الإجابة:
درجة حرارة الاتزان النهائية: Tf = (80+20)/2 = 50°م = 323K.

للماء الساخن: ΔS₁ = mc ln(Tf/T₁) = 1×4200×ln(323/353)
= 4200 × ln(0.915) = 4200 × (-0.0888) = -373 J/K.

للماء البارد: ΔS₂ = mc ln(Tf/T₂) = 1×4200×ln(323/293)
= 4200 × ln(1.1024) = 4200 × 0.0975 = +409.5 J/K.

ΔS الكلية = -373 + 409.5 = +36.5 J/K > 0. (العملية تلقائية/غير عكوسة).

سؤال: اشرح معادلة فان دير فالس للغازات الحقيقية ومعنى الثابتين a و b.

الإجابة:
معادلة فان دير فالس: (P + an²/V²)(V - nb) = nRT.

لعدد 1 مول: (P + a/V²)(V - b) = RT.

a: يمثل قوى التجاذب بين الجزيئات. يقلل الضغط (P_مثالي > P_حقيقي).

b: يمثل الحجم المستبعد (حجم الجزيئات نفسها). الحجم المتاح = V - nb.

عند الحجم الكبير: تؤول لمعادلة الغاز المثالي.

النقطة الحرجة: ∂P/∂V = 0, ∂²P/∂V² = 0.

Tc = 8a/(27Rb), Pc = a/(27b²), Vc = 3b.

سؤال: اشرح دورة ستيرلينج (Stirling Cycle) ومكوناتها.

الإجابة:
دورة ستيرلينج: دورة حرارية من 4 عمليات عكوسة (نظرية):
1. تمدد متساوي الحرارة (Isothermal expansion) عند Th: يمتص حرارة Qh وينتج شغلاً.

2. تبريد ثابت الحجم (Isochoric cooling): يمر الغاز خلال مُجَدِّد (Regenerator) ويفقد حرارة.

3. انضغاط متساوي الحرارة عند Tc: يطرد حرارة Qc ويبذل عليه شغل.

4. تسخين ثابت الحجم: يعود الغاز عبر المُجَدِّد ويمتص الحرارة المختزنة.

ميزتها: كفاءة نظرية = كفاءة كارنو. المُجَدِّد (مبادل حراري) يعيد تدوير الحرارة الداخلية.

محرك ستيرلينج عملي: هادئ، يمكن تشغيله بأي مصدر حراري (شمسي، حرارة ضائعة).

## النسبية الخاصة والعامة
سؤال: مركبة فضائية تتحرك بسرعة 0.8c بالنسبة للأرض. طولها الساكن 100 متر. ما طولها بالنسبة لمراقب أرضي؟

سؤال: احسب الطاقة اللازمة لتسريع إلكترون (كتلته السكونية 0.511 MeV/c²) من السكون لسرعة 0.9c.

الإجابة:

عند v=0.9c: γ = 1/√(1-0.81) = 1/√0.19 = 2.294.

سؤال: اشرح معادلة المجال لأينشتاين (Einstein Field Equations) وماذا يمثل كل حد.

الإجابة:
Rμν - ½gμνR + Λgμν = (8πG/c⁴) Tμν
Rμν: موتر ريتشي (Ricci Tensor) – يصف انحناء الزمكان الناتج عن المادة.

gμν: موتر المترية (Metric Tensor) – يصف هندسة الزمكان.

R: عدد ريتشي (Ricci Scalar) – تقلص موتر ريتشي.

Λ: الثابت الكوني (Cosmological Constant) – يمثل طاقة الفراغ (الطاقة المظلمة).

Tμν: موتر الإجهاد-الطاقة (Stress-Energy Tensor) – يصف توزع المادة والطاقة.

الطرف الأيسر: يصف هندسة الزمكان (الانحناء).

الطرف الأيمن: يصف محتوى المادة والطاقة.

المعادلة تقول: "المادة تخبر الزمكان كيف ينحني، والزمكان يخبر المادة كيف تتحرك" (جون ويلر).

سؤال: احسب نصف قطر شفارتزشيلد (Schwarzschild Radius) للشمس. M☉ = 2×10³⁰ kg.

الإجابة:
Rs = 2GM/c² = 2(6.67×10⁻¹¹)(2×10³⁰)/(9×10¹⁶)
= 26.68×10¹⁹/9×10¹⁶ = 2.96×10³ متر ≈ 3 كم.

(لو انضغطت الشمس داخل كرة نصف قطرها 3 كم، لتحولت لثقب أسود).

سؤال: مراقبان A و B يتحركان بسرعتين 0.6c و 0.8c بالنسبة للأرض في اتجاهين متعاكسين. ما سرعة B بالنسبة لـ A؟ (قانون جمع السرعات النسبوي)
الإجابة:
قانون جمع السرعات: u' = (u - v)/(1 - uv/c²)
نعتبر الأرض إطار S، A إطار S' يتحرك بسرعة v=0.6c.

سرعة B في S هي u = -0.8c.

سرعة B بالنسبة لـ A: u' = (-0.8c - 0.6c)/(1 - (-0.8×0.6)) = (-1.4c)/(1+0.48) = -1.4c/1.48 = -0.946c.

السرعة النسبية أقل من c دائماً.

## ميكانيكا الكم المتقدمة
سؤال: جسيم في بئر جهد لا نهائي عرضه L في الحالة n=2. احسب احتمال وجود الجسيم في الثلث الأوسط من البئر.

الإجابة:
Ψ₂(x) = √(2/L) sin(2πx/L).

الاحتمال: P = ∫_{L/3}^{2L/3} |Ψ₂|² dx = (2/L) ∫_{L/3}^{2L/3} sin²(2πx/L) dx.

باستخدام sin²θ = (1-cos2θ)/2:
= (2/L) ∫_{L/3}^{2L/3} [1/2 - (1/2)cos(4πx/L)] dx
= (1/L) [x - (L/4π)sin(4πx/L)]_{L/3}^{2L/3}
= (1/L)[(L/3) - (L/4π)(sin(8π/3) - sin(4π/3))]
sin(8π/3) = sin(240°) = -√3/2، sin(4π/3) = -√3/2.

= (1/L)[L/3 - (L/4π)(-√3/2 + √3/2)] = 1/3 ≈ 33.3%.

سؤال: أوجد القيم الذاتية للطاقة والدوال الذاتية لمذبذب توافقي كمي.

الإجابة:
معادلة شرودنجر: -(ħ²/2m)(d²Ψ/dx²) + ½mω²x²Ψ = EΨ.

باستخدام المؤثرات السلمية:
a = √(mω/2ħ)(x + ip/mω) (مؤثر الفناء).

a† = √(mω/2ħ)(x - ip/mω) (مؤثر الخلق).

الهاملتوني: H = ħω(a†a + ½).

عدد الجسيمات: N = a†a. القيم الذاتية n = 0,1,2,...

طاقات المذبذب: Eₙ = ħω(n + ½).

الدالة الموجية للحالة الأرضية: Ψ₀(x) = (mω/πħ)^(1/4) e^(-mωx²/2ħ).

باقي الدوال: Ψₙ(x) = (1/√(2ⁿn!))(a†)ⁿΨ₀(x) (كثيرات حدود هيرمت × جاوسيان).

طاقة النقطة الصفرية E₀ = ½ħω ≠ 0 (تتفق مع مبدأ اللايقين).

سؤال: استخدم نظرية الاضطراب المستقلة عن الزمن لحساب تصحيح الطاقة من الرتبة الأولى لحالة أرضية جسيم في صندوق بعرض L مع اضطراب V(x) = εx/L.

الإجابة:
الطاقة غير المضطربة: E₁^(0) = h²/(8mL²).

الدالة غير المضطربة: Ψ₁^(0) = √(2/L) sin(πx/L).

التصحيح الأول: E₁^(1) = <Ψ₁|V|Ψ₁> = ∫₀ᴸ (2/L) sin²(πx/L) × (εx/L) dx.

= (2ε/L²) ∫₀ᴸ x sin²(πx/L) dx.

باستخدام التكامل: ∫₀ᴸ x sin²(πx/L) dx = L²/4.

إذن E₁^(1) = (2ε/L²)(L²/4) = ε/2.

وهذا معقول: متوسط V هو قيمته في منتصف الصندوق (ε/2).

سؤال: اشرح تشابك الكم (Quantum Entanglement) ومفارقة EPR واختبار بل.

الإجابة:
التشابك: حالة كمومية لجسيمين أو أكثر لا يمكن وصفها بشكل منفصل. قياس أحد الجسيمين يحدد فوراً نتيجة قياس الآخر مهما كانت المسافة.

مفارقة EPR (أينشتاين-بودولسكي-روزن 1935): جادلت بأن ميكانيكا الكم غير مكتملة لأنها تسمح "بتأثير شبحي عن بعد". اقترحوا وجود متغيرات خفية محلية (Local Hidden Variables).

اختبار بل (Bell's Inequality - 1964):
افترض بل أن أي نظرية متغيرات خفية محلية يجب أن تحقق متراجحة معينة:
|E(a,b) - E(a,c)| ≤ 1 + E(b,c).

ميكانيكا الكم تنبأت بانتهاك هذه المتراجحة.

تجارب أسبكت (Aspect 1982) وغيرها: انتهكت متراجحة بل بشكل واضح، مؤكدة صحة ميكانيكا الكم ونفي المتغيرات الخفية المحلية.

التشابك حقيقي ويستخدم الآن في الحوسبة الكمومية والتشفير الكمومي.

سؤال: اشرح تجربة الشق المزدوج (Double Slit Experiment) ودلالاتها الفلسفية.

الإجابة:
التجربة:
- يطلق جسيمات (إلكترونات مثلاً) منفردة نحو حاجز بشقين، ثم تسجل على شاشة.

- مع تراكم التصادمات: يتشكل نمط تداخل (موجات).

- حتى لو أطلقت الإلكترونات واحداً تلو الآخر (لا يوجد جسيمات أخرى لتتداخل معها)، يظهر نمط التداخل.

- الإلكترون يتصرف كموجة، ويمر بالشقين معاً، ويتداخل مع نفسه.

إذا حاولنا رصد أي شق يمر منه الإلكترون (وضع كاشف): يختفي نمط التداخل، ويتصرف كجسيم يمر من أحد الشقين فقط.

الدلالات الفلسفية:
- مبدأ التكامل (Complementarity) لبوهر: السلوك الموجي والجسيمي وجهان مكملان لا يظهران معاً.

- دور الراصد: القياس يؤثر على النظام الكمومي (انهيار الدالة الموجية).

- الطبيعة الاحتمالية: لا يمكن التنبؤ بمسار فردي، بل باحتمالات فقط.

## فيزياء نووية وفيزياء الجسيمات
سؤال: اشرح النموذج القياسي لفيزياء الجسيمات (Standard Model) ومكوناته.

الإجابة:
النموذج القياسي: نظرية تصف ثلاث قوى أساسية (كهرومغناطيسية، نووية قوية، نووية ضعيفة) والجسيمات الأولية.

الجسيمات:
1. الفرميونات (المادة - سبين 1/2):
   - الكواركات (6): Up, Down, Charm, Strange, Top, Bottom. تكون البروتونات والنيوترونات...

   - اللبتونات (6): إلكترون، ميون، تاو، ونيوترينواتها.

   - كل جسيم له جسيم مضاد.

2. البوزونات (حاملات القوى - سبين صحيح):
   - فوتون (γ): القوة الكهرومغناطيسية، كتلة 0.

   - غلوونات (g - 8 أنواع): القوة النووية القوية، كتلة 0.

   - W⁺, W⁻, Z⁰: القوة النووية الضعيفة، كتل كبيرة.

   - بوزون هيجز (H⁰): يعطي الكتلة للجسيمات عبر آلية هيجز.

القوى الموحدة جزئياً: الكهرومغناطيسية + الضعيفة = قوة كهروضعيفة (Electroweak) عند طاقات عالية (نظرية جلاشو-واينبرج-سلام).

## فيزياء الحالة الصلبة والمادة المكثفة
سؤال: اشتق قانون براج (Bragg's Law) لحيود الأشعة السينية على البلورات.

الإجابة:
عند سقوط أشعة X بزاوية θ على مستويات ذرية متوازية المسافة بينها d، تنعكس عن كل مستوى.

فرق المسار بين الشعاعين المنعكسين من مستويين متتاليين = 2d sinθ.

للحصول على تداخل بناء، يجب أن يكون فرق المسار = عدد صحيح من الأطوال الموجية:
nλ = 2d sinθ (قانون براج).

n: رتبة الحيود (1,2,3...).

λ: الطول الموجي للأشعة السينية.

تطبيق: بمعرفة λ وقياس θ، نحسب d المسافات بين المستويات البلورية ونحدد التركيب البلوري (مطيافية حيود الأشعة السينية XRD).

سؤال: اشرح نموذج الإلكترون الحر (Free Electron Model) في الفلزات. واحسب كثافة الحالات عند مستوى فيرمي.

الإجابة:
نموذج الإلكترون الحر (سومرفيلد): إلكترونات التوصيل حرة الحركة داخل الفلز (بئر جهد منتظم) وتطيع مبدأ باولي وإحصاء فيرمي-ديراك.

الطاقة: E = ħ²k²/2m. متجه الموجة k مكماة بشروط دورية.

كل حالة تشغل حجم (2π/L)³ في فضاء k.

عدد الحالات لكل وحدة حجم حتى k: N/V = k³/(3π²).

كثافة الحالات g(E) = dN/dE = (V/2π²)(2m/ħ²)^(3/2) √E.

عند طاقة فيرمي: g(EF) = (3/2)(n/EF) حيث n كثافة الإلكترونات.

درجة حرارة فيرمي: TF = EF/k ~ 10⁴-10⁵ K. في درجة حرارة الغرفة، الإلكترونات "باردة" جداً مقارنة بـ TF.

سؤال: قارن بين العوازل وأشباه الموصلات والموصلات من حيث تركيب النطاقات (Band Structure).

الإجابة:
الموصل (فلز):
- نطاق التوصيل CB ونطاق التكافؤ VB يتداخلان.

- أو VB ممتلئ جزئياً.

- المقاومية تزداد بزيادة T (تصادمات أكثر مع أيونات الشبكة).

شبه الموصل (سيليكون، جرمانيوم):
- فجوة طاقة Eg بين 0.1 و 3 eV.

- عند T=0: VB ممتلئ، CB فارغ. عازل.

- عند T>0: إلكترونات تثار حرارياً لـ CB، تاركة ثقوباً. المقاومية تقل بزيادة T.

- النوع n (إلكترونات إضافية)، النوع p (ثقوب إضافية) بالتطعيم.

عازل (الماس، كوارتز):
- فجوة طاقة كبيرة > 5 eV.

- الإثارة الحرارية مهملة، يبقى CB فارغاً.

سؤال: اشرح نظرية BCS في الموصلية الفائقة.

الإجابة:
نظرية BCS (باردين-كوبر-شريفر 1957): تفسر الموصلية الفائقة في الفلزات عند درجات حرارة منخفضة.

الآلية:
- إلكترون يمر بشبكة الأيونات الموجبة، يجذب الأيونات محدثاً تشويهاً موضعياً (زيادة كثافة شحنة موجبة).

- إلكترون آخر ينجذب لهذه المنطقة ذات الشحنة الموجبة الزائدة.

- النتيجة: ترابط فعال بين إلكترونين مكونين "زوج كوبر" (Cooper Pair) رغم تنافرهما الكهروستاتيكي.

زوج كوبر: سبين كلي = 0 (بوزون)، يمكنه التكثف في حالة أرضية واحدة (تكثف بوز-أينشتاين).

هناك فجوة طاقة Δ بين هذه الحالة والحالات المثارة.

طالما الطاقة الحرارية kT < Δ، تنتشر أزواج كوبر دون مقاومة (لا تصادمات مبددة).

Tc (درجة الحرارة الحرجة) تتناسب مع Δ.

محددات: BCS تصلح للموصلات التقليدية (Tc < 30K). لا تصلح للموصلات الفائقة عالية الحرارة (الكوبرات).

سؤال: اشرح تأثير هول الكمومي (Quantum Hall Effect).

الإجابة:
تأثير هول الكلاسيكي: في موصل رقيق بمجال مغناطيسي عمودي، ينشأ جهد هول عرضي. مقاومة هول R_H = B/ne.

تأثير هول الكمومي (1980، فون كليتزينج): عند درجات حرارة منخفضة ومجالات مغناطيسية قوية، مقاومة هول لا تتغير خطياً بل تظهر هضبات (Plateaus) عند قيم مكماة:
R_H = h/(νe²) حيث ν عدد صحيح (Integer QHE).

هضبات المقاومة تظهر دقة فائقة (حتى جزء من مليار)، وتستخدم لتعريف المقاومة القياسية (ثابت فون كليتزينج R_K = h/e² = 25812.807... أوم).

التفسير: مستويات لانداو المكماة. الإلكترونات في مستويات طاقة منفصلة (ħω_c). عندما تكون المستويات ممتلئة تماماً (ν ممتلئ)، تكون المقاومة مكماة.

تأثير هول الكمومي الكسري (Fractional QHE، تسوي 1982): هضبات عند ν = 1/3, 2/5,... تفسر بشبه جسيمات لها شحنة كسرية e/3 (إثارة جماعية للإلكترونات).

Question: Explain the concept of gauge invariance in quantum electrodynamics (QED).

Answer:
Gauge invariance is the principle that the laws of physics are unchanged under local phase transformations of the wavefunction:
Ψ(x) → e^(iα(x)q) Ψ(x)
For the Dirac Lagrangian to remain invariant, we must introduce a gauge field Aμ (the photon field) that transforms as:
Aμ → Aμ - ∂μα(x)
And replace ordinary derivatives with covariant derivatives:
∂μ → Dμ = ∂μ + iqAμ
This generates the interaction term between electrons and photons: -qΨ̄γμΨ Aμ.

Question: Explain the Franck-Condon principle in electronic spectroscopy.

Answer:
The Franck-Condon principle states that electronic transitions occur much faster (≈ 10⁻¹⁵ s) than nuclear motion (≈ 10⁻¹³ s). Therefore, during an electronic transition, the nuclei remain essentially stationary (constant position and momentum).

Consequences: The most probable transitions are "vertical" on a potential energy diagram.

If the equilibrium bond lengths of ground and excited states are similar, the 0-0 transition is strongest.

If they differ significantly, transitions to higher vibrational levels (v' > 0) are most probable.

This explains the vibrational fine structure observed in UV-Vis absorption and fluorescence spectra of molecules like I₂.

Question: Prove that the number e is irrational.

Answer:
Assume e is rational: e = p/q where p,q are integers, q ≥ 2.

Using the series: e = Σ(1/k!) from k=0 to ∞.

Multiply by q!: q!e = q! Σ(1/k!) = Σ(q!/k!).

For k ≤ q, q!/k! is an integer.

For k > q: q!/k! = 1/[(q+1)(q+2)...k] < 1/(q+1)^(k-q).

The sum for k > q: Σ q!/k! < Σ 1/(q+1)^(k-q) = 1/(q+1) + 1/(q+1)² + ... = 1/q < 1.

Thus q!e = integer + fraction, but q!e = q!(p/q) = p(q-1)! which is integer.

Contradiction. Therefore, e is irrational.

Question: Implement a function to find the longest palindromic substring in O(n²) time.

Answer:
We use the "expand around center" approach. For each index (and pair), we expand outward while characters match.

Pseudocode:
function longestPalindrome(s):
    if len(s) <= 1: return s
    start = 0, maxLen = 1
    for i from 0 to len(s)-1:
        // odd length palindromes
        len1 = expandAroundCenter(s, i, i)
        // even length palindromes
        len2 = expandAroundCenter(s, i, i+1)
        len = max(len1, len2)
        if len > maxLen:
            start = i - (len-1)//2
            maxLen = len
    return s[start : start+maxLen]
function expandAroundCenter(s, left, right):
    while left >= 0 and right < len(s) and s[left] == s[right]:
        left--
        right++
    return right - left - 1
Question: Design a Least Recently Used (LRU) Cache with O(1) get and put operations.

Answer:
Use a combination of a Hash Map and a Doubly Linked List.

The HashMap stores key → Node (address).

The Doubly Linked List maintains the order of use: head is most recent, tail is least recent.

get(key):
- If key exists: move the node to the head of the list, return its value.

- Else return -1.

put(key, value):
- If key exists: update value, move node to head.

- Else if capacity is full: remove the tail node (LRU), delete its key from map.

- Create new node, add to head, insert key in map.

Complexity: O(1) for both operations.

function mergeKLists(lists):

Question: Implement Dijkstra's algorithm to find the shortest path from a source node in a weighted graph with non-negative edges.

Answer:
function dijkstra(graph, source):
    // graph is an adjacency list: graph[u] = [(v, weight), ...]
    dist = map with default infinity
    dist[source] = 0
    pq = new MinHeap()
    pq.push((0, source))  // (distance, node)
    visited = set()
    while pq is not empty:
        (d, u) = pq.pop()
        if u in visited: continue
        visited.add(u)
        for each (v, weight) in graph[u]:
            if dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight
                pq.push((dist[v], v))
    return dist
Time: O((V+E) log V) with binary heap.

Question: Dynamic Programming: Given a set of items with weights and values, and a knapsack capacity W, find the maximum value achievable (0/1 knapsack).

Answer:
function knapsack(weights, values, W):
    n = len(weights)
    dp = array[0..n][0..W] initialized to 0
    for i from 1 to n:
        for w from 0 to W:
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], values[i-1] + dp[i-1][w - weights[i-1]])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]
Time: O(nW), Space: O(nW). Can be optimized to O(W) space using 1D array.

Question: Detect if a linked list has a cycle. Find the start of the cycle.

slow = head, fast = head

    fast = fast.next.next
    if slow == fast:
        break

while slow != slow2:
    slow = slow.next
    slow2 = slow2.next
return slow (start of cycle).

Mathematical proof: Let distance from head to cycle start = a, cycle start to meeting point = b, cycle length = L. Fast travels a + b + nL, slow travels a + b. 2(a+b) = a + b + nL → a + b = nL → a = nL - b. So distance from meeting point to cycle start = a.

Puzzle: Two trains are on the same track, 100 km apart, heading toward each other at 50 km/h each. A fly starts at the front of one train, flying at 75 km/h toward the other train. Solution:
The trains approach each other at 100 km/h (50+50). They collide in 1 hour (100 km / 100 km/h).

The fly flies continuously at 75 km/h for exactly 1 hour.

Distance = speed × time = 75 × 1 = 75 km.

The infinite series of back-and-forth trips sums to 75 km. (Sum of infinite geometric series).

Puzzle: You have 1000 bottles of wine, one of which is poisoned. You have 10 test strips that can be used to detect poison. A single drop of poison will turn the test strip positive after 24 hours, and you need results in 24 hours. How do you identify the poisoned bottle?
Solution:
Use binary encoding. Number the bottles 0 to 999.

Represent each bottle number in binary (10 bits, since 2¹⁰ = 1024 > 1000).

For each bottle, place a drop on the test strips corresponding to the '1' bits in its binary representation.

After 24 hours, the pattern of positive test strips directly gives the binary number of the poisoned bottle.

Example: If strips 1, 3, 4 are positive → binary 0000011010 → bottle number.

Puzzle: You have a 5-gallon jug and a 3-gallon jug. How can you measure exactly 4 gallons of water?
Solution:
1. Fill the 5-gallon jug.

2. Pour from the 5-gallon jug into the 3-gallon jug until it's full. (5-gal has 2 left, 3-gal is full).

3. Empty the 3-gallon jug.

4. Pour the 2 gallons from the 5-gallon jug into the 3-gallon jug. (3-gal has 2 gal, 5-gal is empty).

5. Fill the 5-gallon jug again.

6. Pour from the 5-gallon jug into the 3-gallon jug until it's full. (The 3-gal had 2 gal, so it takes 1 more. 5-gal now has 4 gallons left).

Done: 4 gallons in the 5-gallon jug.
