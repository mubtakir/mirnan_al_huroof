# العلاقات الثابتة في al_aql

ليست كل فكرة حدثا حركيا. بعض المعاني تكون علاقة قائمة بين شيئين، مثل:

```text
خالد أخو أحمد
القاهرة في مصر
الباب جزء من البيت
البيت له باب
```

لهذا أضيفت طبقة `SemanticRelation`.

## البنية

كل علاقة تحفظ كالتالي:

```text
مصدر + نوع علاقة + هدف + ثقة + دليل
```

مثال:

```text
خالد --أخو--> أحمد
القاهرة --في--> مصر
باب --جزء_من--> البيت
```

## الصيغة في ADL

صيغة مختصرة:

```adl
علاقة خالد أخو أحمد
علاقة : القاهرة في مصر
```

وصيغة ذات حقول:

```adl
علاقة { مصدر: الباب, علاقة: جزء_من, هدف: البيت, ثقة: 0.95 }
```

## الواجهة البرمجية

```julia
space = SimulationSpace()

assert_relation!(space, "خالد", "أخو", "أحمد"; confidence=1.0, evidence="manual")

relations_from(space, "خالد")
relations_to(space, "أحمد")
relations_between(space, "خالد", "أحمد")
```

## الارتباط بالفعل المضمَر

عندما يفهم `al_aql` جملا مثل:

```text
عصفور على الشجرة
باب البيت
```

فإنه لا يكتفي بتسجيل إطار سببي بفعل `يكون`، بل يضيف علاقات ثابتة أيضا:

```text
عصفور --على--> الشجرة
البيت --له--> باب
باب --جزء_من--> البيت
```

بهذا يمكن لمرنان لاحقا أن يسأل عن العلاقات مباشرة، لا أن يبحث عنها داخل سجل الأحداث فقط.

## لماذا هذه الطبقة مهمة؟

العلاقات الثابتة تقرب النظام من الفهم البرمجي لأن كثيرا من المعرفة لا تعبر عن تغير، بل عن ربط:

- القرابة: أخو، أب، ابن.
- المكان: في، على، داخل.
- الجزئية: جزء_من، له.
- الملكية: يملك، له.
- الانتماء: عضو_في، تابع_لـ.

هذه الطبقة تصلح لتغذية التخطيط والاستنتاج لاحقا، لأنها تجعل العلاقات قابلة للفهرسة والسؤال والمقارنة.
