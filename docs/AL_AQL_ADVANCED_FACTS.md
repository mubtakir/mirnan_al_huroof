# المجاز والنية والاستثناء في al_aql

هذه الوثيقة تلخص الطبقات التي تكمل تمثيل الفكرة بعد الأشياء والأحداث والعلاقات والكم.

## RelationFact

العلاقات الثابتة صارت لها تسمية صريحة:

```julia
RelationFact
```

وهي تمثل:

```text
مصدر + علاقة + هدف + ثقة + دليل
```

مثال ADL:

```adl
علاقة الحديد نوع_من معدن
```

ملاحظة: `SemanticRelation` بقي اسما متوافقا مع الكود السابق، لكنه يشير إلى `RelationFact`.

## MetaphorFact

المجاز يمثل نقلا من مجال إلى مجال، لا علاقة حرفية.

مثال:

```text
جيش الليل زحف
```

ليس المقصود أن الليل جيش حرفي، بل أن صفة من مجال الحرب/الجيوش انتقلت إلى مجال الزمن/الظلام، مثل الانتشار أو الغلبة.

صيغة ADL:

```adl
مجاز { تعبير: جيش الليل زحف, مجال_المصدر: حرب, مجال_الهدف: زمن, موضوع: الليل, مستعار: جيش, فعل: زحف, خاصية_منقولة: انتشار, ثقة: 0.8 }
```

ويمكن السؤال:

```julia
metaphors_for(space, "الليل")
```

## IntentFact

النية تفصل بين:

- الفعل الواقع.
- المقصود أو النية.
- الغاية.
- النتيجة الواقعة.

مثال:

```text
ذهب خالد ليشتري خبزا
```

صيغة ADL:

```adl
نية { فاعل: خالد, فعل: ذهب, هدف_الفعل: السوق, نية: شراء_خبز, غاية: إحضار_طعام, نتيجة_واقعة: وصل_السوق, ثقة: 0.9 }
```

ويمكن السؤال:

```julia
intents_for(space, "خالد")
```

## ExceptionRule

الاستثناء يمثل قاعدة عامة مع حالة تمنعها أو تعدلها، مع أولوية.

مثال:

```text
الحديد يتمدد بالحرارة إلا إذا كان مقيدا
```

صيغة ADL:

```adl
استثناء { قاعدة: تمدد_الحديد_بالحرارة, شرط: حرارة > 0.5, استثناء: الحديد_مقيد, أولوية: 10, ثقة: 0.95 }
```

ويمكن السؤال:

```julia
exceptions_for(space, "تمدد_الحديد_بالحرارة")
active_exception(space, "تمدد_الحديد_بالحرارة")
```

`active_exception` يرجع أعلى استثناء أولوية للقاعدة. هذا لا يطبق الاستثناء تلقائيا على كل القواعد بعد، لكنه يوفر البنية التي يحتاجها نظام الاستنتاج عند دمج الأولويات لاحقا.
