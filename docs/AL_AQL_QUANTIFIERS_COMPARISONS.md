# الكم والمقارنة في al_aql

هذه الطبقة تمثل نوعين من المعاني التي لا تكفي فيها علاقة بسيطة:

- الكم: كل، بعض، معظم، لا.
- المقارنة: أكبر، أصغر، أكثر، أقل، يساوي.

## الكم

يمثل الكم حكما عاما أو جزئيا على فئة أو جماعة.

أمثلة:

```text
كل حيوان حي
بعض الناس لا يردون السلام
```

صيغة ADL:

```adl
كم كل حيوان يكون حي
كم بعض الناس لا يردون السلام
```

وصيغة الحقول:

```adl
كم { مقدار: كل, نطاق: حيوان, حكم: يكون, هدف: حي, ثقة: 1.0 }
```

يحفظ ذلك في:

```julia
space.quantified_facts
```

ويمكن السؤال:

```julia
quantified_facts_for(space, "حيوان")
```

## المقارنة

تمثل المقارنة علاقة بين شيئين في خاصية محددة.

مثال:

```adl
مقارنة كتلة1 أكبر من كتلة2 في mass
```

أو:

```adl
مقارنة { طرف1: كتلة1, خاصية: mass, طرف2: كتلة2, احسب: true }
```

إذا كانت `احسب: true` يحاول النظام قراءة القيم الرقمية من الكيانين ثم يقرر:

```text
أكبر / أصغر / يساوي
```

وتحفظ النتيجة في:

```julia
space.comparisons
```

ويمكن السؤال:

```julia
comparisons_for(space, "كتلة1")
```

## لماذا هذا مهم؟

الكم يسمح لمرنان بفهم الفرق بين:

```text
كل حيوان حي
بعض الناس لا يردون السلام
معظم المعادن تتمدد بالحرارة
```

والمقارنة تسمح له بفهم قواعد مثل:

```text
الأكبر يجذب الأصغر أكثر
الشحنة الأقوى تؤثر أكثر
الجسم الأسرع يقطع مسافة أكبر
```

هذه ليست مجرد علاقات ثابتة، بل أحكام تحتاج مقدار شمول أو تفاضل بين شيئين.
