# أسماء العمليات في al_aql

بعض الأسماء لا تشير إلى شيء مباشر، بل إلى عملية أو مجموعة عمليات.

مثلاً:

```text
الكرم = إعطاء من شخص لآخر بلا مقابل
الجود = كرم بدرجة أعلى
العدل = سماع، دراسة، موازنة، حكم
```

لهذا أضيفت طبقة `ProcessConcept`.

## الأنواع

```julia
ProcessStep
ProcessConcept
```

والدوال:

```julia
register_process!
get_process
instantiate_process!
```

## صيغة ADL

تعريف عملية:

```adl
عملية كرم { مجال: أخلاق, شدة: 1.0, خطوة: source أعطى target -> بلا_مقابل }
```

تعريف عملية ترث من عملية أخرى:

```adl
عملية جود < كرم { شدة: 2.0 }
```

هنا `جود` يرث خطوات `كرم`، لكنه يضاعف الشدة.

## تنفيذ العملية

```julia
frames = instantiate_process!(space, "كرم", "سالم", "محمود")
```

ينتج إطاراً بمعنى:

```text
سالم أعطى محمود، النتيجة: بلا مقابل
```

أما:

```julia
instantiate_process!(space, "جود", "سالم", "محمود")
```

فينتج نفس العملية، لكن بشدة أعلى.

## لماذا هذا مهم؟

هذا يحل مشكلة الأسماء المجردة جزئياً.

فالاسم قد يكون:

- اسم شيء: `عصفور`، `شجرة`، `سالم`.
- اسم عملية: `كرم`، `جود`، `عدل`.
- اسم نمط سببي: `تجاذب`، `رد_السلام`.

وبهذا يمكن لمرنان أن يتعامل مع المجردات بوصفها عمليات قابلة للفك إلى أفعال ونتائج، لا مجرد كلمات غامضة.
