# مرصد فيزياء الكلمة

هذه الطبقة تجعل فيزياء الحرف قابلة للاستعمال المباشر، لا مجرد أساس داخلي للتوليد.

الفكرة:

- الحرف له متجه طوري وخواص فيزيائية.
- الكلمة تجمع حروفها كموجات، ومعها تمثيل كليفوردي يحفظ أثراً من ترتيب الحروف.
- عند ظهور كلمة جديدة، يستطيع مرنان حساب موقعها الطيفي فوراً، ثم يبحث عن أقرب كلمات معروفة في المعجم.

هذا لا يعني أن مرنان "يعرف" الكلمة الجديدة يقيناً من الحروف وحدها. الأدق أنه يملك حدساً فيزيائياً أولياً، ثم يحتاج السياق و`K_sem` و`al_aql` لتثبيت المعنى.

## الدوال

أضيف الملف:

```text
src/physics/engines/lexical_oracle.jl
```

والدوال المصدرة:

```julia
word_physics_profile(word)
phonosemantic_quality(word)
nearest_phase_words(word, vocab)
analyze_unknown_word(word, vocab)
coin_word_for_concept(seed_words)
```

## تحليل كلمة جديدة

```julia
analysis = analyze_unknown_word("نوارية", vocab; top_k=5)
```

يعيد:

- هل الكلمة موجودة في المعجم.
- الجذر التقريبي.
- الكتلة والتردد والطاقة.
- معيار المتجه الطوري.
- معيار متجه كليفورد.
- التناغم والثبات والثقل.
- أقرب الكلمات طيفياً في المعجم.
- درجة ثقة أولية في الاستنباط.

## جودة الكلمة صوتياً/دلالياً

```julia
phonosemantic_quality("نوارية")
```

يعطي قيماً مثل:

- `harmony`: تناغم الحروف المتجاورة.
- `stability`: استقرار الانتقال بين الحروف.
- `heaviness`: ثقل الكلمة الطيفي.
- `aesthetic_score`: تقدير جمالي طيفي أولي.

هذه ليست نقداً أدبياً كاملاً بعد، لكنها نواة "ناقد أدبي فيزيائي": يقرأ ثقل الكلمة واستقرارها من بنيتها الحرفية.

## توليد لفظ لمفهوم

```julia
coin_word_for_concept(["نور", "علم"]; vocab=vocab)
```

يبني مرشحات من جذور كلمات المعنى، يركبها على أوزان عربية عامة، ثم يقيس قربها من متوسط الطيف المقصود. النتيجة ليست اعتماداً لغوياً نهائياً، بل قائمة ألفاظ مرشحة مع درجاتها.

## الربط مع generate!

صار المولد يجيب مباشرة عن صيغة مثل:

```text
حلل كلمة نوارية
```

فيرجع تقريراً مختصراً يبدأ بـ:

```text
فيزياء الحرف لكلمة [...]
```

هذا مفيد لاختبار الطبقة من الخادم أو من التشغيل العادي دون الدخول إلى Julia مباشرة.

## حدود هذه الطبقة

هذه الطبقة لا تستبدل corpus ولا `al_aql`.

هي تعطي "استبصاراً حرفياً" أولياً:

```text
حروف -> موجة كلمة -> موقع طيفي -> أقرب كلمات -> حدس معنى
```

أما الفهم الأقوى فيحتاج:

```text
حدس فيزياء الحرف + سياق corpus + علاقات al_aql + كبح/تصحيح معرفي
```

بهذا تصبح الكلمة الجديدة قابلة للفحص منذ لحظة ظهورها، بدل أن تكون خارج النظام تماماً.
