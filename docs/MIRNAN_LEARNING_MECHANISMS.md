# آليات تعلم مرنان

تاريخ الإنشاء: 2026-06-08

هذه الوثيقة تشرح كيف يتعلم مرنان عمليا، لا بوصفه شبكة عصبية، بل كنظام  
فيزيائي لغوي تتراكم فيه العلاقات عبر الطور، الجاذبية، الرنين، الذاكرة،  
والتغذية الراجعة.

السؤال المركزي هنا:

> إذا أدخل المستخدم: "ماذا فعل جيش الليل"، كيف يعمل مرنان حتى يجيب؟

والسؤال الأعمق:

> أين توجد فرص التعلم الإضافية التي يمكن أن تجعل الإجابة أذكى؟

## 1\. ما معنى التعلم في مرنان؟

مرنان لا يتعلم بطريقة:

*   backpropagation
*   gradient descent
*   تحديث ملايين الأوزان العصبية
*   softmax احتمالي تقليدي
*   embeddings متعلمة مثل Word2Vec أو Transformer

بدلا من ذلك، التعلم في مرنان هو تراكم فيزيائي للعلاقات:

| آلية التعلم | ماذا تتعلم؟ | أين تظهر؟ |
| --- | --- | --- |
| مصفوفات الاقتران `K` | أي الكلمات تظهر معا، وبأي قرب واتجاه | `K_sem`, `K_syn`, `K_causal`, `K_dialogue` |
| متجه الطور | هوية الكلمة الفيزيائية في 10000 بعد | `compute_extended_phase_vector` |
| الجاذبية الدلالية | أي الكلمات تجذب بعضها في السياق | scoring والتوليد |
| الذاكرة الطورية | ماذا قيل في الحوار الحالي | `RAMCore`, `DialogueMemory`, `InteractionTrace` |
| التعزيز الطوري | أي اختيارات كانت ناجحة أو ضعيفة | `PhaseReinforcement`, `LanguageFeedback` |
| التعلم الصرفي | كيف تتحول الكلمات عبر الجذر والوزن | `MorphoTwistor`, `root_affinity` |
| التعلم السببي | ما الذي يحدث بعد ماذا | `K_causal`, `CausalFlow`, `BeamReasoner` |
| التعلم الهولوغرافي | حقائق وعلاقات قابلة للاسترجاع | `HolographicKB` |

إذن مرنان لا "يحفظ جوابا" فقط؛ بل يحاول بناء مجال فيزيائي حول السؤال،  
ثم يختار مسارا منخفض التوتر وعالي الرنين.

## 2\. طبقات التعلم الحالية

### 2.1 التعلم من النصوص قبل الاستخدام

عند التدريب عبر `train.jl`، يتعلم مرنان من corpus عبر بناء عدة مصفوفات:

text نسخ

```text
النصوص -> تنظيف -> تقطيع -> vocab -> K_sem/K_syn/K_dialogue/K_causal
```

المعنى:

*   إذا تكررت "جيش" قرب "حرب"، "زحف"، "قاتل"، "حاصر"، تقوى روابطها في `K_sem`.
*   إذا ظهر تركيب "فعل جيش" أو "جيش فعل" كثيرا، تقوى إشارات نحوية في `K_syn`.
*   إذا جاءت "جيش" ثم بعدها "هاجم"، "دخل"، "انسحب"، تقوى اتجاهات في `K_causal`.
*   إذا ظهر سؤال وجواب في حوار، تقوى علاقات `K_dialogue`.

هذه الطبقة تعطي النموذج ذاكرة ثقافية/نصية عامة.

### 2.2 التعلم من فيزياء الكلمة نفسها

حتى لو لم ير مرنان كلمة في corpus، يستطيع تكوين متجه لها:

text نسخ

```text
جيش -> ج + ي + ش -> متجهات حروف -> إزاحة موضعية -> 9958D -> 10000D
الليل -> ا + ل + ل + ي + ل -> 10000D
```

هذا يعني أن مرنان لديه "فطرة حرفية": يعرف شيئا عن الكلمة من تركيبها،  
قبل أن يتعلم معناها من النصوص.

### 2.3 التعلم من الجذر والسطح

أضيفت إشارات:

*   `root_affinity`: تقارب الجذر.
*   `surface_affinity`: تقاطع الحروف/السطح اللفظي.

مثلا:

text نسخ

```text
علم -> تعلم، معلم، العالم
نور -> أنار، منير، ضياء
```

هذه ليست تعلما عصبيا، بل قناة صرفية/حرفية تساعد التوليد عندما تكون `K_sem`  
ضعيفة أو غائبة.

### 2.4 التعلم أثناء الحوار

أثناء الاستخدام، يمكن للنظام أن يسجل:

*   السؤال.
*   الإجابة.
*   الكلمات التي نجحت.
*   الكلمات التي كررت نفسها.
*   تفضيلات المستخدم.
*   قوة تماسك الرد.

الأدوات الحالية أو القابلة للربط:

*   `RAMCore.observe!`: يسجل مسارات الكلمات في ذاكرة جاذبة.
*   `DialogueMemory.add_turn!`: يحفظ آخر الجولات.
*   `InteractionTrace.record!`: يبني أثرا طوريا مستمرا من تفاعلات المستخدم.
*   `AssociativeDialogueMemory.store!`: يربط مفتاحا سياقيا بجواب.
*   `LanguageFeedback.apply_feedback!`: يعزز أو يضعف اختيارات لغوية.

## 3\. مثال عملي: "ماذا فعل جيش الليل"

لنفترض أن المستخدم كتب:

text نسخ

```text
ماذا فعل جيش الليل
```

هذه الجملة قد تكون سؤالا حرفيا، أو صورة شعرية. كلمة "جيش الليل" ليست بالضرورة  
كيانا عسكريا؛ قد تعني الظلام، السكون، الأحلام، النجوم، الخوف، أو امتداد الليل.

هدف مرنان الجيد هنا ليس فقط إكمال كلمة بعد كلمة، بل فهم مجال السؤال.

## 4\. المرحلة الأولى: تحليل السؤال

### 4.1 تقطيع أولي

text نسخ

```text
["ماذا", "فعل", "جيش", "الليل"]
```

### 4.2 تحديد نوع السؤال

text نسخ

```text
ماذا -> أداة استفهام عن حدث/فعل/نتيجة
فعل -> طلب فعل أو حدث
جيش -> فاعل محتمل
الليل -> مضاف إليه أو مجال دلالي
```

الهيكل التقريبي:

text نسخ

```text
ما الحدث الذي قام به [جيش الليل]؟
```

### 4.3 بناء متجهات الطور

لكل كلمة:

julia نسخ

```julia
compute_extended_phase_vector("ماذا")
compute_extended_phase_vector("فعل")
compute_extended_phase_vector("جيش")
compute_extended_phase_vector("الليل")
```

ثم يتكون مجال السؤال:

text نسخ

```text
Q = field("ماذا") + field("فعل") + field("جيش") + field("الليل")
```

لكن الجمع وحده لا يكفي؛ هناك أدوار:

*   "ماذا" يفتح خانة جواب.
*   "فعل" يطلب فعلا.
*   "جيش الليل" يشكل كيانا مركبا.

## 5\. المرحلة الثانية: بناء الكيان المركب "جيش الليل"

النموذج يجب ألا يعامل "جيش" و"الليل" ككلمتين منفصلتين فقط.

هناك احتمالان:

### 5.1 قراءة حرفية

text نسخ

```text
جيش تابع لليل أو يتحرك في الليل
```

مرشحات:

*   زحف
*   هاجم
*   سار
*   حاصر
*   انسحب

### 5.2 قراءة مجازية/شعرية

text نسخ

```text
جيش الليل = الظلام، النجوم، السكون، الأحلام، الخوف
```

مرشحات:

*   زحف على المدينة
*   غطى الطرقات
*   نشر السكون
*   أيقظ الأحلام
*   حاصر الضوء

كيف يقرر مرنان؟

يحتاج إلى مؤشرات:

*   هل السياق السابق شعري؟
*   هل المستخدم يسأل عن نص أدبي؟
*   هل "جيش الليل" ظهر سابقا في corpus كتعبير مجازي؟
*   هل توجد روابط قوية بين "ليل" و"ظلام/سكون/نجوم"؟
*   هل توجد روابط قوية بين "جيش" و"زحف/حاصر/هاجم"؟

هنا تظهر فرصة تعلم مهمة: تعلم التراكيب المجازية المركبة.

## 6\. المرحلة الثالثة: استدعاء الذاكرة والمعرفة

### 6.1 من `K_sem`

يبحث مرنان عن الكلمات المرتبطة بـ:

text نسخ

```text
جيش -> حرب، جنود، زحف، قتال، حصار
ليل -> ظلام، قمر، نجوم، سكون، حلم، خوف
```

ثم يبحث عن تقاطع مجالين:

text نسخ

```text
field(جيش) ∩ field(ليل)
```

المرشحات ذات الرنين الأعلى قد تكون:

text نسخ

```text
زحف، غطى، حاصر، انتشر، خيم، أسدل، أظلم
```

### 6.2 من `K_causal`

لأن السؤال يحتوي "فعل"، نحتاج أفعالا. `K_causal` يجب أن يساعد في اتجاه:

text نسخ

```text
فاعل -> فعل -> أثر
```

مثلا:

text نسخ

```text
جيش -> زحف
ليل -> خيم
ظلام -> غطى
```

إذا لم تكن هذه العلاقات موجودة في التدريب، سيقع النموذج في اختيار عام أو  
قريب سطحيا.

### 6.3 من `HolographicKB`

إذا خزن النظام حقائق مثل:

text نسخ

```text
الليل -> يجلب -> الظلام
الجيش -> يقوم -> بالزحف
الظلام -> يغطي -> الأشياء
```

يمكنه تركيب جواب:

text نسخ

```text
زحف جيش الليل حتى غطى المكان بالظلام.
```

## 7\. المرحلة الرابعة: توليد مسارات جواب

بدلا من اختيار جواب واحد مباشرة، الأفضل أن يبني مرنان عدة مسارات:

### مسار حرفي

text نسخ

```text
جيش الليل سار في الظلام.
```

### مسار مجازي

text نسخ

```text
زحف جيش الليل على المدينة حتى غطاها بالسكون.
```

### مسار تفسيري

text نسخ

```text
إن كنت تقصد التعبير المجازي، فجيش الليل نشر الظلام والسكون.
```

### مسار استيضاحي

text نسخ

```text
هل تقصد جيشا حقيقيا تحرك ليلا، أم صورة شعرية عن الليل؟
```

هنا يجب أن يختار المولد حسب:

*   قوة prompt.
*   تاريخ الحوار.
*   درجة الشعرية.
*   رنين الجواب.
*   عدم التكرار.
*   وضوح السؤال.

## 8\. المرحلة الخامسة: scoring

كل جواب مرشح يقيم عبر عدة قوى:

| القوة | السؤال الذي تجيب عنه |
| --- | --- |
| توافق prompt | هل الجواب متعلق بـ"جيش الليل"؟ |
| توافق الفعل | هل يحتوي فعلا مناسبا لأن السؤال "ماذا فعل"؟ |
| الجاذبية الدلالية | هل الكلمات منجذبة في فضاء الطور؟ |
| الرنين السببي | هل الفاعل يؤدي إلى فعل ثم أثر؟ |
| الجذر/السطح | هل هناك تقارب عربي مفيد؟ |
| الذاكرة الحوارية | هل يناسب سياق المستخدم السابق؟ |
| الجمال/الشعرية | هل التعبير محتمل أدبيا؟ |
| الوضوح | هل يجيب لا يتهرب؟ |

جواب قوي:

text نسخ

```text
زحف جيش الليل حتى غطى الطرقات بالظلام والسكون.
```

لماذا قوي؟

*   "زحف" ينسجم مع "جيش".
*   "غطى" ينسجم مع "ليل/ظلام".
*   "الطرقات" تعطي مكانا.
*   "الظلام والسكون" أثر سببي طبيعي.

## 9\. ماذا يتعلم مرنان من هذا التفاعل؟

بعد أن يجيب، يمكن للنظام أن يتعلم أشياء متعددة.

### 9.1 إذا قبل المستخدم الجواب

مثلا قال المستخدم:

text نسخ

```text
جميل، هذا ما أقصده.
```

يجب أن يعزز:

text نسخ

```text
جيش الليل -> زحف
جيش الليل -> غطى
الليل -> ظلام
الليل -> سكون
زحف -> غطى
```

أين؟

*   `PhaseReinforcement`: تقوية الكلمات الناجحة.
*   `AssociativeDialogueMemory`: ربط السؤال بجواب/نمط جواب.
*   `InteractionTrace`: تحديث ذوق المستخدم نحو التعبير الشعري.
*   `K_sem`: زيادة روابط الكلمات التي نجحت معا.
*   `K_causal`: زيادة اتجاه "جيش الليل -> زحف/غطى".

### 9.2 إذا صحح المستخدم

مثلا قال:

text نسخ

```text
لا، أقصد في قصة معينة: جيش الليل هو اسم فرقة.
```

يجب أن يتعلم:

text نسخ

```text
جيش الليل = اسم كيان خاص
ليس مجازا دائما
```

ويجب أن يخزن هذا كـ:

*   كيان في `EntityRegister`.
*   حقيقة في `HolographicKB`.
*   أثر حواري في `DialogueMemory`.
*   قيد مستقبلي: عند ذكر "جيش الليل" في نفس الحوار، عامله كاسم علم.

### 9.3 إذا طلب المستخدم إجابة أكثر حرفية

text نسخ

```text
أجب بدون شعر.
```

يتعلم النظام تفضيل أسلوب:

text نسخ

```text
خفض الشعرية
رفع الوضوح
رفع المباشرة
```

هذا مناسب لـ:

*   `InteractionTrace.recommend_beta`
*   ذاكرة تفضيلات الأسلوب
*   أوزان scoring

## 10\. آليات تعلم إضافية مقترحة

هذه أفكار لتحسين مرنان لاحقا.

### 10.1 تعلم التراكيب المركبة

المشكلة:

text نسخ

```text
جيش الليل
```

ليست "جيش" + "الليل" فقط. هي وحدة دلالية.

الاقتراح:

إنشاء `CompoundExpressionMemory`:

text نسخ

```text
("جيش", "الليل") -> مركب
نوع المركب: مجازي/اسم علم/إضافة عادية
متجه المركب: fusion(pv("جيش"), pv("الليل"))
```

ما يتعلمه:

*   "جيش الليل" ككيان واحد.
*   "باب الشمس"، "سيف الزمن"، "قلب المدينة" كتراكيب قابلة للتصنيف.

### 10.2 تعلم نوع السؤال

المشكلة:

text نسخ

```text
ماذا فعل X؟
```

يحتاج جوابا بحدث، لا اسما فقط.

الاقتراح:

إنشاء `QuestionIntentLearner`:

text نسخ

```text
ماذا فعل -> مطلوب: فعل + فاعل + أثر
لماذا -> مطلوب: سبب
كيف -> مطلوب: آلية
أين -> مطلوب: مكان
متى -> مطلوب: زمن
```

هذا يحسن ترتيب المرشحات قبل التوليد.

### 10.3 تعلم المجاز

المشكلة:

مرنان قد يخلط بين المعنى الحرفي والمجازي.

الاقتراح:

إنشاء `MetaphorField`:

text نسخ

```text
جيش الليل -> الظلام كجيش
البحر يبتلع -> فعل مجازي
الوقت يركض -> حدث مجازي
```

مصادر التعلم:

*   corpus شعري.
*   تصحيح المستخدم.
*   كلمات قرينة: كأن، مثل، كـ، صورة، مجاز، شعر.

### 10.4 تعلم الكيانات الخاصة أثناء الحوار

المشكلة:

إذا قال المستخدم:

text نسخ

```text
جيش الليل اسم قبيلة في روايتي
```

يجب أن يتغير سلوك النموذج فورا.

الاقتراح:

تقوية `EntityRegister` وربطه بـ:

*   `DialogueMemory`
*   `HolographicKB`
*   `PromptConstraintField`

حتى يصبح:

text نسخ

```text
جيش الليل -> ENTITY(name, group, story_context)
```

### 10.5 تعلم من قبول/رفض المستخدم

المشكلة:

الاختبارات الحالية تؤكد أن التوليد لا يفرغ وأنه قريب، لكنها لا تتعلم من رد فعل  
المستخدم بشكل كامل.

الاقتراح:

إضافة واجهة feedback بسيطة:

julia نسخ

```julia
learn_from_feedback!(gen, prompt, response; rating=1.0, note="")
```

تقوم بـ:

1.  تعزيز الكلمات الناجحة.
2.  تحديث `K_sem` و`K_causal` محليا.
3.  تخزين زوج prompt/response في ذاكرة ترابطية.
4.  تحديث أثر المستخدم.
5.  إن كانت الملاحظة تصحيحية، استخراج حقيقة جديدة.

### 10.6 تعلم "الأثر" بعد الفعل

السؤال "ماذا فعل" لا يكفي فيه الفعل:

text نسخ

```text
زحف جيش الليل
```

الأفضل:

text نسخ

```text
زحف جيش الليل فغطى المدينة بالسكون.
```

الاقتراح:

تعلم قالب:

text نسخ

```text
فاعل -> فعل -> أثر
```

مثال:

text نسخ

```text
الليل -> خيم -> ساد السكون
الجيش -> زحف -> حاصر المكان
المطر -> هطل -> ابتلت الأرض
```

هذا يمكن بناؤه فوق `K_causal` أو كمصفوفة جديدة:

text نسخ

```text
K_effect[action, effect]
```

## 11\. نموذج تدفق مقترح للإجابة

عند إدخال:

text نسخ

```text
ماذا فعل جيش الليل
```

التدفق الأفضل:

text نسخ

```text
1. tokenize
2. detect_question_type = action_query
3. detect_subject = "جيش الليل"
4. classify_subject:
   - literal army?
   - metaphor?
   - named entity?
5. build subject vector by compound fusion
6. retrieve candidate actions:
   - from K_causal
   - from K_sem
   - from metaphor field
   - from root/surface affinity
7. generate candidate answers
8. score:
   - action fit
   - subject fit
   - effect fit
   - style fit
   - memory fit
9. answer
10. wait for user feedback
11. update memory/reinforcement/K/local facts
```

## 12\. مثال إجابة مثالية

إذا لم يوجد سياق سابق:

text نسخ

```text
زحف جيش الليل على المكان، فغطاه بالظلام والسكون.
```

إذا أردنا جوابا أدبيا:

text نسخ

```text
زحف جيش الليل من حواف الأفق، فأطفأ ضجيج النهار وترك المدينة في سكونها.
```

إذا أردنا جوابا حذرا:

text نسخ

```text
إن كنت تقصدها كصورة شعرية، فقد زحف جيش الليل وغطى المكان بالظلام. وإن كان
"جيش الليل" اسما لكيان في قصة، فأحتاج سياق القصة لأجيب بدقة.
```

## 13\. ما الذي يجب تنفيذه أولا؟

الأولوية المقترحة:

1.  `CompoundExpressionMemory` للتراكيب مثل "جيش الليل".
2.  `QuestionIntentLearner` لتمييز "ماذا فعل/لماذا/كيف/أين".
3.  `learn_from_feedback!` كواجهة موحدة لتعلم مرنان أثناء الاستخدام.
