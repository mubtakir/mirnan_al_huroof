# النفي والتضاد في al_aql

بدأت طبقة النفي في `al_aql` بفكرة القطبية:

```text
-فعل
```

لا يعني فقط غياب الفعل، بل محاولة تشغيل نقيضه إن كان معروفاً.

## التضاد

يمكن تعريف علاقة ضدية في ADL:

```adl
ضد حسن : قبيح
ضد خاف : ثبت_وهاجم
```

هذه العلاقة ثنائية الاتجاه:

```julia
opposite_of(space, "حسن")  # قبيح
opposite_of(space, "قبيح") # حسن
```

## الفعل المنفي

مثال:

```adl
ضد خاف : ثبت_وهاجم
غزال : كائن { خوف: 0.4, حركة: 0.2 }
أسد : كائن { طاقة: 0.9 }
ثبت_وهاجم : فعل { الهدف: خوف, مقياس: -3.0; الهدف: حركة, مقياس: 4.0 }
فكرة : غزال -خاف أسد
```

المعنى:

```text
الغزال لم يخف من الأسد، بل ثبت وهاجم.
```

في هذه المرحلة، الفعل المضاد في حالة النفي يطبق أثره على الفاعل نفسه، لأن المثال من نوع الحالة الداخلية:

```text
الغزال خاف -> الغزال هرب
الغزال -خاف -> الغزال ثبت وهاجم
```

## القيم السالبة

الأفعال تستطيع استعمال مقاييس سالبة في آثارها:

```adl
ثبت_وهاجم : فعل { الهدف: خوف, مقياس: -3.0; الهدف: حركة, مقياس: 4.0 }
```

هذا يخفض الخوف ويرفع الحركة. أما العلاقات المفهومية مثل:

```text
حسن = - قبيح
```

فتمثل حالياً بعلاقة `ضد`، وهي أوضح وأأمن من إدخال الإشارة السالبة في كل المتجهات الفيزيائية مباشرة.
