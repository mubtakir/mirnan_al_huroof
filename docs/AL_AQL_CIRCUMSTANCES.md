# ظروف المكان والزمان في al_aql

كل كيان في `al_aql` يحصل الآن على ظرف افتراضي:

```text
مكان = غير_محدد
زمان = غير_محدد
```

هذا يعني أن المكان والزمان جزء من وجود الشيء، حتى لو لم نستعملهما في كل استنتاج.

## الأنواع

```julia
Circumstance
TemporalRelation
```

والدوال:

```julia
set_circumstance!
get_circumstance
set_location!
set_time!
relate_events!
```

## صيغة ADL

تحديد ظرف كيان:

```adl
ظرف سالم { مكان: بيته, زمان: يوم الجمعة }
```

ترتيب حدثين:

```adl
ترتيب سلام_سالم قبل رد_محمود
ترتيب سقوط_الجسم بعد تباطؤ_الجسم
```

## الجمل المكانية

الجمل التي فيها جار ومجرور تحدث ظرف المكان أيضاً:

```text
عصفور على الشجرة.
```

تفهم كفكرة مضمرة:

```text
عصفور يكون/يوجد على الشجرة
```

وتحفظ أيضاً:

```text
ظرف عصفور: مكان = على الشجرة
```

## لماذا هذا مهم؟

الأحداث لا تقع في فراغ.

عندما يقول النص:

```text
في بيته، يوم الجمعة، سلّم سالم على محمود.
```

فالحدث والكيانات المشاركة فيه تحتاج إلى ظرف مكاني وزماني. هذه الطبقة هي الأساس الذي سنبني عليه لاحقاً فهم عبارات مثل:

- قبل/بعد/أثناء.
- في يوم كذا.
- في بلد كذا.
- في بيت فلان.
- أثناء الحرب.
- بعد المطر.
