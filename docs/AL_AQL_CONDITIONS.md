# الشرط والاحتمال في al_aql

أضيفت إلى `CausalTemplate` ثلاثة حقول:

```text
condition
confidence
polarity
```

بهذا يستطيع النمط أن يقول: هذه النتيجة لا تقع دائماً، بل تقع إذا تحقق شرط، وبدرجة ثقة معينة.

## صيغة ADL

```adl
نمط مشروط تنافر_قريب {
  مجال: كهرباء,
  مصدر: شحنة_موجبة,
  فعل: قرب,
  هدف: شحنة_موجبة,
  شرط: source.distance < 0.5,
  فاعل_النتيجة: كلاهما,
  نتيجة: تنافر,
  ثقة: 0.95
}
```

إذا كانت `distance` عند المصدر أكبر من أو تساوي `0.5` فلن ينتج النمط نتيجة. وإذا صارت أقل من `0.5` ينتج إطاراً سببياً يحمل:

```text
condition=source.distance < 0.5
confidence=0.95
polarity=1
```

## الشرط المدعوم الآن

المرحلة الحالية تدعم شروطاً عددية بسيطة:

```text
source.distance < 0.5
target.energy >= 0.8
source.fear > 0.4
```

ويمكن استعمال أسماء عربية لبعض الخصائص الشائعة مثل:

```text
مسافة، خوف، طاقة، حركة
```

## لماذا هذا مهم؟

هذا هو الأساس لعبارات مثل:

```text
إذا اقتربت الشحنتان الموجبتان تنافرتا.
قد يرد محمود السلام.
```

فالنتيجة هنا ليست مطلقة دائماً، بل مشروطة أو احتمالية.
