# فهرس سريع للتوثيق

**صاحب أفكار مرنان:** باسل يحيى عبدالله (basil Yahya Abdullah)

هذا الملف فهرس عملي مختصر لأهم وثائق المشروع داخل `docs/`.

## الوثائق الحالية المهمة

- [AL_AQL_ADL.md](AL_AQL_ADL.md): محرك العقل `al_aql` ولغة ADL الحالية لتعريف الأشياء والأفعال والقواعد والأفكار.
- [AL_AQL_TAXONOMY.md](AL_AQL_TAXONOMY.md): مفاتيح `al_aql` العامة/الفئات المجردة ووراثة صفات الكيانات، مع قاعدة البيانات `data/al_aql_taxonomy.json`.
- [AL_AQL_CAUSAL_TEMPLATES.md](AL_AQL_CAUSAL_TEMPLATES.md): أنماط سببية عامة تصلح للفيزياء والحوار ومجالات أخرى بصيغة أشياء + حدث -> نتيجة.
- [AL_AQL_PROCESS_CONCEPTS.md](AL_AQL_PROCESS_CONCEPTS.md): أسماء العمليات مثل الكرم والجود والعدل بوصفها سلاسل أفعال ونتائج.
- [AL_AQL_NEGATION.md](AL_AQL_NEGATION.md): النفي والتضاد، مثل `حسن = - قبيح` و`فكرة : غزال -خاف أسد`.
- [AL_AQL_CIRCUMSTANCES.md](AL_AQL_CIRCUMSTANCES.md): ظروف المكان والزمان لكل كيان وترتيب الأحداث قبل/بعد/أثناء.
- [AL_AQL_CONDITIONS.md](AL_AQL_CONDITIONS.md): الشرط والاحتمال في الأنماط السببية، مثل `شرط: source.distance < 0.5` و`ثقة: 0.95`.
- [AL_AQL_RESULT_ACTIONS.md](AL_AQL_RESULT_ACTIONS.md): تطبيق `فعل_النتيجة` تلقائيا عند تحقق النمط السببي، مثل رفع درجة غليان الماء بعد إضافة الملح.
- [AL_AQL_EVENT_CHAINS.md](AL_AQL_EVENT_CHAINS.md): سلاسل الأحداث المركبة والمتتالية، مثل حدث أول يليه رد فعل ثم أثر جانبي مع حفظ الترتيب الزمني.
- [AL_AQL_ENGLISH_ADL.md](AL_AQL_ENGLISH_ADL.md): صيغة ADL الإنجليزية لوصف التخطيط البرمجي والكود والعلاقات التقنية.
- [AL_AQL_RELATIONS.md](AL_AQL_RELATIONS.md): العلاقات الثابتة غير الحدثية، مثل القرابة والمكان والجزئية والملكية.
- [AL_AQL_QUANTIFIERS_COMPARISONS.md](AL_AQL_QUANTIFIERS_COMPARISONS.md): الكم والمقارنة، مثل كل/بعض/معظم وأكبر/أصغر/أكثر/أقل.
- [AL_AQL_ADVANCED_FACTS.md](AL_AQL_ADVANCED_FACTS.md): المجاز والنية والاستثناء، مع `RelationFact` و`MetaphorFact` و`IntentFact` و`ExceptionRule`.
- [AL_AQL_GOVERNANCE.md](AL_AQL_GOVERNANCE.md): حوكمة معرفة `al_aql`: القواعد الموثوقة، المقترحة، المرفوضة، دروس الرفض، الكبح العقلي، ووسوم المراجعة النقدية للـ corpus.
- [LETTER_PHYSICS_ORACLE.md](LETTER_PHYSICS_ORACLE.md): مرصد فيزياء الكلمة: تحليل كلمة جديدة من فيزياء الحروف، أقرب الكلمات الطيفية، جودة اللفظ، وتوليد ألفاظ مرشحة لمفهوم.
- [ARABIC_ANALYSIS.md](ARABIC_ANALYSIS.md): أدوات التحليل العربي المنقولة فكرتها من بايثون إلى Julia داخل `al_aql`.
- [RECENT_CHANGES_2026_06_16.md](RECENT_CHANGES_2026_06_16.md): سجل تحديث المخيخ الداخلي، تراكب المعنى، المراجعة الذاتية، وذاكرة العلاج.
- [RECENT_CHANGES_2026_06_14.md](RECENT_CHANGES_2026_06_14.md): سجل التغييرات الأخيرة: فصل بيان القديم، تفعيل `IdeaEngine`، إضافة ADL، وإصلاح `CausalFlow`.
- [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md): حالة التطوير الحالية وما تم نقله أو إصلاحه.
- [MIRNAN_TRAINING_MESSAGE_FLOW.md](MIRNAN_TRAINING_MESSAGE_FLOW.md): شرح موحد لكيف يتعلم مرنان أثناء التدريب، وكيف تمر رسالة المستخدم داخل المولد والـ API وطبقة `al_aql`.
- [MIRNAN_SELF_REVIEW_AND_META_CONTROL.md](MIRNAN_SELF_REVIEW_AND_META_CONTROL.md): المخيخ الداخلي، تراكب معنى الكلمة، نواة تدقيق بيان المحلية، المراجعة الذاتية، وذاكرة التشخيص والعلاج.
- [MIRNAN_LEARNING_MECHANISMS.md](MIRNAN_LEARNING_MECHANISMS.md): شرح آليات تعلم مرنان.
- [PATTERN_MEMORIES.md](PATTERN_MEMORIES.md): توثيق ذاكرات النمط الجديدة: `al_lisan` و`al_code` و`al_tadbir` و`al_hisab` والحسبان الدلالي `al_hisban_al_dalali`.
- [INDEX.md](INDEX.md): الفهرس التفصيلي القديم للتوثيق.

## ملاحظة حول بيان

وثيقة [mirnan_bayan_integration.md](mirnan_bayan_integration.md) تاريخية/أرشيفية. المسار الحالي للفهم السببي داخل مرنان هو `al_aql` وADL و`IdeaEngine`، وليس لغة بيان الهجينة القديمة.

التحديث الجديد لا يعيد ربط مرنان بمجلد `BayanLanguage` الكامل. الذي أضيف هو
نواة محلية صغيرة اسمها `BayanLogicKernel` داخل مرنان، تستعير فكرة التدقيق
المنطقي البسيط من بيان لاكتشاف تناقضات مباشرة أثناء المراجعة الذاتية.
