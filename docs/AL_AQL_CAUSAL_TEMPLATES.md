# الأنماط السببية العابرة للمجالات

هذه الطبقة توسع فكرة `al_aql` من مجال الأشياء الحية فقط إلى أي مجال يمكن التعبير عنه بصيغة:

```text
أشياء + حدث -> نتيجة
```

الفكرة أن `كتلة` و`شحنة` و`إنسان` و`جملة سلام` كلها يمكن أن تدخل في نفس القالب العقلي:

- شيء أو أشياء.
- حدث يقع بينها.
- نتيجة تترتب على الحدث.

## الواجهة

النوع الأساسي:

```julia
CausalTemplate
```

والدوال:

```julia
register_template!
matching_templates
infer_event!
```

## صيغة ADL

يمكن تعريف نمط سببي من اللغة الصغيرة:

```adl
نمط تجاذب_الكتل {
  مجال: فيزياء,
  مصدر: كتلة,
  فعل: تجاذب,
  هدف: كتلة,
  فاعل_النتيجة: كلاهما,
  نتيجة: تقارب ثم التحام
}
```

ويمكن تعريف نمط مشروط مع درجة ثقة:

```adl
نمط مشروط تنافر_قريب {
  مجال: كهرباء,
  مصدر: شحنة_موجبة,
  فعل: قرب,
  هدف: شحنة_موجبة,
  شرط: source.distance < 0.5,
  فاعل_النتيجة: كلاهما,
  نتيجة: تنافر,
  ثقة: 0.95
}
```

الشرط الحالي يدعم مقارنات عددية بسيطة مثل:

```text
source.distance < 0.5
target.energy >= 0.8
```

إذا لم يتحقق الشرط لا ينتج النمط إطاراً سببياً. وإذا تحقق، تحفظ النتيجة معها:

```text
condition=...
confidence=...
polarity=...
```

ثم عند وجود كيانين مصنفين كـ `كتلة`:

```julia
infer_event!(space, "كتلة1", "تجاذب", "كتلة2")
```

ينتج إطاراً سببياً بمعنى:

```text
كتلة1 + كتلة2، حدث: تجاذب، نتيجة: تقارب ثم التحام
```

## أمثلة

كتلتان:

```adl
مفتاح كتلة < شيء { مجال: فيزياء }
كتلة1 : كتلة { مقدار: 1.0 }
كتلة2 : كتلة { مقدار: 2.0 }
نمط تجاذب_الكتل { مجال: فيزياء, مصدر: كتلة, فعل: تجاذب, هدف: كتلة, فاعل_النتيجة: كلاهما, نتيجة: تقارب ثم التحام }
```

شُحنتان موجبتان:

```adl
مفتاح شحنة < شيء { مجال: كهرباء }
مفتاح شحنة_موجبة < شحنة { إشارة: موجبة }
شحنة1 : شحنة_موجبة { مقدار: 1.0 }
شحنة2 : شحنة_موجبة { مقدار: 1.0 }
نمط تنافر_الشحنات { مجال: كهرباء, مصدر: شحنة_موجبة, فعل: قرب, هدف: شحنة_موجبة, فاعل_النتيجة: كلاهما, نتيجة: تنافر }
```

حوار السلام:

```adl
مفتاح متكلم < إنسان { قدرة: قول }
مفتاح مخاطب < إنسان { قدرة: رد }
سالم : متكلم { }
محمود : مخاطب { }
نمط رد_السلام { مجال: حوار, مصدر: متكلم, فعل: قال, نوع: السلام_عليكم, هدف: مخاطب, فاعل_النتيجة: الهدف, فعل_النتيجة: قال, هدف_النتيجة: المصدر, نوع_النتيجة: وعليكم_السلام }
```

ثم:

```julia
infer_event!(space, "سالم", "قال", "محمود"; kind="السلام_عليكم")
```

ينتج أن محمود هو فاعل النتيجة، وفعل النتيجة `قال`، ونوعها `وعليكم_السلام`.

## لماذا هذا مهم؟

بهذا لا تكون وحدة العقل محصورة في مجال واحد.

نفس النظام يصلح لتمثيل:

- فيزياء: كتلة، شحنة، حركة، اصطدام.
- أحياء: وردة، حشرة، رائحة، جذب.
- حوار: متكلم، قول، رد.
- اجتماعيات: طلب، موافقة، رفض.
- برمجة: دالة، إدخال، إخراج، خطأ.

كل مجال يضيف مفاتيحه وأنماطه، لكن البنية العقلية تبقى واحدة.

## الفعل المضمَر

بعض الجمل لا يظهر فيها الفعل صراحة، مثل:

```text
عصفور على الشجرة
باب البيت
بيت جميل
الماء ساخن
```

يعاملها `al_aql` كفكرة بفعل مضمَر:

```text
عصفور يكون/يوجد على الشجرة
البيت يكون له باب
بيت يكون جميلاً
الماء يكون ساخناً
```

هذا مهم لأن الجار والمجرور والمضاف والمضاف إليه يحملان علاقة حقيقية حتى عندما لا تظهر كلمة الفعل.

في حالة المضاف، يحتفظ النظام أيضاً بالاسم المركب مثل `باب البيت` ليكون هو الشيء المحدد الذي يدور عليه الحديث بعد ذلك.

وفي حالة الصفة، تحفظ الصفة على الكيان مثل `beauty` أو `temperature` بحسب قاموس الصفات المضمرة.
