# وثيقة آليات التعلم في مرنان V8

> "التعلم ليس تحسين دالة خسارة — التعلم هو تراكم طوري، تجاذب موجي، ومزامنة هيبيانية في فضاء فيزيائي."
>
> قبل التعلم: [`docs/PREPROCESSING.md`](PREPROCESSING.md) — خط المعالجة المسبقة 5 مراحل لتنظيف النصوص الخام من الإنترنت والموسوعات.
>
> محركات متخصصة: [`BeamReasoner`](ALGORITHMS.md#20-مسبب-البحث-الشعاعي--beamreasoner) — استدلال | [`CodePhaseEngine`](ALGORITHMS.md#21-البرمجة-الفيزيائية--codephaseengine) — برمجة | [`SymbolicMathEngine`](ALGORITHMS.md#22-الرياضيات-الفيزيائية--symbolicmathengine) — رياضيات

## 0. المبادئ الجوهرية

مرنان **لا يستخدم أي شكل من أشكال التعلم التقليدي**:

| ما لا يستخدمه | ما يستخدمه بدلاً من ذلك |
|---|---|
| شبكات عصبية | متجهات طورية حتمية في 9958 بُعداً |
| Backpropagation | ميكانيكا موجية: تداخل + حيود + دوران طوري |
| SGD / Adam / RMSprop | جاذبية نيوتنية: `F = G·m₁·m₂/r²` |
| دالة خسارة (Loss) | 5 مقاييس فيزيائية: تماسك طوري، ترابط جذبوي، رنين LC، رنين الكثافة الكمومية، محاذاة الأمر |
| Softmax | بوابة إنتروبيا + بحث شعاعي فيزيائي |
| Embeddings إحصائية | متجهات ±1 حتمية (MersenneTwister) |
| Transformer Attention | حقل اقتران ديناميكي DCCF + مصفوفة كثافة كمومية ρ |

**الفكرة المركزية**: اللغة ظاهرة فيزيائية. الكلمات أنظمة موجية (لها طاقة وكتلة وتردد وزخم). تعلم اللغة = تزامن هذه الأنظمة الموجية عبر الفعل والتفاعل — تماماً كما تتزامن بندولات الساعات المعلقة على حائط واحد (ظاهرة هيغنز).

## 1. نظرة عامة: خريطة التعلم الكاملة

ينقسم التعلم في مرنان إلى **مرحلتين زمنيتين** و **5 آليات متزامنة**:

```
│  ║  ② اقتران الموجة الحاملة           ← دوران طوري + تجاذب   ║ │
│  ║  ③ تطور المتجهات الطورية           ← مزامنة هيبيانية       ║ │
│  ╚══════════════════════════════════════════════════════════════╝ │

                                ↓

│               (حلقة تغذية راجعة مغلقة — مستمر)                   │
│                                                                  │
│  ╔══════════════════════════════════════════════════════════════╗ │
```

## 2. التفصيل: آلية آلية

### 2.1 بناء مصفوفات الاقتران K (Co-occurrence Matrix Building)

**الملف**: `train.jl:227-266` (دالة `build_K`)  
**نوع التعلم**: إحصاء تشارك (Co-occurrence Statistics) — تعلم غير موجه وغير تكراري.

#### المبدأ الفيزيائي
كلما تشاركت كلمتان في نفس السياق (نفس النافذة المنزلقة)، ازداد وزن الرابط بينهما. الوزن يتناسب عكسياً مع المسافة — الكلمات الأقرب تحصل على وزن أكبر.

#### الصيغة الرياضية
```
K[wᵢ, wⱼ] += 1 / |j - i|    ← داخل نافذة منزلقة بحجم window
```

حيث:
- `i`: موقع الكلمة الأولى في النص
- `j`: موقع الكلمة الثانية
- `|j - i|`: المسافة الموضعية بين الكلمتين

#### المصفوفات الأربع المبنية
| المصفوفة | النافذة | الاتجاه | الدور |
|----------|---------|---------|-------|
| `K_sem` | 10 | ثنائي | دلالي — كلمات ذات صلة معنوية |
| `K_syn` | 4 | ثنائي | نحوي — كلمات متجاورة نحوياً |
| `K_dialogue` | 2 | ثنائي | حواري — أزواج متجاورة مباشرة |
| `K_causal` | 10 | أمامي فقط | سببي — `A→B` وليس `B→A` |

#### لماذا K_causal اتجاهية؟
```
"الملك يحكم" ≠ "يحكم الملك"
```
K_causal أحادية الاتجاه تفرض أن الفعل يأتي بعد الفاعل الطبيعي. هذا ليس قاعدة نحوية، بل **انحياز سببي فيزيائي** — التأثير يأتي بعد السبب، زمنياً.

#### خصائص المصفوفات
- **متفرقة (Sparse)**: توفر ذاكرة CPU بآلاف المرات
- **مخزنة بصيغة CSC**: استخراج سريع للأعمدة (الكلمات المتصلة بكلمة معينة)
- **غير متماثلة (في K_causal)**: تحافظ على اتجاهية العلاقات

#### متى يُستخدم هذا التعلم؟
أثناء التوليد، يستخرج المولّد المرشحين من عمود الكلمة الحالية في `K_sem` للحصول على الكلمات الأكثر ارتباطاً بها دلالياً.

### 2.2 اقتران الموجة الحاملة (Carrier Wave Coupling)

**الملف**: `src/physics/carrier_engine.jl`  
**نوع التعلم**: دوران طوري + تجاذب متبادل — تعلم موجه فيزيائياً.

#### المبدأ الفيزيائي
في الفيزياء، "الموجة الحاملة" (Carrier Wave) هي موجة ذات تردد ثابت تُحمّل عليها إشارة المعلومات (Modulation). في اللغة العربية:
- **الاسم = موجة حاملة**: تردد ثابت يجذب الكلمات التابعة له
- **الفعل/الصفة = موجة محمولة**: إشارة تُحمّل على تردد الاسم

```
"العلمُ ينيرُ العقولَ"
  ↑        ↑       ↑
حامل    محمول   اسم آخر
(اسم)   (فعل)   (مفعول)
```

#### خوارزمية التدريب (Epochs × 2)

```
لكل جملة في الكوربس:
  ① تصنيف كل كلمة نحوياً: اسم / فعل / صفة / حال
  ② حساب تماسك الجملة γ = sentence_coherence(...)
     (γ عالٍ = جملة متماسكة ← تعلم أقوى)
  ③ تدوير طوري للأسماء: rotate_phase(v, θ = γ × π)
     — FFT + إزاحة طورية + الحفاظ على التناظر المرافق
  ④ تدوير طوري للأفعال: rotate_phase(v, θ = π/2)
     — يجعل الأفعال متعامدة (orthogonal) على الأسماء في فضاء الطور
  ⑤ تجاذب متبادل داخل نافذة محلية (مسافة ≤ 15):
     v_carrier += η × γ × v_companion / (1 + distance × 0.15)
     v_companion += η × γ × v_carrier / (1 + distance × 0.15)
```

#### لماذا π/2 للأفعال؟
التعامد (Orthogonality) هو أعلى درجة من "الاختلاف مع الاحتفاظ بالعلاقة". `cos(π/2) = 0`: الفعل ليس هو الاسم، لكنه مرتبط به عبر علاقة تربيعية — تماماً كما يختلف المجال الكهربائي عن المغناطيسي بزاوية 90° في الموجة الكهرومغناطيسية.

#### متى يُستخدم هذا التعلم؟
أثناء التوليد، عامل `carrier` (وزن 3.0) يقيّم كل مرشح بمدى توافقه مع الموجات الحاملة (الأسماء) في السياق.

### 2.3 تطور المتجهات الطورية (Phase Evolution)

**الملف**: `src/physics/phase_evolution.jl`  
**نوع التعلم**: مزامنة هيبيانية (Hebbian Synchronization) — "الخلايا التي تنشط معاً، ترتبط معاً".

#### المبدأ الفيزيائي
كلمتان تتشاركان في نفس السياق ← تنجذبان في فضاء الطور. هذا هو المكافئ الفيزيائي لقاعدة هيب في علم الأعصاب: `Δw_ij = η × x_i × x_j`، لكن مطبقة على متجهات طورية 10000-بعد بدلاً من أوزان تشابكية.

#### الخوارزمية (مرحلتان)

**المرحلة 1: المراقبة** (`observe_cooccurrence!`)
```
لكل زوج كلمات متتالية (w₁, w₂) في النص:
  سجّل أن w₁ و w₂ تشاركتا
  احسب اتجاه الإزاحة: shift_dir = pv(w₂) - pv(w₁)
  خزّن الإزاحة في shifts[w₁][w₂] ← تراكمي
  زد عداد التشارك cooc_counts[w₁][w₂]
```

**المرحلة 2: التطبيق** (`evolve!`)
```
لكل زوج كلمات سُجّل له تشارك:
  إذا كانت مرات التشارك ≥ min_cooc (2):
    sim = cosine_similarity(pv₁, pv₂)
    shift = lr_cooc × (1 - sim) × (pv₂ - pv₁)
    shift = clamp_norm(shift, max_shift=0.25)
    new_pv₁ += shift × 0.3    ← ثقة التحديث 30%
    new_pv₁ = normalize(new_pv₁)
```

#### لماذا max_shift = 0.25؟
يمنع تغيير هوية الكلمة جذرياً — المتجهات تتطور ببطء عبر الزمن، مثل التطور الدلالي للكلمات في اللغات الطبيعية.

#### لماذا ثقة التحديث 30%؟
التعلم البطيء يمنع "النسيان الكارثي" (Catastrophic Forgetting) — الكلمة تحتفظ بـ 70% من هويتها الأصلية.

#### التخزين الدائم
فقط المتجهات التي تغيرت فعلاً (`diff > 1e-6`) تُحفظ إلى `model/evolved_pvs.bin`. أثناء التوليد، للمولّد 3 مستويات لاستخراج متجه الكلمة:
1. **المتجهات المتطورة** (evolved_pvs.bin) — الأولوية القصوى
2. **الذاكرة المؤقتة على القرص** (pv_cache.bin via Mmap) — سريع، لا يُحمّل في RAM
3. **الحساب من الصفر** (compute_extended_phase_vector) — احتياطي

### 2.4 التعزيز الطوري الذاتي (Phase Reinforcement)

**الملف**: `src/physics/phase_reinforcement.jl`  
**نوع التعلم**: تعزيز إيجابي/سلبي — تعلم عبر التغذية الراجعة المباشرة.

#### المبدأ الفيزيائي
كلما أنتجت كلمة جملة متماسكة، يُسجّل أثر طوري لها — "هذه الكلمة ناجحة في هذا السياق". الآثار الناجحة تُعزّز (strengthen)، والضعيفة تُضعف (weaken) وتُحذف إذا انخفضت قوتها عن 0.01.

#### بنية البيانات
```
traces[w]  = المتجه الطوري المُعزَّز للكلمة w (Vector{Float64})
strengths[w] = قوة الأثر (Float64 ∈ [0, 1])
max_traces = 200  ← أقصى عدد للآثار المحفوظة
```

#### خوارزمية التعزيز (`reinforce!`)
```
إذا كانت جودة الجملة > 0.4:
  trace[w] = trace_old + lr × reward × (pv_new - trace_old)
  trace[w] = normalize(trace[w])
  strength[w] = min(1.0, strength_old + reward × lr)
```

#### خوارزمية الإضعاف (`weaken!`)
```
إذا كانت جودة الجملة < 0.15:
  strength[w] -= penalty × lr
  إذا strength[w] < 0.01:
    احذف الأثر ← توفير ذاكرة + إفساح المجال لكلمات جديدة
```

#### التطبيق أثناء التوليد
عند تقييم مرشح، يُخلط متجهه الأصلي مع أثره المُعزَّز:
```
mixed_pv = (1 - strength × 0.5) × original_pv + strength × 0.5 × trace_pv
```
كلما زادت قوة الأثر، زاد تأثيره على المتجه المستخدم في التسجيل.

#### التقليم الدوري
كل 5 توليدات، تضمحل جميع القوى بنسبة 0.5% (`decay_rate = 0.005`). هذا يمنع تراكم آثار قديمة لم تعد ذات صلة.

#### السقف الأعلى
الحد الأقصى 200 أثر — عند تجاوزه، تُحذف أضعف 20%. هذا يحافظ على ذاكرة محدودة وفعالة.

### 2.5 معايرة الرنين الذاتية (Resonance Calibration)

**الملف**: `src/physics/resonance_calibration.jl`  
**نوع التعلم**: تحكم تناسبي تكاملي تفاضلي (PID-like Controller) — ضبط تلقائي للأوزان.

#### المبدأ الفيزيائي
النظام يحتوي على 40+ عامل تسجيل فيزيائي. كل عامل له وزن (من `config.yaml`). لكن الأوزان المثالية تختلف باختلاف:
- نوع النص (شعر، نثر، حوار، مقال علمي)
- لغة النص (عربية، إنجليزية)
- طول السياق
- تفضيلات المستخدم الضمنية

الحل: معايرة تلقائية تشبه متحكم PID في الهندسة — تدفع جميع المقاييس نحو نقطة التوازن 0.5.

#### الخوارزمية (كل 10 توليدات)
```
لكل مقياس فيزيائي m من المقاييس الخمسة:
  avg_score = متوسط قيمة m عبر آخر 10 توليدات
  error = avg_score - 0.5
  new_weight[m] = weight_current + lr_calib × error
```

#### مثال
إذا كان `avg_phase_coherence = 0.8` (مرتفع جداً — النظام "محافظ"):
→ `error = 0.8 - 0.5 = +0.3`
→ وزن `align` (التوافق الطوري) يُخفَّض ← يفسح المجال لعوامل التنوع

إذا كان `avg_gravity = 0.2` (منخفض جداً — النظام "مشتت"):
→ `error = 0.2 - 0.5 = -0.3`
→ وزن `gravity` يُرفع ← يجذب الكلمات المترابطة بقوة أكبر

#### شروط التقارب
- `lr_calib = 0.02` — معدل تعلم بطيء لاستقرار النظام
- `convergence = 0.001` — توقف إذا كانت التغيرات دون هذه العتبة
- `max_iterations = 10` — حد أقصى للجولات

## 3. حلقة التغذية الراجعة المغلقة (Closed Feedback Loop)

**الملف**: `src/physics/language_feedback.jl`  
**هذا هو قلب التعلم المستمر في مرنان.**

### سير العملية (بعد كل توليد)

```
┌─────────────────────────────────────────┐
│        ① تـقـيـيـم الـجـودة              │
│                                         │
│  تُحسب 5 مقاييس فيزيائية:                │
│  ┌───────────────────────────────────┐  │
│  │ 1. التماسك الطوري (30%)           │  │
│  │    متوسط cos بين الكلمات المتجاورة │  │
│  │                                   │  │
│  │ 2. الترابط الجذبوي (25%)          │  │
│  │    مجموع F = G·m₁m₂/r² عبر الجملة │  │
│  │                                   │  │
│  │ 3. تماسك السلسلة الرنينية (20%)    │  │
│  │    تباين ترددات LC عبر الجملة      │  │
│  │                                   │  │
│  │ 4. رنين الكثافة الكمومية (15%)    │  │
│  │    ⟨v_last|ρ|v_last⟩              │  │
│  │                                   │  │
│  │ 5. محاذاة الأمر (10%)             │  │
│  │    cos(متوسط المخرجات, متجه الأمر) │  │
│  └───────────────────────────────────┘  │
│                                         │
│  quality = Σ w_i × metric_i             │
└──────────────┬──────────────────────────┘
               │
     ┌─────────┴──────────┐
     │                    │
     ▼                    ▼
┌────────────┐    ┌────────────┐
│ quality    │    │ quality    │
│ > 0.4      │    │ < 0.15     │
│ (ناجح)     │    │ (فاشل)     │
└─────┬──────┘    └─────┬──────┘
      │                 │
      ▼                 ▼
┌───────────────────────────────────────────┐
│           ② تـعـزيـز (Reinforce)           │
│                                           │
│  ✓ PhaseReinforcer.reinforce!              │
│    → أثر EMA للكلمات الناجحة               │
│                                           │
│  ✓ PhaseEvolution.observe_cooccurrence!    │
│    → إزاحة هيبيانية بين الكلمات المتجاورة   │
│                                           │
│  ✓ K_sem[wᵢ, wⱼ] += lr × quality × 0.1   │
│    → تعزيز وزن الاقتران بين الكلمات         │
│                                           │
│  ✓ ρ += pv × pv'  (تحديث مصفوفة الكثافة)   │
│    → إضافة المتجهات الناجحة للسياق الكمومي  │
│                                           │
│  ✓ إذا avg_coherence > 0.6:               │
│    β = min(β + 0.05, 5.0)                  │
│    → رفع الحرارة ← استكشاف أكثر             │
└───────────────────────────────────────────┘
      أو (حسب quality)
┌───────────────────────────────────────────┐
│            ③ إضـعـاف (Penalize)            │
│                                           │
│  ✗ PhaseReinforcer.weaken!                 │
│    → إضعاف آثار الكلمات الفاشلة             │
│                                           │
│  ✗ K_sem[wᵢ, wⱼ] -= lr × (1-quality) × 0.05│
│    → إضعاف وزن الاقتران الفاشل              │
│                                           │
│  ✗ إذا avg_coherence < 0.25:              │
│    β = max(β - 0.05, 1.0)                  │
│    → خفض الحرارة ← تركيز أكثر               │
└───────────────────────────────────────────┘
               │
               ▼
┌───────────────────────────────────────────┐
│      ④ مـعـايـرة ذاتـيـة (كل 10 أجيال)     │
│                                           │
│  لكل مقياس:                               │
│  new_weight = old + lr × (avg - 0.5)      │
│                                           │
│  الهدف: كل المقاييس تستقر عند 0.5          │
└───────────────────────────────────────────┘
```

### لماذا العتبات 0.4 و 0.15؟
- **0.4**: المنطقة "الرمادية" — لا تعزيز ولا إضعاف. تمنع التقلب المفرط.
- **0.15**: عتبة الفشل الواضح — فقط الإخفاقات الحادة تُعاقب.

## 4. التعلم عبر آليات التوليد المختلفة

كل نمط توليد يُنتج نوعاً مختلفاً من التعلم:

### 4.1 النمط القياسي (Standard / Resonant)
- تعلم عبر الحلقة المغلقة الكاملة (5 مقاييس)
- يستخدم البحث الشعاعي (Beam Search) مع 40+ عامل فيزيائي
- الأنسب لتراكم المعرفة العامة

### 4.2 النمط الإبداعي (Creative)
- نفس آليات التعلم، لكن بحرارة Boltzmann أعلى (`τ = 1.2`)
- احتمالية "نفق كمومي" (`tunnel_prob = 0.05`) تضيف قفزات غير متوقعة
- ينتج تعلمًا أكثر تنوعاً وأقل تحفظاً

### 4.3 النمط الحواري (Dialogue)
- يُفعّل ذاكرة حوارية ترابطية (AssociativeDialogueMemory)
- يتعلم أنماط التفاعل: سؤال ← جواب، تحية ← رد تحية
- يعزز الارتباطات الحوارية الناجحة ويعاقب الفاشلة

### 4.4 نمط PRNN (Stuart-Landau Oscillator)
- تدريب هيبياني فوري (on-the-fly) على انتقالات الطور
- يحوّل المتجهات الحقيقية إلى متجهات طورية مركبة (`phases = v × √N × π`)
- يبني أزواج انتقال `(v_curr, bind(v_next, v_curr))`
- مناسب للتوليد الشعري والإيقاعي

### 4.5 نمط التشابك (Entangle / Wave Optics)
- تقسيم/دمج موجي تناظري (Analog wave splitting/merging)
- اقتران هولوغرافي (Holographic coupling)
- تسجيل عبر تداخل الموجات (Wave interference scoring)

### 5.3 أثر التفاعل (Interaction Trace)
- **الملف**: `src/physics/interaction_trace.jl`
- حقل مستمر يتراكم من تفاعلات المستخدم: `prompt + response → phase vector`
- اضمحلال أسي (`decay_rate = 0.95`) — التفاعلات القديمة تتلاشى تدريجياً
- يتعلم أسلوب المستخدم: يقترح β (حرارة) مناسبة بناءً على طول الأسئلة

### 5.4 مشهد القصد (Intent Landscape)


- التعلم: تراكم متعدد المقاييس للسياق

### 2.6 عامل الالتواء الطوري (MorphoTwistor) — آلية التعلم السادسة

**الملف**: `src/physics/morpho_twistor.jl`  
**نوع التعلم**: قسمة هندسية + تجميع تجميعي — تعلم القوالب الصرفية كتحويلات في فضاء كليفورد.

#### المبدأ الفيزيائي
بين أي كلمتين مرتبطتين صرفياً (مثل "نور" ← "نورا")، يوجد عامل هندسي T في فضاء كليفورد 22D يحوّل الأولى إلى الثانية. هذا العامل ليس قاعدة نصية ("أضف ألفاً")، بل **تحويل متعدد المتجهات**: دوران + تمدد + انعكاس في فضاء الطور.

#### خوارزمية التدريب
```
① استخراج الأزواج الصرفية من الكوربس
   — find_morphological_pairs: تطابق أول 3 حروف (جذر مشترك)
   — نافذة محلية بمسافة ≤ 5

② حساب عامل الالتواء لكل زوج
   T₁₂ = compute_twistor(w₁, w₂)
       = MV(w₂) / MV(w₁)    ← قسمة كليفورد

③ تجميع تجميعي (Agglomerative Clustering)
   — تجميع T's المتشابهة (cosine ≥ 0.7)
   — مركز كل مجموعة = قالب صرفي (MorphPattern)

④ دمج القوالب المتشابهة جداً (cosine ≥ 0.85)
   — تحديث المراكز بمتوسط متحرك
```

#### خوارزمية الاستدلال
```
① استقبال مثال: المستخدم يعطي w₁ → w₂
   compute_twistor(w₁, w₂) → T

② مطابقة القوالب: مقارنة T مع مراكز القوالب المتعلمة
   — إذا وُجد قالب قريب (sim > 0.5): استخدم القالب

③ تطبيق على كلمة الاستفسار:
   v_pred = T ∘ MV(query)    ← جداء كليفورد

④ بحث في المعجم عن أقرب متجه لـ v_pred
   — cosine similarity عبر أول 22 بعداً
```

#### مثال توضيحي
```
الكوربس: "نور، نورا، علم، علما، حلم، حلما"

الأزواج المستخرجة:
  (نور, نورا), (علم, علما), (حلم, حلما)

T₁ (نور→نورا) ≈ T₂ (علم→علما) ≈ T₃ (حلم→حلما)
  ↑ تقارب 0.92 — نفس النمط الصرفي

القالب المتعلَّم: MorphPattern { label="نمط_1", count=3 }
  ← "إضافة ألف" مكتشفة تلقائياً من البيانات

الاستدلال: "نور نورا جو ؟"
  T = compute_twistor("نور", "نورا")
  T ≈ MorphPattern_1.center (sim = 0.89)
  v_pred = T ∘ MV("جو")
  أقرب كلمة: "جوا" (sim = 0.87) ✓
```

## 10. الخلاصة

التعلم في مرنان ليس خوارزمية واحدة، بل **منظومة فيزيائية متكاملة** من 5 آليات تعلم صريحة و 7 آليات تعلم ضمنية، تعمل معاً في انسجام:

1. **إحصاء التشارك** يبني الأساس

3. **المزامنة الهيبيانية** تطوّر المتجهات
4. **التعزيز الطوري** يكافئ النجاح ويعاقب الفشل
5. **المعايرة الذاتية** توازن 40+ عامل تسجيل

والنتيجة: نظام يتعلم **باستمرار**، **بدون معلمات قابلة للتدريب**، **وبدون دالة خسارة أو انتشار عكسي** — فيزياء بحتة في فضاء طوري 10000-بعد.
