## نظرة عامة

### ما هو مرنان؟
مِرنان هو نموذج لغوي فيزيائي ديناميكي يولّد النصوص العربية والإنجليزية باستخدام **الفيزياء البحتة** — الموجات، الجاذبية الدلالية، الميكانيكا الموجية والتداخل الطوري، جبر كليفورد الهندسي، ومذبذبات كوراموتو — بدلاً من الشبكات العصبية والتغذية الراجعة الرياضية الاحتمالية.

### الفلسفة الفيزيائية
* **الحرف = مذبذب**: لكل حرف تردد ذاتي وعناصر طورية عشوائية حتمية.
* **الكلمة = حزمة موجية**: ناتجة عن إزاحة متجهات حروفها وحركاتها دورياً لكسر التبادلية.
* **الجملة = نظام جاذبية**: كلمات تتجاذب في فضاء طوري 10000 بُعد حسب قانون نيوتن للجاذبية.
* **المعنى = رنين طوري**: حالة استقرار تنشأ من انسجام الموجات وسلسلة رنين RLC.
* **التعلم = مزامنة**: Hebbian synchronization في فضاء الطور — وليس backpropagation.
* **الاستدلال = تدفق سببي**: حقل متجهات يقود الكلمات نحو استنتاجات منطقية في فضاء العقل.

## الخوارزميات الفيزيائية الـ 26 للتسجيل (Scoring Weights)

أثناء التوليد، يتم تقييم كل كلمة مرشحة بناءً على 26 عاملاً فيزيائياً تتم معايرتها وتعديلها ديناميكياً بواسطة متحكم PID في المخيخ:
1. `align`: التوافق الطوري الكوزيني مع الهدف السياقي.
2. `gravity`: الجاذبية الدلالية النيوتنية في فضاء الطور.
3. `resonant_chain`: رنين LC وسلسلة زيتا للرنين الموجي.
4. `contextual_spectra`: الأطياف السياقية المتقاربة.
5. `syntax`: التوافق النحوي وانتقالات الحالة.
6. `heterodyne`: التغاير الترددي في القنوات الـ 22.
7. `dccf`: اقتران الحقل الديناميكي (بديل self-attention).
8. `density_matrix`: رنين إسقاط الكثافة الطورية الكمومية $\rho$.
9. `ppm`: حقل تعديل الطور بالأمر وسياق الـ In-Context Learning.
10. `causal_flow_align`: التوافق مع حقل التدفق السببي $J(pv)$.
11. `oscillator`: التزامن الطوري عبر مذبذبات كوراموتو مع التخميد.
12. `kb_knowledge`: المطابقة مع بنك المرشحات الرنان الهولوغرافي للعلاقات.
... وبقية العوامل الـ 26 المفصلة في [docs/ARCHITECTURE.md](ARCHITECTURE.md).

## مقارنة Python vs Julia

| المعيار | إصدار Python القديم | إصدار Julia V9 الحالي |
|---------|---------------------|-----------------------|
| **عدد ملفات الكود** | 246 ملفاً | 28 ملفاً فقط (تنظيم مجموعي) |
| **هياكل البيانات** | 84 فئة (classes) معقدة | 17 هيكلاً (structs) موحدة |
| **إدارة الحالة** | سمات كائن ديناميكية | حقول هياكل ثابتة لثبات النوع |
| **دقة المتجهات الكبيرة** | `Float64` (78KB للكلمة) | `Float32` (39KB للكلمة) - وفر 50% RAM |
| **التكامل العددي** | تكامل يدوي بطيء | تكامل Runge-Kutta 4 (RK4) سريع ومخمد |
| **زمن التشغيل البدئي** | فوري (مع تأخير حسابي) | أقل من ثانية واحدة (Mmap Cache مستمر) |
| **سرعة المعالجة والـ JIT** | بطيئة وغير متسقة | أسرع بمقدار 2-5 أضعاف بفضل JIT |
