## 1. ما هو مرنان؟

### الفلسفة
> **"اللغة ظاهرة فيزيائية قبل أن تكون إحصائية."**

مرنان نموذج لغوي لا يستخدم شبكات عصبية ولا backpropagation ولا embeddings إحصائية ولا softmax ولا transformers. يعتمد بالكامل على الفيزياء: الموجات، الميكانيكا الموجية والتداخل الطوري، جبر كليفورد الهندسي، والجاذبية الدلالية.

### ما لا يستخدمه
- ❌ شبكات عصبية من أي نوع
- ❌ خوارزميات تحسين تقليدية (SGD, Adam)
- ❌ تضمينات إحصائية (Word2Vec, GloVe)
- ❌ Softmax أو توزيعات احتمالية
- ❌ Transformer Attention

### ما يستخدمه
- ✅ فيزياء الحروف — 9958 بُعداً لكل حرف + 22 بُعداً هندسياً
- ✅ جبر كليفورد الهندسي (255 بُعداً للكلمة)
- ✅ الجاذبية النيوتنية الدلالية: F = G·m₁·m₂/r²
- ✅ دوائر الرنين LC بين الكلمات المتجاورة
- ✅ مذبذبات كوراموتو — تزامن طوري
- ✅ مصفوفة الكثافة الكمومية ρ — مكافئ فيزيائي للـ word embedding
- ✅ الموجة الحاملة والمحمولة — الأسماء تجذب أفعالها وصفاتها
- ✅ محرك الأفكار — فكرة = أشياء + حدث + نتيجة
- ✅ الانتشار الرنيني — K كوسط انتشار موجي، ليس كجدول بحث
- ✅ الإدراك الدلالي — حرف ← كلمة ← جملة ← موضوع
- ✅ حلقة تغذية راجعة مغلقة — توليد ← تقييم ← تعزيز/إضعاف ذاتي
- ✅ PRNN — شبكة رنينية طورية هولوغرافية
- ✅ معايرة تلقائية للأوزان

## 2. الطبقات الفيزيائية السبع

مرنان يبني "الفهم" عبر 7 طبقات فيزيائية متراكمة، كل منها مستوحاة من قانون فيزيائي حقيقي:

```
┌─────────────────────────────────────────────────────────┐
│ ٧. حلقة التغذية الراجعة المغلقة                         │
│    توليد ← تقييم بـ 5 مقاييس ← تعزيز/إضعاف تلقائي       │
│ ├─────────────────────────────────────────────────────────┤
│ ٦. مصفوفة الكثافة الكمومية ρ                             │
│    ρ = Σ wᵢ|ψᵢ⟩⟨ψᵢ| — المكافئ الفيزيائي للـ embedding  │
│ ├─────────────────────────────────────────────────────────┤
│ ٥. الموجة الحاملة والمحمولة                             │
│    الاسم = موجة حاملة، الفعل/الصفة = موجات محمولة        │
│ ├─────────────────────────────────────────────────────────┤
│ ٤. فكرة = أشياء + حدث + نتيجة                           │
│    كل فكرة تُختزل إلى متجه طوري واحد                    │
│ ├─────────────────────────────────────────────────────────┤
│ ٣. دوائر الرنين LC بين الكلمات المتجاورة                │
│    كل جزيئتين = مكثف C + ملف L = دائرة رنين بتردد f     │
│ ├─────────────────────────────────────────────────────────┤
│ ٢. الجاذبية الدلالية بين كتل الكلمات                    │
│    F = G·m₁·m₂/r² — كلمات الجملة تتجاذب                 │
│ ├─────────────────────────────────────────────────────────┤
│ ١. طاقة الكلمة وكتلتها                                  │
│    E = hf → m = E/c² — h=c=G=1 في كون النموذج          │
│ └─────────────────────────────────────────────────────────┘
```

## 3. الحرف — المذبذب الأساسي

### ملف: `src/physics/letter_db.jl`

كل حرف (عربي أو إنجليزي) يمثل مذبذباً فيزيائياً في فضاء 9958 بُعداً. المتجه الطوري للحرف يولَّد عشوائياً حتمياً (بناءً على قيمة الحرف) ويبقى ثابتاً:

```julia
struct LetterEntry
    vector::Vector{Int8}      # متجه 9958D من ±1
    operator::String          # +1, -1, 0
    activation::Float64
    spin::Float64
    articulation::String
    manner::String
    meaning::String
end
```

التردد الذاتي للحرف: $\omega_0 = 0.5 + 2.0 \times \frac{|v|}{\sqrt{9958}}$.

بالإضافة إلى المتجه الطوري (9958D)، هناك **22 بُعداً هندسياً** تمثل أبعاداً دلالية نوعية: التركيز، الكثافة، الحرارة، الحركة الخطية والدورانية والنبضية، الكتلة، الصلابة، الشحنة، الامتداد المكاني، السببية الزمنية... هذه الأبعاد هي ما يستخدمه جبر كليفورد.

## 4. الكلمة — حزمة موجية بجبر كليفورد

### 4.1 فيزياء الكلمة — الطاقة والكتلة
$$E = h \times f$$
$$m = E / c^2$$
الثوابت h = c = G = 1 في كون النموذج.

### 4.2 المتجه الطوري للكلمة (9958D)
الكلمة تبني متجهها من حروفها المعدَّلة بالحركات (تشكيل). الحركات العربية تُعدِّل المتجه:
- فتحة/تنوين فتح → +0.5 × متجه الألف
- ضمة/تنوين ضم → +0.5 × متجه الواو
- كسرة/تنوين كسر → +0.5 × متجه الياء
- شدة → ×2.0

كل حرف يُزاح دورياً (circular shift) حسب موضعه في الكلمة لكسر تناظر التباديل.

### 4.3 جبر كليفورد — Multivector22
الملف: `src/physics/clifford_math.jl`
```julia
mutable struct Multivector22
    s::Float64         # درجة 0: عددية
    v::Vector{Float64} # درجة 1: متجهة (22D)
    b::Vector{Float64} # درجة 2: ثنائية المتجه (231D)
    p::Float64         # درجة 22: كاذبة
end
```

## 6. دوائر الرنين LC

### ملف: `src/physics/resonant_chain.jl`
الجملة = سلك من جزيئات متراصة (الكلمات). كل جزيئتين متجاورتين بينهما فجوة:
- **الفجوة = مكثف** (سعة C)
- **الرابط = ملف** (محاثة L)
- **تردد الرنين:** $f = \frac{1}{2\pi\sqrt{LC}}$

---

## 7. الموجة الحاملة والمحمولة

عبر الكوربس، كل جملة تحوي نفس الاسم تجعل موجاته الحاملة **تتجاذب طورياً** وتجذب محمولاتها:
- الاسم = موجة حاملة (carrier)
- الفعل/الصفة = موجات محمولة (modulation)

هذا هو **المكافئ الفيزيائي للـ word embedding** — يُبنى من فيزياء الكلمات لا من إحصاء تردداتها.

## 8. مصفوفة الكثافة ρ — الذاكرة الدلالية

### ملف: `src/physics/density_matrix.jl`
مصفوفة الكثافة الطورية الكمومية $\rho$:
$$\rho = \sum w_i |\psi_i\rangle\langle\psi_i|$$
وقيمة التوقع لرنين الكلمة مع الذاكرة: $R = \langle v|\rho|v\rangle$.

## 12. PRNN — الشبكة الرنينية الطورية الهولوغرافية

شبكة تعتمد على مذبذبات ستوارت-لانداو بدلاً من العصبونات، وتستخدم الربط الهولوغرافي الطوري.

### معادلة ستوارت-لانداو
$$\frac{dz_i}{dt} = (\mu - |z_i|^2 + i\omega_i)z_i + \text{coupling}_i - g_{\text{inh}} a_i z_i$$

## 20. أسئلة وأجوبة

* **لماذا Float32؟** لأنها تقلل استهلاك الذاكرة العشوائية بنسبة 50% مع الحفاظ على سرعة معالجة عالية جداً على مستوى المعالجات والـ cache.
* **هل يدعم لغات غير العربية؟** نعم، يدعم اللاتينية والإنجليزية بشكل افتراضي في متجهات الحروف.

## 21. تطوير استراتيجية توليد جديدة

لإضافة استراتيجية توليد مخصصة جديدة:
1. قم بإنشاء ملف جديد في `src/physics/engines/strategies/` (مثال: `my_custom_strategy.jl`).
2. قم بتعريف الهيكل وتطبيق دالة التقاط Candidates وتقييمها:
```julia
module MyCustomStrategy
    using ..SharedScoring: evaluate_candidate_scores
    
    function generate_custom(gen, prompt)
        # منطق التوليد الفريد
    end
end
```
3. قم بتضمين الملف الجديد في `src/physics/groups/generation_group.jl` وتصدير الواجهات الخاصة به.
4. أضف تفعيله في موجه التوليد المركزي `generator.jl` ضمن دالة الاختيار المتكيف.

## 22. معايرة ومعاملات تخميد كوراموتو

يتأثر التزامن الطوري بمعاملين أساسيين في `kuramoto_oscillator.jl`:
- **`damping_coeff` (الافتراضي = 0.1)**: يتحكم في معدل امتصاص الصدمات الترددية. قيم أعلى (مثال 0.5) تجعل التزامن بطيئاً جداً، وقيم أقل من 0.01 قد تؤدي إلى تشتت وانهيار التكامل العددي.
- **قص المطال (Amplitude Clipping)**: يتم تقييد المشتقة الزمنية بحد أقصى يساوي `50.0` لمنع JIT من حدوث تباعد حسابي عند تكامل الجمل الضخمة.

## 23. إعداد وضبط متحكم PID في المخيخ

يتم التحكم بخصائص المخيخ التكيفي عبر هيكل `PIDController` في `mirnan_cerebellum.jl`:
* **المعاملات الافتراضية**:
  - `Kp = 0.6`: التناسب الفوري مع نسبة خطأ الإنتروبيا.
  - `Ki = 0.0`: معامل التكامل لمسح الأخطاء التراكمية الطويلة.
  - `Kd = 0.0`: معامل التفاضل لتوقع اتجاه حركة إنتروبيا النص.
  - `setpoint = 0.5`: درجة إنتروبيا شانون المستهدفة لثبات النص.
* **التحكم بالتشغيل**:
  لتفعيل أو تعطيل التغذية الراجعة ديناميكياً أثناء تشغيل الكود، قم بتغيير المتغير البولياني في الكيان:
  ```julia
  gen.cerebellum.pid_enabled = true # أو false للتعطيل التام
  ```
