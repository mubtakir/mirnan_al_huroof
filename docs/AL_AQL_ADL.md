# محرك العقل ولغة ADL

هذا المستند يصف الطبقة الحالية المعتمدة داخل مرنان لتمثيل الفكرة كعلاقة بين أشياء وأحداث ونتائج.

المسار الحالي هو:

```text
src/physics/al_aql/
```

أما لغة بيان الهجينة القديمة فليست جزءا من مسار التشغيل الحالي. لا يعتمد `al_aql` على `BayanAnalyzer` ولا على مجلد `BayanLanguage`.

## الفكرة

في `al_aql` كل شيء يعامل ككيان له اسم وحالة:

- أشياء: أسماء أو كيانات مثل `أسد`، `غزال`، `وردة`، `بيت`.
- خصائص: قيم قابلة للتغير مثل `خوف`، `حركة`، `طاقة`، `جمال`.
- أفعال: مؤثرات تغير خصائص كيان آخر أو تشغل نتيجة لاحقة.
- نتيجة: حالة جديدة أو فعل لاحق ينتج من تغير الخصائص.

الصورة المختصرة:

```text
أشياء + حدث -> نتيجة
```

أمثلة:

```text
أسد زأر غزال -> ارتفع خوف الغزال -> هرب
بيت يكون جميل -> صار للبيت جمال
وردة أرسلت رائحة -> زاد وعي/انجذاب كيان آخر
```

## الواجهة البرمجية

الرموز الأساسية مصدرة من `MirnanNew`:

```julia
using .MirnanNew

space = SimulationSpace()
```

أهم الأنواع والدوال:

```julia
Thing
SimulationSpace
PropertyEffect
DynamicVerb
CausalRule

register_entity!
register_verb!
add_rule!
apply_verb!
evaluate_idea!
interact!

compile_adl!
train_from_text!
property_key
```

## المفاتيح العامة

أضيفت طبقة تصنيف عامة إلى `al_aql` حتى لا نكرر الصفات المشتركة مع كل كيان.

كل `SimulationSpace()` يحتوي على سجل:

```julia
space.taxonomy
```

ويمكن ربط الكيان بفئة مجردة:

```julia
lion = Thing("أسد"; kind="حيوان")
register_entity!(space, lion; classes=["مفترس"])
```

بهذا يرث `أسد` من `مفترس` ثم `حيوان` ثم `حي` ثم `ذو_روح` ثم `شيء`.

للتفاصيل اقرأ [AL_AQL_TAXONOMY.md](AL_AQL_TAXONOMY.md).

## تعريف كيان

يمكن إنشاء كيان عام بخصائص وسمات:

```julia
rose = Thing("وردة"; kind="plant", attributes=Dict{String,Any}(
    "color" => "أحمر",
    "scent" => "فواحة",
    "beauty" => 0.8,
))

register_entity!(space, rose)
```

الخصائص الفيزيائية المعروفة تحفظ في متجه الخصائص. السمات الحرة تحفظ في قاموس `attributes`.

## الأفعال الديناميكية

الفعل الديناميكي هو مجموعة تأثيرات على خصائص الهدف:

```julia
roar = DynamicVerb("زأر", [
    PropertyEffect("fear", 5.0, "self"),
])

register_verb!(space, roar)
```

معنى `PropertyEffect("fear", 5.0, "self")`:

- الخاصية المستهدفة: `fear`.
- شدة التأثير: `5.0`.
- مصدر القوة: `self`، أي لا يعتمد على خاصية معينة من الفاعل.

يمكن جعل التأثير يعتمد على خاصية من الفاعل:

```julia
hit = DynamicVerb("ضرب", [
    PropertyEffect("stability", -3.0, "anger"),
])
```

هنا قوة الضرب تتأثر بصفة `anger` لدى الفاعل.

## القواعد السببية

القاعدة السببية تشغل فعلا إذا تجاوزت خاصية معينة عتبة محددة:

```julia
add_rule!(space, CausalRule("fear", :>, 0.5, "هرب"))
```

المعنى: إذا صار الخوف أكبر من `0.5` فشغل فعل `هرب`.

## لغة ADL

`compile_adl!` يقرأ لغة تعريف بسيطة مستقلة عن بيان. هذه اللغة مخصصة لـ `al_aql`.

مثال كامل:

```julia
space = SimulationSpace()

compile_adl!(space, """
أسد : كائن { كتلة: 2.0, طاقة: 0.9 }
غزال : كائن { كتلة: 0.6, خوف: 0.1, حركة: 0.2 }
زأر : فعل { الهدف: خوف, مقياس: 5.0 }
هرب : فعل { الهدف: حركة, مقياس: 6.0; الهدف: خوف, مقياس: -2.0 }
قاعدة : خوف > 0.5 -> هرب
فكرة : أسد زأر غزال
""")
```

بعد تنفيذ المثال:

- يوجد كيانان: `أسد` و`غزال`.
- يوجد فعلان: `زأر` و`هرب`.
- توجد قاعدة سببية للخوف.
- تنفذ الفكرة الأخيرة تفاعلا بين الأسد والغزال.

## صيغ ADL المدعومة

تعريف مفتاح عام:

```adl
مفتاح صياد < إنسان { غذاء: سمك, أعضاء: الصياد|صياد_آخر }
مفتاح آلة_ذكية < آلة { عاقل: لا, قابل_للبرمجة: نعم }
```

تصنيف كيان موجود أو جديد:

```adl
تصنيف خالد : صياد
تصنيف الحاسوب : آلة
```

تعريف كيان مصنف في سطر واحد:

```adl
فارس : صياد { مهارة: صيد, طاقة: 0.6 }
حاسوب_بحثي : آلة { ذاكرة: كبيرة, طاقة: 0.4 }
```

تعريف نمط سببي عام:

```adl
نمط تجاذب_الكتل { مجال: فيزياء, مصدر: كتلة, فعل: تجاذب, هدف: كتلة, فاعل_النتيجة: كلاهما, نتيجة: تقارب ثم التحام }
نمط رد_السلام { مجال: حوار, مصدر: متكلم, فعل: قال, نوع: السلام_عليكم, هدف: مخاطب, فاعل_النتيجة: الهدف, فعل_النتيجة: قال, هدف_النتيجة: المصدر, نوع_النتيجة: وعليكم_السلام }
نمط مشروط تنافر_قريب { مجال: كهرباء, مصدر: شحنة_موجبة, فعل: قرب, هدف: شحنة_موجبة, شرط: source.distance < 0.5, نتيجة: تنافر, ثقة: 0.95 }
```

تعريف اسم عملية:

```adl
عملية كرم { مجال: أخلاق, شدة: 1.0, خطوة: source أعطى target -> بلا_مقابل }
عملية جود < كرم { شدة: 2.0 }
```

تعريف سلسلة أحداث مركبة:

```adl
سلسلة ضرب_ثم_نتائج { مصدر: إنسان, فعل: ضرب, هدف: إنسان, ثقة: 0.9; خطوة: target هرب source -> هروب_المضروب; خطوة: الكتاب سقط الأرض -> سقوط_تابع }
```

هذه الصيغة لا تعطي اسما لمعنى مجرد مثل `كرم`، بل تصف ما يمكن أن يحدث بعد حدث ابتدائي. في المثال: إذا وقع فعل `ضرب` بين مصدر من فئة `إنسان` وهدف من فئة `إنسان`، يمكن تشغيل السلسلة لتنتج:

```text
أحمد هرب خالد
الكتاب سقط الأرض
```

وتسجل علاقة زمنية `بعد` بين الحدث الابتدائي وكل خطوة لاحقة. راجع [AL_AQL_EVENT_CHAINS.md](AL_AQL_EVENT_CHAINS.md).

تعريف ضد ونفي فعل:

```adl
ضد حسن : قبيح
ضد خاف : ثبت_وهاجم
فكرة : غزال -خاف أسد
```

تعريف ظرف مكاني/زماني وترتيب أحداث:

```adl
ظرف سالم { مكان: بيته, زمان: يوم الجمعة }
ترتيب سلام_سالم قبل رد_محمود
```

تعريف علاقة ثابتة غير حدثية:

```adl
علاقة خالد أخو أحمد
علاقة : القاهرة في مصر
علاقة { مصدر: الباب, علاقة: جزء_من, هدف: البيت, ثقة: 0.95 }
```

هذه العلاقات تحفظ في `space.semantic_relations` ويمكن السؤال عنها عبر `relations_from` و`relations_to` و`relations_between`. راجع [AL_AQL_RELATIONS.md](AL_AQL_RELATIONS.md).

تعريف كم ومقارنة:

```adl
كم كل حيوان يكون حي
كم بعض الناس لا يردون السلام
مقارنة كتلة1 أكبر من كتلة2 في mass
مقارنة { طرف1: كتلة1, خاصية: mass, طرف2: كتلة2, احسب: true }
```

الكم يحفظ في `space.quantified_facts`، والمقارنة تحفظ في `space.comparisons`. راجع [AL_AQL_QUANTIFIERS_COMPARISONS.md](AL_AQL_QUANTIFIERS_COMPARISONS.md).

تعريف مجاز ونية واستثناء:

```adl
مجاز { تعبير: جيش الليل زحف, مجال_المصدر: حرب, مجال_الهدف: زمن, موضوع: الليل, مستعار: جيش, فعل: زحف, خاصية_منقولة: انتشار, ثقة: 0.8 }
نية { فاعل: خالد, فعل: ذهب, هدف_الفعل: السوق, نية: شراء_خبز, غاية: إحضار_طعام, نتيجة_واقعة: وصل_السوق, ثقة: 0.9 }
استثناء { قاعدة: تمدد_الحديد_بالحرارة, شرط: حرارة > 0.5, استثناء: الحديد_مقيد, أولوية: 10, ثقة: 0.95 }
```

هذه تحفظ في `space.metaphors` و`space.intents` و`space.exception_rules`. راجع [AL_AQL_ADVANCED_FACTS.md](AL_AQL_ADVANCED_FACTS.md).

فكرة بفعل مضمَر:

```adl
فكرة : عصفور على الشجرة
فكرة : بيت جميل
```

تُفهم كأنها:

```text
عصفور يكون/يوجد على الشجرة
بيت يكون جميلاً
```

وكذلك في التدريب النصي:

```text
عصفور على الشجرة.
باب البيت.
بيت جميل.
الماء ساخن.
```

الأولى تسجل علاقة مكانية بفعل مضمَر `يكون`، والثانية تسجل علاقة امتلاك/جزئية، والثالثة والرابعة تسجلان صفة مضمرة بفعل `يكون`.

صيغة المضاف مثل `باب البيت` تفك إلى:

```text
البيت يكون له باب
```

ثم يحفظ النظام الاسم المركب `باب البيت` بوصفه الباب المحدد الذي صار الحديث عنه.

تعريف كيان:

```adl
اسم : كائن { كتلة: 1.0, خاصية: قيمة }
شيء اسم { كتلة: 1.0, خاصية: قيمة }
```

تعريف فعل:

```adl
اسم_الفعل : فعل { الهدف: خاصية, مقياس: رقم }
فعل اسم_الفعل { الهدف: خاصية, مقياس: رقم }
```

تعريف فعل بتأثيرات متعددة:

```adl
هرب : فعل { الهدف: حركة, مقياس: 6.0; الهدف: خوف, مقياس: -2.0 }
```

تعريف قاعدة:

```adl
قاعدة : خوف > 0.5 -> هرب
قاعدة : استقرار < 0.3 -> سقط
```

تنفيذ فكرة:

```adl
فكرة : فاعل فعل مفعول
فكرة : أسد زأر غزال
فكرة : نار على أثاث
```

حروف الجر البسيطة مثل `على` و`في` و`من` و`إلى` تتجاهل عند تحليل الفكرة.

## خريطة الخصائص العربية

`property_key` يترجم أسماء الخصائص العربية إلى مفاتيح داخلية:

| العربي | الداخلي |
|---|---|
| حرارة | `temperature` |
| حركة | `motion` |
| وعي | `awareness` |
| خوف | `fear` |
| استقرار | `stability` |
| تماسك | `integrity` |
| نور | `light` |
| طاقة | `energy` |
| جمال | `beauty` |
| غضب | `anger` |
| رائحة | `scent` |
| لون | `color` |
| كتلة | `mass` |

الخصائص غير المعروفة تحفظ كسمات حرة في `Thing.attributes` عندما لا تكون ضمن متجه الخصائص الثابت.

## التعلم من نص عربي

`train_from_text!` يوفر استخلاصا أوليا من نص عربي حر. الهدف منه الآن هو طبقة عملية صغيرة، لا محلل صرفي كامل.

مثال:

```julia
space = SimulationSpace()

train_from_text!(space, """
الأسد حيوان مفترس قوي وطاقته كبيرة.
الغزال حيوان خائف وسريع.
زأر الأسد على الغزال يرفع الخوف.
إذا زاد الخوف عن 0.5 يهرب الغزال.
الأسد زأر على الغزال.
""")
```

ما يستخلصه هذا النمط:

- كيانات مبدئية من أوائل الجمل.
- أفعال من جمل مثل: `زأر الأسد على الغزال يرفع الخوف`.
- قواعد من جمل مثل: `إذا زاد الخوف عن 0.5 يهرب الغزال`.
- تفاعل من جمل مثل: `الأسد زأر على الغزال`.

## العلاقة مع IdeaEngine

هناك طبقتان متكاملتان:

- `IdeaEngine`: تمثيل موجي للفكرة كـ `objects + event + result`، ويستخدم دوال مثل `compute_idea_vector`.
- `AlAql`: محاكاة سببية لكيانات وأفعال وخصائص تتغير مع الزمن.

الأولى تقيس مطابقة الفكرة موجيا، والثانية تنفذ أثر الفكرة على كيانات قابلة للتغير.

## ما ليس جزءا من هذه الطبقة

هذه الطبقة لا تستخدم:

- `BayanAnalyzer`
- `BayanLanguage`
- كتل `هجين { ... }`
- مترجم بيان القديم

أي توثيق قديم يذكر هذه العناصر يجب اعتباره أرشيفيا أو بحاجة إلى تحديث، وليس دليلا على مسار التشغيل الحالي.
