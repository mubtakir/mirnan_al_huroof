## نظرة عامة

مرنان V9 هو مشروع لغوي فيزيائي ديناميكي يهدف إلى بناء نموذج لغوي عربي وإنجليزي متكامل، يعتمد بالكامل على القوانين الفيزيائية (الأمواج، التداخل الطوري، الجاذبية الدلالية، ومذبذبات كوراموتو) والتحسين التطوري الجيني بدلاً من الشبكات العصبية والتعلم الإحصائي التقليدي.

يتكون المشروع من الطبقات التالية:
- **المعالجة المسبقة (Preprocessing)**: خط أنابيب من 5 مراحل لتنظيف النصوص وتطبيعها وتصفية جودتها.
- **النحو العربي (Grammar)**: تحليل الجمل وصياغة العلاقات الصرفية والنحوية في فضاء 6D.
- **الدلالة العربية (Semantics)**: تضمين الحروف والكلمات واستخراج الجذور اللغوية.
- **الفيزياء اللغوية (Physics)**: محاكاة الجاذبية الطورية والتزامن الموجي والتغذية الراجعة عبر المخيخ PID، والتحسين التطوري.
- **الربط المتكامل (Integration)**: محرك التنسيق العام الذي يربط كافة الطبقات لإنتاج الاستجابة والتحليل النهائي.

## مميزات الإصدار V9 المكتملة

- 🗂️ **عمارة برمجية مجموعية**: تقسيم المحركات الفيزيائية والمعرفية إلى 10 مجموعات واضحة التبعيات.
- 🎯 **استراتيجيات توليد مفصلة**: توزيع منطق التوليد إلى 15 ملفاً استراتيجياً (Strategy Pattern) يسهل صيانتها وتمديدها.
- ⚡ **أداء فائق واستخدام ذكي للذاكرة**:
  - توحيد متجهات الكلمات الساخنة إلى `Float32` لتقليص استهلاك الذاكرة بنسبة 50%.
  - تخزين مؤقت مستمر على القرص لمتجهات الكلمات والكتل (`pv_cache.bin` و `mass_cache.bin`) مع ربط فوري عبر `Mmap` في أقل من ثانية.
- 🧠 **متحكم المخيخ PID التكيفي**: تعديل ديناميكي ذكي لأوزان التسجيل الـ 24 بناءً على استقرار إنتروبيا الموجة الحالية لتوليد نصوص أكثر تماسكاً وعقلانية.
- ⚛️ **مذبذبات كوراموتو المحدثة**: إضافة معاملات التخميد (`damping_coeff`) وعمليات قص المطال للحد من تشتت المحاكاة الفيزيائية.
- 🔍 **الاكتشاف الذاتي للمفاتيح (Unsupervised Marker Discovery)**: محرك استكشاف يعتمد على إنتروبيا السياق لشبهن (Context Entropy) لاكتشاف أدوات النفي والاستفهام والروابط والسببية تلقائياً دون قوائم لغوية صلبة.
- 🧬 **المُحسِّن التطوري للأوزان (Al-Tawweer)**: خوارزمية جينية متكاملة (انتخاب، تزاوج، طفرات) لتحسين أوزان التقييم الـ 24 للنموذج تلقائياً على نصوص الكوربس وحفظها مباشرة في ملف الإعدادات.

## التثبيت والتشغيل

### المتطلبات
* Julia 1.10 أو أحدث (موصى بـ 1.12+).
* ذاكرة عشوائية 4 جيجابايت كحد أدنى.

### خطوات التثبيت
```bash
# استنساخ المستودع والانتقال إليه
git clone https://github.com/yourusername/mirnan.git
cd mirnan

# تهيئة وتثبيت التبعيات
julia --project=. -e "using Pkg; Pkg.instantiate()"
```

### التدريب المبدئي واكتشاف المفاتيح
```bash
# تدريب الموديل وبناء المعجم واكتشاف المفاتيح اللغوية تلقائياً
julia --project=. train.jl
```

### التحسين التطوري للأوزان (Genetic Optimization)
```bash
# تشغيل الخوارزمية الجينية لتطوير وتحسين أوزان التقييم وحفظ الأوزان الفائزة في config.yaml
julia --project=. run_evolution.jl
```

### واجهة الأوامر التفاعلية (CLI)
```bash
# تشغيل سطر الأوامر التفاعلي
julia --project=. cli.jl -i
```

## أمثلة استخدام مكتبية

### 1. تحليل نص وتوليد استجابة
```julia
using MirnanNew

# تهيئة خط الأنابيب
pipeline = MirnanPipeline()

# تحليل جملة كاملة
result = analyze_text(pipeline, "الطالب يقرأ الكتاب في المكتبة")

# طباعة الاستجابة الموجية المتولدة
println("الاستجابة: ", result.response)

# طباعة التقرير التحليلي الفيزيائي
println(get_analysis_report(result))
```

### 2. فحص ذاكرات النماذج والأنماط
بعد التدريب، يقوم مرنان بتحميل ذاكرات الأنماط للتحقق من صياغتها:
```julia
using MirnanNew

# تهيئة المولد بالمعجم والمجلد الافتراضي للموديل
gen = MirnanGenerator(Dict("العلم" => 1, "ينير" => 2); model_dir="model")

# طباعة ملخص ذاكرات الأنماط النشطة
summary = pattern_memory_summary(gen)
println(summary)
```

## التبعيات الرئيسية

يعتمد المشروع على المكتبات القياسية لـ Julia ومجموعة من الحزم الفعالة:
* `LinearAlgebra`: للحسابات المتجهية والجبرية وقيم التشابه.
* `SparseArrays`: للمصفوفات المتفرقة ذات الأبعاد الضخمة (مصفوفات K).
* `JSON`: للتعامل مع معجم المفردات وقوالب العلاقات.
* `NPZ`: لحفظ وقراءة مصفوفات الاقتران المتفرقة.
* `YAML`: لقراءة إعدادات الملف المركزي `config.yaml`.
* `Mmap`: للتخريط الفوري لملفات التخزين المؤقت المستمرة.
