# مرنان الحروف: حقل الجذب والتنافر الفيزيائي للحروف 🌊⚛️

**Acoustic-Semantic Wave Field Analyzer** — أداة لقياس التداخل الموجي والجاذبية الدلالية بين الكلمات العربية بناءً على بصمات حروفها الفيزيائية والفلسفية، دون الحاجة لشبكات عصبية أو تدريب إحصائي تقليدي.

## 💡 المبدأ العلمي والرياضي

تعتمد المعمارية على فكرة أن لكل حرف عربي **بصمة طيفية** محددة سلفاً في الطبيعة. عندما تجتمع الحروف لتكوّن كلمة، فإن موجاتها تتداخل لتنتج **حزمة موجية (Wave Packet)** تمثل تلك الكلمة في فضاء متعدد الأبعاد.

يتم الحساب في 3 فضاءات طورية:

1. **الطور المادي الأصواتي (Physical Phase - 22D)**: يمثل الخصائص المادية والصوتية للحرف (مثل: مخارج الحروف، الصفات، التركيز، الشحنة، الاستقرار، الاستعلاء، الإطباق...).
2. **الطور الفلسفي الدلالي (Philosophical Phase - 16D)**: يمثل دلالة الحرف الفلسفية التكوينية في اللسان العربي (مثل: `أ` = ابتداء/أصل، `ب` = بناء/تأسيس، `ح` = حياة، `ي` = عمق...).
3. **الطور المدمج الكامل (Combined Phase - 38D)**: يدمج المتجهين المادي والفلسفي لتشكيل بصمة الكلمة الكلية.

### 📐 المعادلات الأساسية

* حساب المتجه الطوري للكلمة $v_{\text{word}}$ من متجهات حروفها $v_{\text{letter}}$ (مع إعطاء وزن مضاعف للحرف الأول والأخير وتأثير متجاور للأزواج):
$$v_{\text{word}} = \text{Normalize}\left(\sum_{i=1}^n w_i v_{\text{letter}_i} + \gamma \sum_{i=1}^{n-1} v_{\text{letter}_i} \cdot v_{\text{letter}_{i+1}}\right)$$

* قياس قوة المجال (التجاذب والتنافر) بين كلمتين باستخدام تشابه جيب التمام الموجه (Cosine Similarity):
$$\text{Similarity}(w_1, w_2) = \frac{v_{w_1} \cdot v_{w_2}}{\|v_{w_1}\| \|v_{w_2}\|}$$

* **التجاذب (Attraction)**: تقارب طوري عالٍ يقترب من $+1.0$.
* **التنافر (Repulsion)**: تباعد طوري يقترب من $-1.0$.

## 🛠️ التشغيل والتركيب

### 1. تثبيت المتطلبات
تثبيت المكونات الأساسية (خفيفة جداً، لا تحتاج GPU أو مكتبات ضخمة):
```bash
pip install -r requirements.txt
```

### 2. تشغيل واجهة التحكم التفاعلية
يمكنك تشغيل واجهة الأوامر التفاعلية مباشرة عبر:
```bash
python cli.py -i
```
أو تمرير كلمة معينة لتحليلها مباشرة:
```bash
python cli.py عدل --space combined --k 10
```

### 3. تشغيل واجهة المتصفح الرسومية (Web UI)
تشغيل خادم الويب المحلي:
```bash
python -m uvicorn src.api.main:app --host 127.0.0.1 --port 8000
```
ثم افتح الرابط التالي في متصفحك: [http://127.0.0.1:8000](http://127.0.0.1:8000) لتجربة واجهة بصرية تفاعلية مبهرة مع أشرطة تقدم حية لقياس قوى الحقول.

### 4. تشغيل الاختبارات
للتحقق من سلامة البنية وصحة الحسابات الرياضية:
```bash
python -m pytest tests/test_word_physics.py -v
```
