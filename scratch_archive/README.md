# Scratch Archive

هذه الملفات هي سكربتات تجارب وتشخيص سابقة، نُقلت من مجلد `scratch/` لتنظيف المشروع.

## التصنيف
- **diag*.jl, check*.jl** — أدوات تشخيص وتصحيح
- **test_*.jl** — اختبارات تجريبية للمكونات الفردية
- **profile_*.jl** — اختبارات قياس الأداء
- **find_*.jl, search_*.jl** — أدوات بحث في قاعدة البيانات
- **clean_*.py** — سكربتات Python لتنظيف البيانات
- **view_sentences.jl, parse_dicts.py** — أدوات عرض وتحليل
- **debug_benchmark.jl** — اختبار قياس الأداء

لم يتم حذفها للاحتياط. يمكن أرشفتها أو حذفها بعد التحقق من عدم الحاجة لها.
